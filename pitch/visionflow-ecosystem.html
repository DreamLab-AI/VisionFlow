VisionFlow · canon of the Dynamic Agentic Mesh

Coordination engineering for federated human–AI intelligence

Hierarchy was an information-routing protocol bounded by human bandwidth. AI is collapsing the cost of that routing towards zero — so the human role is not eliminated, it is promoted: from router to judgment broker, the person who holds the decision at the intersections a machine should not close on its own.

Six independent systems mesh through one cryptographic identity spine. VisionFlow is the canon that keeps them honest — the thing that stops six honest local truths from assembling into one collective lie.

The problem

Agent loops are unbounded by construction. Something formal has to bound them.

In 2026 the industry converged on an answer from the other direction: an ontology — the formal vocabulary of classes, typed properties and rules that defines what can be said — shared across a mesh rather than wired into each agent. The vocabulary is new (neurosymbolic AI: thin agents over a shared formal semantic layer); the architecture is what these repositories already run, in named pieces.

An OWL 2 EL ontology. Two symbolic reasoners. A runtime knowledge graph. And the Ontology Loom to serve the checked graph into any model's context. Reasoning here is a machine check, not an LLM thinking hard: an EL-profile reasoner gates the published closure at build time, and the Whelk EL++ reasoner classifies the shared runtime graph and rejects contradictions before they enter it.

The knowledge stack

Written once, compiled losslessly, checked twice, served grounded.

This is a genuine pipeline — each layer is built from the one before it.

01 Corpus8,100+ pages · Logseq Researchers and agents write a readable corpus at narrativegoldmine.com — a Logseq corpus that is also an OWL ontology. Pure TBox: every page a class, zero individuals by design. Mostly synthetic, agent-written under human direction — a testbed, not an encyclopaedia.
02 OntologyOWL 2 EL · 286,533 triples A seven-stage pipeline compiles the corpus losslessly into the formal ontology, machine-checking every statement as it builds. 0 errors, 0 warnings; 1,396 classes deliberately declare more than one parent — the taxonomy is a lattice, not a tree, and the overlap is published as data.
03 Knowledge graphruntime only The ontology populated with live instances at runtime: VisionClaw's running graph, agents' working graphs, and the personal graphs written into Solid pods. The term is reserved for this layer — the published corpus has no instance data.
04 ReasoningEL-profile · Whelk EL++ Machine-checked at two points: the pipeline's EL-profile reasoner gates the published closure at build, and Whelk classifies the shared runtime graph, rejecting contradictions before they enter it.
05 Groundingthe Ontology Loom The Loom serves the checked ontology back into any model's context at query time, so answers restate verified facts rather than guesses. The model behind it is a URL, swapped by benchmark — consumers never change.

Agents act. Humans sign. The loop must fail loud.

"Silence indistinguishable from success is the exact property a signing loop must not have." ADR-007 · close the governance loop

ADR-007 exists because the canon's own live test (ADR-006) found the governed write path broken in the middle — and said so. Staging must emit the signed request or error; governed writes fail loud rather than fall back silently; decisions are consumed to closure with an enactment receipt.

The same candour extends to competitors. In July 2026, Block released Buzz — a Nostr-native, Rust team-chat + agent platform that independently arrives at the same substrate: signed agent keypairs, events as source of truth. Read as validation of the direction. Buzz is ahead on its wired NIP-42 gate and git forge; what it does not carry — OWL 2 EL grounding, Solid-pod data sovereignty, immersive 3D embodiment, closed memory loops — is the differentiation. Not a claim to win by default.
