## Deleting the merged branches

These are all fully merged, so the safe delete (`-d`) will accept them. Git refuses `-d` for anything unmerged, which protects the held and older branches.

```bash
cd ~/workspace/VisionFlow        && git branch -d fix/estate-review-2026-11-15
cd ~/workspace/project           && git branch -d deploy/nov16-visionclaw feat/store-backup-and-restore fix/estate-review-2026-11-15 fix/governance-builders-to-contract
cd ~/workspace/project/agentbox  && git branch -d fix/estate-review-contracts fix/estate-review-hardening fix/journal-boundary-and-review-leg systemscape-0.3
cd ~/workspace/nostr-rust-forum  && git branch -d feat/governance-contract-v1 integrate/phase-0-1
cd ~/workspace/solid-pod-rs      && git branch -d fix/estate-review-2026-11-15

cd ~/workspace/dream-engine      && git branch -d fix/estate-review-2026-11-15
```
