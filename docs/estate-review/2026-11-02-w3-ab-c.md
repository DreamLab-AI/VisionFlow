# agentbox daemons, hooks, MCP catalogue and ingress diagrams

I assessed all 44 panels in agentbox topics AB-07, AB-08, AB-09 and AB-10 at agentbox `c57d9c0508f4`. 25 are accurate, 18 are corrected, 1 is accurate within limits and none is inaccurate-unfixed. All four topics were restamped from `6500582`. Every diagram citation (1,070 after edits) and every prose citation was re-resolved and read at the pin. The most important finding is in AB-08.13 and AB-08.7. They described `trajectory-recorder.cjs` writing to Postgres behind an inline `RUVECTOR_*` env gate. At the pin, the hook has no database client and no env gate. It POSTs computed rows to `POST /v1/agent-events/trajectory` on the Management API (ADR-2164), and registration is the only gate. Both panels were redrawn. The second most important finding is a class of wrong citation that passes the gate silently. A bare `:NNN` on a line with no participant or path resolves against the last path in document order. In AB-09.5 two citations therefore landed on `agentbox.toml` pod-git lines, and in AB-08.12 one landed on `dream-inbox-surface.cjs`. Both are fixed with explicit paths.

## Findings

**F1. Trajectory recorder moved to the Management API (AB-08.7, AB-08.13).**
- **Trigger:** ADR-2164 landed between `6500582` and the pin, changing trajectory-recorder.cjs (+160/−172).
- **Consequence:** the panels described direct Postgres INSERTs, a `pg module unavailable` branch and an env-gate early return. None of these exists any more. The hook now builds the rows itself. It calls `postTrajectory` with `MANAGEMENT_API_KEY` or `TASK_ACTION_TOKEN` and a 5 s timeout. It advances the watermark only on a 2xx (`trajectory-recorder.cjs:13-17`, `:276-311`, `:508-543`). The entrypoint prefix is now public identity only (`entrypoint-unified.sh:2047-2051`).
- **Drift:** two code comments still say the Jev pre-pass runs "before the database connection opens" (`trajectory-recorder.cjs:110`, `lib/failure-jev.cjs:24`). This is recorded in the panel.
- **To close:** fix the two comments upstream.

**F2. Bare citations resolve against the wrong file without warning (AB-09.5, AB-08.12).**
- **Mechanism:** in flowchart nodes and `alt` lines the generator resolves a bare `:NNN` against the most recent path in the diagram.
- **AB-09.5:** `(:240-241)` and `(:246-250)` were meant for `ruvector-mcp.cjs`. They resolved to `agentbox.toml:240-250` (pod auto-init keys).
- **AB-08.12:** `(:60-66,204-206)` was meant for `project-tracking-publish.cjs`. It resolved to `dream-inbox-surface.cjs`.
- **Status:** all three are fixed with explicit paths.
- **To close:** `diagram-index-gen.cjs` could warn when a bare citation inherits a path from a different line.

**F3. A mechanical restamp carries forward citations that were already wrong.** Several citations were wrong at `6500582` too, and a line-shift remap would have preserved them:
- AB-07.11 `BASELINE-container.md:233` pointed at the sidechain bullet. The Q43 text is at `:235`.
- AB-08.15 `agentbox.toml:783` pointed at `compact_at_percent`, and `:703-707` at `permission_mode`. The jev_compaction text is at `:744-748`, `:756-759` and `:801`.
- AB-08.5 `nostr-live-mirror.cjs:277` pointed at a comment close. The constant is at `:278`.
- AB-10.7 `auth.js:178` should have been `:199`.

All are fixed. These were caught by reading the content, not by the gate.

Both are added.

**F5. A third credential at the Management API gate (AB-10.7, AB-10.14).** A per-task action token is accepted in every auth mode. It is confined to `POST /v1/agent-events/{emit,batch,trajectory}`, and any other route returns 403 (`middleware/auth.js:139-144`, `:207-219`). `verifyAgentEventRequest` returns `did: null` for it, and `reconcileTaskScope` refuses a foreign taskId or an asserted identity (`agent-event-auth.js:139-145`, `:216-235`). Both panels are extended.

**F6. Tension: the ruflo-daemon-gc PID-reuse guard re-checks the argv shape only (AB-07.5).**
- **Mechanism:** `confirm_daemon` re-reads the command line (`procs.rs:77-83`). It does not use the `(pid, argv, starttime)` identity that the Hermes stop path verifies (AB-07.4).
- **Consequence:** a PID recycled by another process with the same daemon-shaped argv still passes the guard.
- **To close:** use `process_identity::verify` at kill time.

**F7. Tension: `startsecs=0` means a loop that is gated off never parks (AB-07.2).**
- **Mechanism:** with `startsecs=0`, supervisord counts every start as successful, so `startretries` never applies. A gated-off scheduler loop returns 0 (`ontology-condense-scheduler.mjs:246-248`), so supervisord relaunches it indefinitely.
- **Correction:** the panel said supervisord "gives up after the default retry budget". That is now corrected.
- **Limit:** this is supervisord semantics, not source in this repository.

**F8. Smaller corrections.**
- AB-07.1 adds the new gated `user-cron` stanza (`flake.nix:3052-3065`, shipped `enabled = true`). It also adds the podcast-cron gate and notes that dream-engine sets no `startsecs`.
- AB-07.8 adds the `pg_restore --clean` replay that `cmd_restore` performs (`agentbox.sh:544-559`).
- AB-07.11 separates the debris tar from the rsync excludes, which the panel had conflated (`agentbox.sh:1833-1864`).
- AB-08.5 adds the ADR-2090 per-project router bypass (`lib/skill-route.cjs:428-446`, `:660`).
- AB-08.8 gains a Drift marker. No registration site sends `action=route` any more.
- AB-08.14: `egress-policy.cjs` has two consumers, because `activity-sink.cjs:315` also uses it. `ontology-monitor` imports `lib/ontology-proposal-jev.cjs`.
- AB-09.5 notes the Postgres password-file change (`ruvector-mcp.cjs:52-55`).
- AB-10.1 has its INGRESS-identity prose citations moved: the doc grew by five lines.
- AB-10.8 no longer shows a "default upstream".
- AB-10.12 counts 128 `assert()` call sites, not 129. The 129th match is the helper's definition.

**F9. Prose citations are outside the gate.**
- **Mechanism:** the generator checks only Mermaid text. AB-10 prose cites in the form `agentbox/...`, without `../project/`, which no tool remaps or checks.
- **Status:** I re-resolved all of these citations by hand, as well as the AB-08 `../project/agentbox/...` prose citations.
- **To close:** extend `--cite-check` to the paragraphs between diagrams.
