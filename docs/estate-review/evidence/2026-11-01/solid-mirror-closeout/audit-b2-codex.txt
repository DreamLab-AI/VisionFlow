## Implementation

All new code is in `migrate_fork.rs`, a child module of `migrate` (`#[path]`), so it uses B1's private machinery directly.

**B1 machinery made class-aware.** A `Kind { Mirror, Fork(Plan) }` is threaded through. `migrate_one` became `migrate_store(.., kind)` (`migrate_one` is the `Mirror` wrapper). The following take the kind:
- `detect_for`, which uses B1's `detect` for mirrors and `fork::detect` for forks;
- `gate`, `new_journal` (journal `class`, plus a new optional `parent` field so a resumed fork knows its lineage while its store is in recovery), `rebuild`, `build`, `seal(.., marked)`, `served_is_ours(.., marked)` and `write_report` (`class`, plus `parent`, `followed` and `ancestors` for a fork).

A journal of the other class is left alone and gates. The mirror pass skips fork journals, which the fork pass resumes.

**Item 1: discovery.** The fork pass lists stores with B1's `served_stores` (errors make the pass incomplete) and reads every store's config with the new `forks::read_fork_parent_checked`, which, unlike `read_fork_parent`, returns read errors instead of "not a fork". Any config error makes the pass incomplete (decision 28). Lineage is walked transitively from each fork's parent:
- it is cycle-safe through a visited set, and bounded by the store count;
- `count_forks` is not used;
- fork journals are added to the targets, using their `parent`.

**Item 2: trigger.** A fork is rebuilt when it holds any id from an unstamped ancestor report's `.dropped` file. The files are streamed into `cat-file --batch-check`, which stops at the first hit; this is the new file-fed stdin, `Input::Files`, with regular-file checks. The check runs under B1's `MIGRATION_ENV` (replacements and grafts off), never consults the marker, and never uses H. A fork whose served migration id matches a fork report listing every trigger report id among its `ancestors` counts as clean: it was rebuilt against them, and what remains of D is reached by its own refs (risk 4). When the pass is complete and no fork failed, every unstamped mirror-class report gets `forksCleanAt` (rewritten with tmp, fsync, rename and a directory fsync; every other field kept).

**Item 3: rebuild.**
- **Refs:** every ref is copied except `refs/mirror/*` (`mirror`), `refs/replace/*` (`replace`) and unsafe names. Each copied ref, pull-request heads included, must not reach the inherited H beyond the ancestors' roots present in the fork: `reaches_held` with `--not <present ancestor roots>`, present-checked first (C12). A ref that does reach H is dropped as `reaches-held` and reported (D1).
- **Verification:** staging is checked against the inherited H, with every copied ref as a root.
- **Config:** for a fork, an allow-list from the old config: `forge.parent`, `http.receivepack` when it is a boolean, and `uploadpack.hideRefs`/`transfer.hideRefs` entries equal to `refs/forge/`. There is no served config. The marker is written only if the old fork had one.
- **Followed fork:** mirror config and marker; roots that reach the inherited H are dropped first, then B1's mirror selection runs on the surviving roots.
- **Report:** `.held` lists the inherited held objects actually left behind.
- **Unchanged:** grafts and replacements stay off for walks and the push.

**Item 4: locks.** A fork's lock is `lock_path`, which already accepts `valid_name_segment` owners. The fork pass runs after the whole mirror pass, and each `migrate_store` takes and releases its own lock, so two locks are never held at once.

**Item 5: partial forks.** `repos/<owner>/.fork-*.tmp` directories at least 3600 s old (by mtime) are renamed to `mirror-recovery/<owner>/<entry>.<ts>`, with directory fsyncs. Errors are logged only, because this is cleanup.

**Item 6: fork creation against a journal.**
- **Source:** refused by `resolve_repo` → `unpublished_mirror` → `journal_gates` (503). Shown by `b2_a_fork_of_a_journalled_source_is_refused`.
- **Target:** refused by B1's `journal_exists` check (503). Shown by B1's `f12_a_fork_onto_a_journalled_name_is_refused`.
- **A journal appearing mid-fork, within one instance:** migration runs to completion inside `ForgeService::new` before any request is handled, and the engine never writes migration journals, so no journal can appear while `h_api_fork` runs. I did not add a re-check between `build_fork` and the rename. Several instances are out of scope (decision 32).

## Deviations from the brief and the design

1. **Decision 28, extended:** an incomplete pass now also refuses every **fork**: any repository whose `config` names a `forge.parent` or cannot be read. This is in `unpublished_mirror`, and runs only while `migration_incomplete` is set. Decision 28 gated only 64-hex owners, but forks live under any owner, and the brief's unreadable-config test ("incomplete, and it must gate") cannot pass without it.
2. **B1 behaviour change:** a mirror-class rebuild now keeps a valid `forge.parent` from the old config. Without this a followed fork loses its lineage once the mirror pass rebuilds it, and its descendants are never swept. A config that cannot be read now fails that mirror-class migration, which stays gated behind its journal.
3. **More fail-closed gates than the brief lists.** A fork is gated (journal reason `detection-error: …`, re-examined every boot through `fork::detect`) when:
   - its lineage passes a 64-hex store still behind a journal;
   - an ancestor's report, `.held` or `.dropped` is missing or unreadable;
   - an ancestor's lineage could not be read;
   - the inherited H passes `MAX_HELD_IDS`.
4. **Orphaned lineage:** a fork whose chain reaches a store that is gone is checked against **every** mirror-class report (and filtered against all their held sets), rather than left as a residual. This is the advisor's option (a).
5. **Stamping is conservative.** If any fork is gated before its ancestors are known, no report is stamped on that boot.
6. **Three tests are guards, not reds.** The untouched-fork guard's red is mutation M6, and the blocked-stamping test's is M10. The journalled-source test confirms B1's existing refusal.
7. **Report shape:** fork reports carry `class: "fork"`, `parent`, `followed` and `ancestors` (the ancestor report ids). Only `class: "mirror"` reports feed the trigger and the filter.
8. **`migrate::verify`** is kept as a `#[cfg(test)]` wrapper over the new `verify_with_roots`, so B1's tests are unchanged.
9. **`forksCleanAt`, not `forks_clean_at`.** The brief and design name the stamp `forks_clean_at`; I used camelCase to match every other report key (`droppedObjects`, `bytesBase64`).
10. **Decision 30, extended to forks.** A fork whose rebuilt copy exceeds 512 MiB fails, like any other migration failure, and stays gated (503) behind its journal. This is in the CHANGELOG.
11. **A gated plan never rebuilds** (review round). This is in `migrate_store`, just before `rebuild`, and applies to any fork whose plan carries a gate, whatever its journal says. Resuming a fork whose rebuilt store is already in place (`served_is_ours` → `publish`) is unaffected.

+        match dir_state(&dir) {

+                Some(Lineage::Parent(po, pn)) => next = Some((po.clone(), pn.clone())),
+                Some(Lineage::Root) => {}
+                Some(Lineage::Unreadable) | None => {
+                    plan.gate = Some(format!("ancestor {o}/{n}'s lineage could not be read"));
+                    return plan;
+                }
+            },
+            Ok(false) => orphan = true,
+            Err(e) => {
+                plan.gate = Some(format!("ancestor {o}/{n}: {e}"));
+                return plan;
+            }
+        }
+    }
+    if orphan {
+        // The chain stops at a store that is gone: its own ancestors are
+        // unknown, so check against every mirror-class report.
+        match every.get_or_insert_with(|| every_mirror_report(plugin)) {
+            Ok(all) => plan.reports.extend(all.iter().cloned()),
+            Err(e) => {
+                plan.gate = Some(format!("the migration reports could not be listed: {e}"));
+                return plan;
+            }
+        }
+    }
+    let mut seen = HashSet::new();
+    plan.reports.retain(|r| seen.insert(r.id.clone()));
+    plan
+}

+/// The mirror-class migration reports of `<owner>/<name>`, with their
+/// `.held` and `.dropped` files. Any report that cannot be read, or lacks
+/// either file, is an error (the fork is then gated).
+fn mirror_reports(plugin: &Path, owner: &str, name: &str) -> Result<Vec<AncestorReport>, String> {
+    let dir = plugin.join("mirror-recovery").join(owner);
+    let mut out = Vec::new();
+    for path in reports(&dir, name)? {
+        if let Some(r) = read_report(&path)? {
+            out.push(r);
+        }

+/// Every mirror-class migration report under `mirror-recovery/`.
+fn every_mirror_report(plugin: &Path) -> Result<Vec<AncestorReport>, String> {
+    let root = plugin.join("mirror-recovery");
+    let mut out = Vec::new();
+    for (owner, path) in super::names_in(&root)? {
+        if !is_hex64(&owner) || !dir_state(&path)? {
+            continue;
+        }
+        for (file, entry) in super::names_in(&path)? {
+            let Some(stem) = file.strip_suffix(".migration.json") else {
+                continue;
+            };
+            let is_report = stem
+                .rsplit_once(".git.")
+                .is_some_and(|(_, ts)| super::all_digits(ts));
+            if is_report {
+                if let Some(r) = read_report(&entry)? {
+                    out.push(r);
+                }
+            }
+        }
+    }
+    Ok(out)

+/// One report, if it is a mirror-class report.
+fn read_report(path: &Path) -> Result<Option<AncestorReport>, String> {
+    let bytes = read_regular(path).map_err(|e| format!("not read: {}", e.kind()))?;
+    let v: serde_json::Value =
+        serde_json::from_slice(&bytes).map_err(|e| format!("not parsed: {e}"))?;
+    if v.get("class").and_then(|c| c.as_str()) != Some("mirror") {
+        return Ok(None);
+    }
+    let id = v
+        .get("id")
+        .and_then(|i| i.as_str())
+        .ok_or("no id")?
+        .to_string();
+    let file = path
+        .to_str()
+        .and_then(|p| p.strip_suffix(".migration.json"))
+        .ok_or("not a report name")?;
+    let stem = PathBuf::from(file);
+    let (held, dropped) = (with_suffix(&stem, ".held"), with_suffix(&stem, ".dropped"));
+    for f in [&held, &dropped] {
+        if !std::fs::symlink_metadata(f).is_ok_and(|m| m.is_file()) {
+            return Err("its held or dropped list is missing".into());
+        }
+    }
+    let roots = v
+        .get("copied")
+        .and_then(|c| c.as_array())
+        .map(|refs| {
+            refs.iter()
+                .filter(|r| {
+                    r.get("ref")
+                        .and_then(|n| n.as_str())
+                        .is_some_and(super::is_root)
+                })
+                .filter_map(|r| r.get("sha").and_then(|s| s.as_str()))
+                .filter(|s| super::is_sha40(s))
+                .map(str::to_string)
+                .collect()
+        })
+        .unwrap_or_default();
+    Ok(Some(AncestorReport {
+        id,
+        path: path.to_path_buf(),
+        held,
+        dropped,
+        roots,
+        stamped: v.get("forksCleanAt").is_some(),
+    }))
+}

+/// Fork detection: `Rebuild` when the fork holds any object of an
+/// unstamped ancestor's dropped set, `Clean` when it holds none (or this
+/// sweep already rebuilt it against every such report), `Error` when it
+/// cannot be checked.
+pub(super) async fn detect(plugin: &Path, owner: &str, name: &str, plan: &Plan) -> Detected {
+    let served = plugin.join("repos").join(owner).join(format!("{name}.git"));
+    match dir_state(&served) {
+        Ok(true) => {}
+        Ok(false) => return Detected::Skip,
+        Err(e) => return Detected::Error(e),
+    }
+    if let Some(g) = &plan.gate {
+        return Detected::Error(g.clone());
+    }
+    let triggers = plan.triggers();
+    if triggers.is_empty() {
+        return Detected::Clean;
+    }
+    if rebuilt_against(plugin, owner, name, &served, &triggers) {
+        return Detected::Clean;
+    }
+    let files: Vec<PathBuf> = triggers.iter().map(|r| r.dropped.clone()).collect();
+    match holds_any(&served, files).await {
+        Ok(true) => Detected::Rebuild,
+        Ok(false) => Detected::Clean,
+        Err(e) => Detected::Error(e),
+    }
+}

+/// Whether the served fork carries the migration id of a fork report that
+/// lists every one of `triggers` among its ancestors: it was rebuilt against
+/// them, and what it still holds of their dropped sets its own refs reach
+/// (risk 4), so it is not rebuilt again.
+fn rebuilt_against(
+    plugin: &Path,
+    owner: &str,
+    name: &str,
+    served: &Path,
+    triggers: &[&AncestorReport],
+) -> bool {
+    let Some(id) = store_migration_id(served) else {
+        return false;
+    };
+    let dir = plugin.join("mirror-recovery").join(owner);
+    let Ok(found) = reports(&dir, name) else {
+        return false;
+    };
+    found.iter().any(|path| {
+        let Some(v) = read_regular(path)
+            .ok()
+            .and_then(|b| serde_json::from_slice::<serde_json::Value>(&b).ok())
+        else {
+            return false;
+        };
+        let covered: BTreeSet<&str> = v
+            .get("ancestors")
+            .and_then(|a| a.as_array())
+            .map(|a| a.iter().filter_map(|x| x.as_str()).collect())
+            .unwrap_or_default();
+        v.get("class").and_then(|c| c.as_str()) == Some("fork")
+            && v.get("id").and_then(|i| i.as_str()) == Some(id.as_str())
+            && triggers.iter().all(|t| covered.contains(t.id.as_str()))
+    })
+}

+/// Whether the store at `git_dir` holds any id listed in `files`
+/// (`cat-file --batch-check`, the lists streamed, stopping at the first hit).
+async fn holds_any(git_dir: &Path, files: Vec<PathBuf>) -> Result<bool, String> {
+    let mut hit = false;
+    super::for_each_line_input(
+        git_dir,
+        &["cat-file", "--batch-check=%(objectname) %(objecttype)"],
+        Input::Files(files),
+        STORE_BUDGET,
+        |line| {
+            if line.ends_with(" missing") {
+                Ok(super::Flow::Go)
+            } else {
+                hit = true;
+                Ok(super::Flow::Stop)
+            }
+        },
+    )
+    .await?;
+    Ok(hit)
+}

+/// The inherited held set: the union of the ancestors' `.held` files,
+/// bounded by [`MAX_HELD_IDS`].
+pub(super) fn inherited_held(plan: &Plan) -> Result<HashSet<String>, String> {
+    use std::io::BufRead;
+    let mut held = HashSet::new();
+    for r in &plan.reports {
+        let m = std::fs::symlink_metadata(&r.held).map_err(|e| format!("held list: {e}"))?;
+        if !m.file_type().is_file() {
+            return Err("a held list is not a regular file".into());
+        }
+        let f = std::fs::File::open(&r.held).map_err(|e| format!("held list: {e}"))?;
+        for line in std::io::BufReader::new(f).lines() {
+            let line = line.map_err(|e| format!("held list: {e}"))?;
+            if line.is_empty() {
+                continue;
+            }
+            if !super::is_sha40(&line) {
+                return Err("a held list holds something other than object ids".into());
+            }
+            if held.len() >= MAX_HELD_IDS {
+                return Err(format!(
+                    "the inherited held set passed {MAX_HELD_IDS} objects"
+                ));
+            }
+            held.insert(line);
+        }
+    }
+    Ok(held)
+}

+/// The ancestors' roots that `source` holds (checked first: `rev-list
+/// --not` fails on an object it does not have, C12).
+pub(super) async fn present_roots(source: &Path, plan: &Plan) -> Result<Vec<String>, String> {
+    let mut all: Vec<String> = plan
+        .reports
+        .iter()
+        .flat_map(|r| r.roots.iter().cloned())
+        .collect();
+    all.sort();
+    all.dedup();
+    if all.is_empty() {
+        return Ok(all);
+    }
+    let mut input = Vec::with_capacity(all.len() * 41);
+    for sha in &all {
+        input.extend_from_slice(sha.as_bytes());
+        input.push(b'\n');
+    }
+    let out = super::run_with_input(
+        source,
+        &["cat-file", "--batch-check=%(objectname) %(objecttype)"],
+        input,
+        STORE_BUDGET,
+    )
+    .await?;
+    if !out.status.success() {
+        return Err("git cat-file --batch-check failed".into());
+    }
+    let present: Vec<String> = String::from_utf8_lossy(&out.stdout)
+        .lines()
+        .filter(|l| !l.ends_with(" missing"))
+        .filter_map(|l| l.split(' ').next())
+        .filter(|id| super::is_sha40(id))
+        .map(str::to_string)
+        .collect();
+    Ok(present)

+/// Fork ref selection into `built`: every ref but `refs/mirror/*` and
+/// `refs/replace/*` (and names unsafe on a push command line), each copied
+/// only if it reaches nothing in `held` beyond `ancestor_roots` (D1: a ref
+/// that does is dropped and reported as `reaches-held`).
+pub(super) async fn select(
+    source: &Path,
+    refs: Vec<(String, Option<String>, String)>,
+    built: &mut Built,
+    held: &HashSet<String>,
+    ancestor_roots: &[String],
+) -> Result<(), String> {
+    for (sha, name, lossy) in refs {
+        let reason = match name.as_deref() {
+            None => "unsafe-name",
+            Some(r) if !super::safe_ref(r) || !super::is_sha40(&sha) => "unsafe-name",
+            Some(r) if r.starts_with("refs/mirror/") => "mirror",
+            Some(r) if r.starts_with("refs/replace/") => "replace",
+            Some(r) => {
+                if super::reaches_held(source, &sha, ancestor_roots, held).await? {
+                    "reaches-held"
+                } else {
+                    built.copied.insert(r.to_string(), sha);
+                    continue;
+                }
+            }
+        };
+        built.dropped.push(DroppedRef {
+            name: lossy,
+            sha,
+            reason,
+        });
+    }
+    Ok(())
+}

+/// Stamp `forksCleanAt` into every unstamped mirror-class report whose id

+/// Add `forksCleanAt` to the report at `path`, every other field kept: a
+/// temporary file, `fsync`, rename, `fsync` the directory.
+fn stamp(path: &Path) -> Result<(), String> {

+    let mut v: serde_json::Value =
+        serde_json::from_slice(&bytes).map_err(|e| format!("not parsed: {e}"))?;
+    let o = v.as_object_mut().ok_or("not an object")?;
+    o.insert("forksCleanAt".into(), now_secs().into());
+    let out = serde_json::to_vec_pretty(&v).map_err(|e| e.to_string())?;
+    let tmp = with_suffix(path, ".tmp");
+    write_synced(&tmp, &out).map_err(|e| format!("not written: {e}"))?;
+    std::fs::rename(&tmp, path).map_err(|e| format!("not written: {e}"))?;

+        .map_or(Ok(()), sync_dir)
+        .map_err(|e| format!("not synced: {e}"))

+/// D4: move every `repos/<owner>/.fork-*.tmp` directory older than
+/// [`PARTIAL_FORK_AGE`] to `mirror-recovery/<owner>/<entry>.<ts>`. Cleanup
+/// only (smart-HTTP refuses such paths), so errors are logged.
+fn sweep_partial_forks(plugin: &Path) {
+    let Ok(owners) = super::names_in(&plugin.join("repos")) else {
+        return;
+    };
+    for (owner, owner_dir) in owners {
+        if !crate::ownership::valid_name_segment(&owner) {
+            continue;
+        }
+        let Ok(entries) = super::names_in(&owner_dir) else {
+            continue;
+        };
+        for (file, entry) in entries {
+            if !(file.starts_with(".fork-") && file.ends_with(".tmp")) {
+                continue;
+            }
+            let Ok(meta) = std::fs::symlink_metadata(&entry) else {
+                continue;
+            };
+            let old = meta
+                .modified()
+                .ok()
+                .and_then(|t| t.elapsed().ok())
+                .is_some_and(|age| age >= PARTIAL_FORK_AGE);
+            if !meta.is_dir() || !old {
+                continue;
+            }
+            let dir = plugin.join("mirror-recovery").join(&owner);
+            let dest = dir.join(format!("{file}.{}", now_secs()));
+            let moved = std::fs::create_dir_all(&dir)
+                .and_then(|()| std::fs::rename(&entry, &dest))
+                .and_then(|()| sync_dir(&dir))
+                .and_then(|()| sync_dir(&owner_dir));
+            match moved {
+                Ok(()) => {
+                    tracing::info!(owner = %owner, entry = %file, "forge: stale partial fork moved to recovery");
+                }
+                Err(e) => {
+                    tracing::warn!(owner = %owner, entry = %file, error = %e, "forge: stale partial fork not moved");
+                }
+            }
+        }
+    }

     1	//! Boot migration of pre-release served stores, and the served-store
     2	//! plumbing it shares with the mirror engine. Kept outside the `mirror`
     3	//! feature: a plugin directory that was mirrored once must be migrated even
     4	//! when it is now served without the feature.
     5	//!
     6	//! # Shared plumbing
     7	//!
     8	//! The fixed `--receive-pack` command ([`RECEIVE_PACK`]), the fixed served
     9	//! config ([`SERVED_CONFIG`]), the cross-process lock path ([`lock_path`]),
    10	//! the legacy-config probe and the hardened, process-group `git` runner.
    11	//!
    12	//! # Migration
    13	//!
    14	//! [`crate::ForgeService::new`] runs it before returning. A mirror-class
    15	//! store (a 64-hex owner) is migrated when it has no
    16	//! [`crate::PUBLICATION_MARKER`] and shows any pre-release signal, each
    17	//! checked on its own: a mirror record that is flagged, pre-release or
    18	//! unreadable; `refs/mirror/*`; `hideRefs` naming them; alternates; or an
    19	//! earlier migration report. A check that fails with nothing positive found
    20	//! gates the store instead (a `detection-error` journal, removed only once a
    21	//! later boot examines every signal and finds them negative). If the pass
    22	//! cannot list every journal and served store, or cannot gate a store, it
    23	//! reports itself incomplete and the forge refuses every mirror-class store
    24	//! (and every fork).
    25	//! Walks and the push run with replacements and grafts off. Under the
    26	//! store's lock (waited for at most
    27	//! 600 s), with a journal ([`journal_path`]) recording each step:
    28	//!
    29	//! 1. the attempt is counted and a fresh store initialised in
    30	//!    `plugin_dir/mirror-work/staging/`;
    31	//! 2. the roots (branches and tags with safe names) are pushed into it by
    32	//!    SHA, under the [`MAX_REPO_BYTES`] cap, with every other ref whose
    33	//!    closure lies inside theirs; `refs/mirror/*`, pull request heads,
    34	//!    `refs/replace/*`, unsafe or non-UTF-8 names and refs outside the roots
    35	//!    are dropped and reported;
    36	//! 3. it is verified at object level (no object any ref reaches outside the
    37	//!    roots, nothing outside the roots' closure, no alternates, no object file
    38	//!    shared with the old store), then given its [`MIGRATION_ID_FILE`] and
    39	//!    marked;
    40	//! 4. a report naming the migration id is written beside the recovery path
    41	//!    (`<name>.git.<ts>.migration.json`, `.held`, `.dropped`), never over an
    42	//!    existing one;
    43	//! 5. the old store is renamed to `plugin_dir/mirror-recovery/<owner>/<name>.git.<ts>`
    44	//!    and the new one into `repos/`;
    45	//! 6. the record's awaits-migration flag is removed, the candidate wiped and
    46	//!    the journal deleted.
    47	//!
    48	//! Journal, report and lists are `fsync`ed before the renames that depend on
    49	//! them. A crash is resumed at the next boot: a rebuilt store already in
    50	//! `repos/` carrying the journal's migration id is finished, never rebuilt;
    51	//! otherwise the store is rebuilt from the old store, read from recovery
    52	//! once it has moved. Every journal, in any state, keeps every reader
    53	//! refusing the store (503) until it is deleted. A failure leaves a `failed`
    54	//! journal; after [`MAX_ATTEMPTS`] attempts, crashes
    55	//! included, boot stops retrying. Recovery copies are never deleted
    56	//! automatically and must never be served: do not add `.forge` to the pod's
    57	//! dotfile allowlist.
    58	//!
    59	//! # Forks
    60	//!
    61	//! After the mirror-class stores, the same machinery sweeps forks of them
    62	//! (any owner): every served repository's `forge.parent` is read (a config
    63	//! that cannot be read makes the pass incomplete, and the forge then also
    64	//! refuses every fork), each fork's lineage is walked to its root, and a
    65	//! fork holding any object of a migrated ancestor's `.dropped` set is
    66	//! rebuilt. It keeps every ref but `refs/mirror/*` and `refs/replace/*`,
    67	//! except a ref reaching an object in the ancestors' `.held` sets, which is
    68	//! dropped and reported. A fork whose ancestor is still behind a journal is
    69	//! gated. Stale `repos/<owner>/.fork-*.tmp` directories are moved to
    70	//! recovery. See the `migrate_fork` source for the details.
    71	//!
    72	//! # Example
    73	//!
    74	//! ```
    75	//! use std::path::Path;

   318	/// [`run_output`] with `env` added to git's environment and the size
   319	/// watcher's timing given by `poll`.
   320	#[allow(clippy::too_many_arguments)]
   321	async fn run_output_env(
   322	    git_dir: &Path,
   323	    watch: &Path,
   324	    args: &[&str],
   325	    allow: Option<&str>,
   326	    timeout: Duration,
   327	    cap: Option<(u64, DirMeasure)>,
   328	    poll: SizePoll,
   329	    env: &[(&str, &str)],
   330	) -> Result<std::process::Output, String> {
   331	    let mut cmd = git_command(git_dir, watch, args);
   332	    for (k, v) in env {
   333	        cmd.env(k, v);
   334	    }
   335	    if let Some(a) = allow {
   336	        cmd.env("GIT_ALLOW_PROTOCOL", a);
   337	    }
   338	    let child = cmd
   339	        .spawn()
   340	        .map_err(|e| format!("git could not start: {e}"))?;
   341	    let pid = child.id();
   342	    note_group(pid);
   343	    let waited = child.wait_with_output();
   344	    tokio::pin!(waited);
   345	    let deadline = tokio::time::sleep(timeout);
   346	    tokio::pin!(deadline);
   347	    let (tx, mut grew) = tokio::sync::oneshot::channel::<()>();
   348	    let watcher = cap.map(|(limit, measure)| {
   349	        let d = watch.to_path_buf();
   350	        tokio::spawn(async move {
   351	            tokio::time::sleep(poll.0).await;
   352	            loop {
   353	                let d2 = d.clone();
   354	                let size = tokio::task::spawn_blocking(move || measure(&d2))
   355	                    .await
   356	                    .unwrap_or(0);
   357	                if size > limit {
   358	                    let _ = tx.send(());
   359	                    return;
   360	                }
   361	                tokio::time::sleep(poll.1).await;
   362	            }
   363	        })
   364	    });
   365	    let outcome = tokio::select! {
   366	        out = &mut waited => Ok(out),
   367	        () = &mut deadline => Err(GIT_TIMED_OUT.to_string()),
   368	        Ok(()) = &mut grew => Err(GREW_PAST_CAP.to_string()),
   369	    };
   370	    if let Some(w) = watcher {
   371	        w.abort();
   372	    }
   373	    match outcome {
   374	        Ok(out) => {
   375	            forget_group(pid);
   376	            out.map_err(|e| format!("git failed: {e}"))
   377	        }
   378	        Err(why) => {
   379	            kill_group(pid).await;
   380	            forget_group(pid);
   381	            Err(why)
   382	        }
   383	    }
   384	}

   386	/// Run git on the store at `git_dir` and read its stdout line by line,
   387	/// returning the first line `pick` accepts (git is then killed), or `None`
   388	/// once git has exited successfully without one. stderr is discarded; a
   389	/// failure is reported as `git <command> failed`.
   390	#[cfg(feature = "mirror")]
   391	pub(crate) async fn first_line(
   392	    git_dir: &Path,
   393	    args: &[&str],
   394	    timeout: Duration,
   395	    pick: impl Fn(&str) -> bool,
   396	) -> Result<Option<String>, String> {
   397	    use tokio::io::AsyncBufReadExt;
   398	    let mut cmd = git_command(git_dir, git_dir, args);
   399	    cmd.stderr(std::process::Stdio::null());
   400	    let mut child = cmd
   401	        .spawn()
   402	        .map_err(|e| format!("git could not start: {e}"))?;
   403	    let pid = child.id();
   404	    let what = args.first().copied().unwrap_or("git");
   405	    let stdout = child.stdout.take().ok_or("git has no stdout")?;
   406	    let mut lines = tokio::io::BufReader::new(stdout).lines();
   407	    let read = async {
   408	        while let Some(line) = lines
   409	            .next_line()
   410	            .await
   411	            .map_err(|e| format!("git {what} output unreadable: {e}"))?
   412	        {
   413	            if pick(&line) {
   414	                return Ok(Some(line));
   415	            }
   416	        }
   417	        Ok(None)
   418	    };
   419	    let started = tokio::time::Instant::now();
   420	    match tokio::time::timeout(timeout, read).await {
   421	        Err(_) => {
   422	            kill_group(pid).await;
   423	            Err(GIT_TIMED_OUT.to_string())
   424	        }
   425	        Ok(Ok(None)) => {
   426	            let left = timeout.saturating_sub(started.elapsed());
   427	            match tokio::time::timeout(left, child.wait()).await {
   428	                Ok(Ok(st)) if st.success() => Ok(None),
   429	                Ok(_) => Err(format!("git {what} failed")),
   430	                Err(_) => {
   431	                    kill_group(pid).await;
   432	                    Err(GIT_TIMED_OUT.to_string())
   433	                }
   434	            }
   435	        }
   436	        Ok(found) => {
   437	            kill_group(pid).await;
   438	            found

   527	/// directory (tests run in parallel, so nothing here is process-wide).

   530	    use std::path::{Path, PathBuf};
   531	    use std::sync::Mutex;

   533	
   534	    /// What a test injects for one plugin directory.
   535	    #[derive(Debug, Clone, Default)]
   536	    pub(crate) struct Hooks {
   537	        pub(crate) lock_wait: Option<Duration>,
   538	        pub(crate) store_budget: Option<Duration>,
   539	        pub(crate) size_cap: Option<u64>,
   540	        /// Delay the push's size watcher by this long, and measure only this
   541	        /// often (a fast push then finishes before any measurement).
   542	        pub(crate) size_poll: Option<Duration>,
   543	        /// Panic on the migration thread before anything is migrated.
   544	        pub(crate) panic_at_boot: bool,
   545	        /// `std::process::abort()` once the `building` journal is written
   546	        /// (a crash mid-build; only ever set in a child process).
   547	        pub(crate) abort_in_build: bool,

   549	        /// `sleep <token>` in git's process group and waits on it.
   550	        pub(crate) slow_child: Option<String>,
   551	    }

   553	    static HOOKS: Mutex<Vec<(PathBuf, Hooks)>> = Mutex::new(Vec::new());
   554	
   555	    fn key(plugin: &Path) -> PathBuf {
   556	        std::path::absolute(plugin).unwrap_or_else(|_| plugin.to_path_buf())
   557	    }
   558	
   559	    /// Install `h` for `plugin`, replacing any earlier hooks for it.
   560	    pub(crate) fn set(plugin: &Path, h: Hooks) {
   561	        let k = key(plugin);
   562	        let mut all = HOOKS
   563	            .lock()
   564	            .unwrap_or_else(std::sync::PoisonError::into_inner);
   565	        all.retain(|(p, _)| *p != k);
   566	        all.push((k, h));
   567	    }
   568	
   569	    /// Remove the hooks for `plugin`.
   570	    pub(crate) fn clear(plugin: &Path) {
   571	        let k = key(plugin);
   572	        HOOKS
   573	            .lock()
   574	            .unwrap_or_else(std::sync::PoisonError::into_inner)
   575	            .retain(|(p, _)| *p != k);
   576	    }

   578	    /// The hooks for `plugin` (all off when none are installed).
   579	    pub(crate) fn get(plugin: &Path) -> Hooks {
   580	        let k = key(plugin);
   581	        HOOKS
   582	            .lock()
   583	            .unwrap_or_else(std::sync::PoisonError::into_inner)
   584	            .iter()
   585	            .find(|(p, _)| *p == k)
   586	            .map(|(_, h)| h.clone())
   587	            .unwrap_or_default()
   588	    }

   591	        let h = get(plugin);
   592	        super::Limits {
   593	            lock_wait: h.lock_wait.unwrap_or(base.lock_wait),
   594	            store_budget: h.store_budget.unwrap_or(base.store_budget),
   595	            size_cap: h.size_cap.unwrap_or(base.size_cap),
   596	            size_poll: h.size_poll.map_or(base.size_poll, |d| (d, d)),
   597	        }
   598	    }

   623	/// The stage a migration reached, as its journal records it.
   624	#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]

   669	/// What is at a journal path.
   670	enum JournalRead {
   671	    /// Nothing ("not found").
   672	    Absent,
   673	    /// A regular file holding a journal.
   674	    Present(Journal),
   675	    /// Anything else: a symlink, a directory, a file that cannot be read or
   676	    /// parsed, a check that failed. It gates, and is never acted on.
   677	    Bad(String),
   678	}

   680	/// Read `path` only if it is a regular file, not a symlink: `lstat`, open,
   681	/// then `fstat`, refusing a file whose identity changed in between.
   682	fn read_regular(path: &Path) -> std::io::Result<Vec<u8>> {
   683	    use std::io::Read as _;
   684	    let before = std::fs::symlink_metadata(path)?;
   685	    if !before.file_type().is_file() {
   686	        return Err(std::io::Error::new(
   687	            std::io::ErrorKind::InvalidData,
   688	            "not a regular file",
   689	        ));
   690	    }
   691	    let mut file = std::fs::File::open(path)?;
   692	    let after = file.metadata()?;
   693	    #[cfg(unix)]
   694	    {
   695	        use std::os::unix::fs::MetadataExt as _;
   696	        if (before.dev(), before.ino()) != (after.dev(), after.ino()) {
   697	            return Err(std::io::Error::new(
   698	                std::io::ErrorKind::InvalidData,
   699	                "changed while being read",
   700	            ));
   701	        }
   702	    }
   703	    if !after.is_file() {
   704	        return Err(std::io::Error::new(
   705	            std::io::ErrorKind::InvalidData,
   706	            "not a regular file",
   707	        ));
   708	    }
   709	    let mut out = Vec::new();
   710	    file.read_to_end(&mut out)?;
   711	    Ok(out)
   712	}

   714	/// Read the journal at `path` (see [`JournalRead`]).
   715	fn read_journal(path: &Path) -> JournalRead {
   716	    match std::fs::symlink_metadata(path) {
   717	        Err(e) if e.kind() == std::io::ErrorKind::NotFound => return JournalRead::Absent,
   718	        Err(e) => return JournalRead::Bad(format!("cannot be checked: {}", e.kind())),
   719	        Ok(m) if !m.file_type().is_file() => {
   720	            return JournalRead::Bad("not a regular file".into());
   721	        }
   722	        Ok(_) => {}
   723	    }
   724	    match read_regular(path) {
   725	        Ok(bytes) => match serde_json::from_slice(&bytes) {
   726	            Ok(j) => JournalRead::Present(j),
   727	            Err(e) => JournalRead::Bad(format!("not a journal: {e}")),
   728	        },
   729	        Err(e) => JournalRead::Bad(format!("cannot be read: {e}")),
   730	    }
   731	}

   733	/// Whether a reader must refuse `<owner>/<name>` because of its migration
   734	/// journal: anything at the journal path gates, in any state, `published`
   735	/// included, and whatever its file type. "Not found" is the only answer
   736	/// that lets the reader go on (decision 21). A migrated store is briefly
   737	/// refused between the `published` write and [`finish`], which removes the
   738	/// journal.
   739	pub(crate) async fn journal_gates(plugin_dir: &Path, owner: &str, name: &str) -> bool {
   740	    let Some(path) = journal_path(plugin_dir, owner, name) else {
   741	        return false;
   742	    };
   743	    !matches!(
   744	        tokio::task::spawn_blocking(move || read_journal(&path)).await,
   745	        Ok(JournalRead::Absent)
   746	    )
   747	}

   749	/// Whether any entry exists at the migration journal path of
   750	/// `<owner>/<name>`, in any state and of any file type (the tombstone). An
   751	/// entry that cannot be checked counts as present.

   753	    let Some(path) = journal_path(plugin_dir, owner, name) else {
   754	        return false;
   755	    };
   756	    match std::fs::symlink_metadata(path) {
   757	        Ok(_) => true,
   758	        Err(e) => e.kind() != std::io::ErrorKind::NotFound,
   759	    }
   760	}

   762	/// Migrate every pre-release served store under `plugin_dir`, synchronously.
   763	/// Returns whether the pass ran to completion.
   764	///
   765	/// Runs on a dedicated thread with its own current-thread `tokio` runtime and
   766	/// joins it, so it behaves the same from plain synchronous code, from inside
   767	/// actix's current-thread runtime and from a `#[tokio::test]`: no
   768	/// `block_in_place`, no nested `block_on` on the caller's thread. A failure to
   769	/// migrate one store is logged and leaves that store gated behind its
   770	/// journal; it never fails the caller. `false` (the runtime could not be
   771	/// built, the thread panicked, or a store could not be gated by a journal)
   772	/// tells the caller to refuse every mirror-class store instead.
   773	pub(crate) fn run_at_boot(plugin_dir: &Path) -> bool {
   774	    let plugin = std::path::absolute(plugin_dir).unwrap_or_else(|_| plugin_dir.to_path_buf());
   775	    std::thread::scope(|scope| {
   776	        let worker = scope.spawn(|| {
   777	            #[cfg(test)]
   778	            assert!(
   779	                !test_hooks::get(&plugin).panic_at_boot,
   780	                "test hook: the migration thread panics"
   781	            );
   782	            match tokio::runtime::Builder::new_current_thread()
   783	                .enable_all()
   784	                .build()
   785	            {
   786	                Ok(rt) => rt.block_on(run(&plugin)),
   787	                Err(e) => {
   788	                    tracing::error!(error = %e, "forge: migration runtime not built; every mirror-class store is refused");
   789	                    false
   790	                }
   791	            }
   792	        });
   793	        if let Ok(complete) = worker.join() {
   794	            complete
   795	        } else {
   796	            tracing::error!(
   797	                "forge: the migration thread panicked; every mirror-class store is refused"
   798	            );
   799	            false
   800	        }
   801	    })
   802	}

   804	/// One boot pass: resume every journal, then migrate every store detected as
   805	/// needing it (or that detection could not examine). Serial, one lock at a
   806	/// time. Returns `false` if any store could not be gated by a journal, or
   807	/// the journals or stores could not all be listed.
   808	async fn run(plugin: &Path) -> bool {
   809	    let started = std::time::Instant::now();
   810	    let mut outcomes = Vec::new();
   811	    let mut seen = std::collections::BTreeSet::new();
   812	    let (journals, journals_listed) = journaled(plugin);
   813	    for (owner, name) in journals {
   814	        seen.insert((owner.clone(), name.clone()));
   815	        if journal_class(plugin, &owner, &name).as_deref() == Some("fork") {
   816	            // A fork migration: resumed by the fork pass below.
   817	            continue;
   818	        }
   819	        outcomes.push(migrate_one(plugin, &owner, &name).await);
   820	    }
   821	    let (stores, stores_listed) = served_stores(plugin);
   822	    for (owner, name) in stores {
   823	        if seen.contains(&(owner.clone(), name.clone())) {
   824	            continue;
   825	        }
   826	        if matches!(
   827	            detect(plugin, &owner, &name).await,
   828	            Detected::Skip | Detected::Clean
   829	        ) {
   830	            continue;
   831	        }
   832	        outcomes.push(migrate_one(plugin, &owner, &name).await);
   833	    }
   834	    // Forks of migrated mirror-class stores, after every mirror-class store
   835	    // (each lock released before the next is taken: never two at once).
   836	    let mirror_complete = journals_listed && stores_listed && !outcomes.contains(&Outcome::Ungated);
   837	    let forks = fork::sweep(plugin, mirror_complete).await;
   838	    outcomes.extend(forks.outcomes);
   839	    let count = |want: Outcome| outcomes.iter().filter(|o| **o == want).count();
   840	    let (done, failed, ungated) = (
   841	        count(Outcome::Migrated),
   842	        count(Outcome::Failed),
   843	        count(Outcome::Ungated),
   844	    );
   845	    if done + failed + ungated > 0 {
   846	        tracing::info!(
   847	            migrated = done,
   848	            failed,
   849	            ungated,
   850	            ms = u64::try_from(started.elapsed().as_millis()).unwrap_or(u64::MAX),
   851	            "forge: legacy served stores migrated"
   852	        );
   853	    }
   854	    if ungated > 0 {
   855	        tracing::error!(
   856	            ungated,
   857	            "forge: a store could not be gated by a journal; every mirror-class store is refused"
   858	        );
   859	    }
   860	    if !(journals_listed && stores_listed && forks.listed) {
   861	        tracing::error!(
   862	            "forge: the stores could not all be listed or read; every mirror-class store and every fork is refused"
   863	        );
   864	    }
   865	    ungated == 0 && journals_listed && stores_listed && forks.listed
   866	}

   868	/// The `class` of the journal of `<owner>/<name>`, if one is there and
   869	/// readable.

   871	    match read_journal(&journal_path(plugin, owner, name)?) {
   872	        JournalRead::Present(j) => Some(j.class),

   874	    }

   877	/// What one store's pass came to.
   878	#[derive(Debug, Clone, Copy, PartialEq, Eq)]
   879	enum Outcome {
   880	    Migrated,
   881	    /// Not migrated; a journal gates the store.
   882	    Failed,
   883	    /// Not migrated, and no journal could be written to gate it: the caller
   884	    /// must gate it another way.
   885	    Ungated,
   886	    Skipped,
   887	}

   889	/// The names in directory `dir`, or an error. "Not found" is no names.
   890	fn names_in(dir: &Path) -> Result<Vec<(String, PathBuf)>, String> {
   891	    let entries = match std::fs::read_dir(dir) {
   892	        Ok(e) => e,
   893	        Err(e) if e.kind() == std::io::ErrorKind::NotFound => return Ok(Vec::new()),
   894	        Err(e) => return Err(format!("a directory could not be listed: {}", e.kind())),
   895	    };
   896	    let mut out = Vec::new();
   897	    for e in entries {
   898	        let e = e.map_err(|e| format!("a directory entry could not be read: {}", e.kind()))?;
   899	        out.push((e.file_name().to_string_lossy().into_owned(), e.path()));
   900	    }
   901	    Ok(out)
   902	}

   904	/// Every `(owner, name)` with an entry at its journal path, and whether the
   905	/// listing was complete (every directory listed, every entry read).
   906	fn journaled(plugin: &Path) -> (Vec<(String, String)>, bool) {
   907	    let mut out = Vec::new();
   908	    let mut complete = true;
   909	    let root = plugin.join("mirror-work").join("migrations");
   910	    let owners = names_in(&root).unwrap_or_else(|e| {
   911	        tracing::error!(error = %e, "forge: migration journals not listed");
   912	        complete = false;
   913	        Vec::new()
   914	    });
   915	    for (owner, path) in owners {
   916	        if !valid_name_segment(&owner) {
   917	            continue;
   918	        }
   919	        match dir_state(&path) {
   920	            Ok(true) => {}
   921	            Ok(false) => continue,
   922	            Err(e) => {
   923	                tracing::error!(owner = %owner, error = %e, "forge: migration journals not listed");
   924	                complete = false;
   925	                continue;
   926	            }
   927	        }
   928	        match names_in(&path) {
   929	            Ok(files) => {
   930	                for (file, _) in files {
   931	                    if let Some(name) = file.strip_suffix(".json") {
   932	                        if valid_name_segment(name) {
   933	                            out.push((owner.clone(), name.to_string()));
   934	                        }
   935	                    }
   936	                }
   937	            }
   938	            Err(e) => {
   939	                tracing::error!(owner = %owner, error = %e, "forge: migration journals not listed");
   940	                complete = false;
   941	            }
   942	        }
   943	    }
   944	    out.sort();
   945	    (out, complete)
   946	}

   948	/// Every served `(owner, name)` under `repos/` (directories `<name>.git`,
   949	/// symlinks followed, as the readers do), and whether the listing was
   950	/// complete. Unlike [`crate::repo::list_all`], an error listing a
   951	/// directory, reading an entry or checking an entry's type is reported, never
   952	/// taken for absence: a store the pass cannot see is a store it cannot
   953	/// examine.
   954	fn served_stores(plugin: &Path) -> (Vec<(String, String)>, bool) {
   955	    let mut out = Vec::new();
   956	    let mut complete = true;
   957	    let repos = plugin.join("repos");
   958	    let owners = names_in(&repos).unwrap_or_else(|e| {
   959	        tracing::error!(error = %e, "forge: served repositories not listed");
   960	        complete = false;
   961	        Vec::new()
   962	    });
   963	    for (owner, path) in owners {
   964	        if !valid_name_segment(&owner) {
   965	            continue;
   966	        }
   967	        match dir_state(&path) {
   968	            Ok(true) => {}
   969	            Ok(false) => continue,
   970	            Err(e) => {
   971	                tracing::error!(owner = %owner, error = %e, "forge: served repositories not listed");
   972	                complete = false;
   973	                continue;
   974	            }
   975	        }
   976	        let repos = match names_in(&path) {
   977	            Ok(r) => r,
   978	            Err(e) => {
   979	                tracing::error!(owner = %owner, error = %e, "forge: served repositories not listed");
   980	                complete = false;
   981	                continue;
   982	            }
   983	        };
   984	        for (file, entry) in repos {
   985	            let Some(name) = file.strip_suffix(".git") else {
   986	                continue;
   987	            };
   988	            if !valid_name_segment(name) {
   989	                continue;
   990	            }
   991	            match dir_state(&entry) {
   992	                Ok(true) => out.push((owner.clone(), name.to_string())),
   993	                Ok(false) => {}
   994	                Err(e) => {
   995	                    tracing::error!(owner = %owner, name = %name, error = %e, "forge: served repository not checked");
   996	                    complete = false;
   997	                }
   998	            }
   999	        }
  1000	    }
  1001	    out.sort();
  1002	    (out, complete)
  1003	}

  1005	/// What detection found for one store.
  1006	#[derive(Debug, Clone, PartialEq, Eq)]
  1007	enum Detected {
  1008	    /// Out of scope, or not examined: not a mirror-class name, no store, or
  1009	    /// a marked store whose record is not flagged. Nothing to do, but not
  1010	    /// proof the store is clean.
  1011	    Skip,
  1012	    /// Examined: an unmarked store, every signal checked successfully and
  1013	    /// found negative. The only answer that removes a `detection-error`
  1014	    /// journal.
  1015	    Clean,
  1016	    /// A legacy store: rebuild it.
  1017	    Rebuild,
  1018	    /// Rebuilt and marked by a migration whose report names the store's
  1019	    /// migration id, but the record still carries the flag (a crash after
  1020	    /// the journal was removed, or an engine write in between): finish only.
  1021	    Finish,
  1022	    /// A check could not be made and nothing positive was found: gate it.
  1023	    Error(String),
  1024	}

  1053	/// Whether `p` is a directory, following symlinks as the readers do (an
  1054	/// operator may symlink a store to another disk). "Not found" is `false`;
  1055	/// any other error is an error, never taken for absence.
  1056	fn dir_state(p: &Path) -> Result<bool, String> {
  1057	    match std::fs::metadata(p) {
  1058	        Ok(m) => Ok(m.is_dir()),
  1059	        Err(e) if e.kind() == std::io::ErrorKind::NotFound => Ok(false),
  1060	        Err(e) => Err(format!(
  1061	            "a store directory could not be checked: {}",
  1062	            e.kind()
  1063	        )),
  1064	    }
  1065	}

  1078	/// The migration reports (`<name>.git.<ts>.migration.json`, regular files)
  1079	/// in recovery. "Not found" is no reports; any other error is an error.
  1080	fn reports(recovery_dir: &Path, name: &str) -> Result<Vec<PathBuf>, String> {
  1081	    let entries = match std::fs::read_dir(recovery_dir) {
  1082	        Ok(e) => e,
  1083	        Err(e) if e.kind() == std::io::ErrorKind::NotFound => return Ok(Vec::new()),
  1084	        Err(e) => return Err(format!("the recovery directory: {}", e.kind())),
  1085	    };
  1086	    let prefix = format!("{name}.git.");
  1087	    let mut out = Vec::new();
  1088	    for e in entries {
  1089	        let e = e.map_err(|e| format!("the recovery directory: {}", e.kind()))?;
  1090	        let f = e.file_name();
  1091	        let f = f.to_string_lossy();
  1092	        let is_report = f
  1093	            .strip_prefix(&prefix)
  1094	            .and_then(|rest| rest.strip_suffix(".migration.json"))
  1095	            .is_some_and(all_digits);
  1096	        if is_report {
  1097	            out.push(e.path());
  1098	        }
  1099	    }
  1100	    Ok(out)
  1101	}

  1119	/// Whether `served` carries migration id `id` (and, when `marked`, the
  1120	/// marker as a regular file): the store this migration built is in place. A
  1121	/// fork that had no marker is rebuilt without one, so only its id is
  1122	/// checked.
  1123	fn served_is_ours(served: &Path, id: &str, marked: bool) -> bool {
  1124	    (!marked
  1125	        || std::fs::symlink_metadata(served.join(crate::PUBLICATION_MARKER))
  1126	            .is_ok_and(|m| m.is_file()))
  1127	        && store_migration_id(served).is_some_and(|got| got == id)

  1130	/// Legacy detection for a mirror-class store (64-hex owner). Every
  1131	/// pre-release signal is evaluated independently: any positive is
  1132	/// `Rebuild`, whatever the others' errors; if none is positive and a check
  1133	/// failed, the answer is `Error` (the store is then gated, never left
  1134	/// served).
  1135	async fn detect(plugin: &Path, owner: &str, name: &str) -> Detected {
  1136	    if !is_hex64(owner) || !is_repo_name(name) {
  1137	        return Detected::Skip;
  1138	    }
  1139	    let Some(p) = Paths::of(plugin, owner, name) else {
  1140	        return Detected::Skip;
  1141	    };
  1142	    match dir_state(&p.served) {
  1143	        Ok(true) => {}
  1144	        Ok(false) => return Detected::Skip,
  1145	        Err(e) => return Detected::Error(e),
  1146	    }
  1147	    let record = MirrorStore::new(plugin).load(owner, name);
  1148	    let marked = match std::fs::symlink_metadata(p.served.join(crate::PUBLICATION_MARKER)) {
  1149	        Ok(m) => m.is_file(),
  1150	        Err(e) if e.kind() == std::io::ErrorKind::NotFound => false,
  1151	        Err(e) => return Detected::Error(format!("the marker check failed: {}", e.kind())),
  1152	    };
  1153	    if marked {
  1154	        if !matches!(&record, StoredRecord::Valid(r) if r.awaits_migration) {
  1155	            return Detected::Skip;
  1156	        }
  1157	        // Flagged but marked: finish only if a report names this store's
  1158	        // migration id; otherwise the marker proves nothing, rebuild.
  1159	        let Some(id) = store_migration_id(&p.served) else {
  1160	            return Detected::Rebuild;
  1161	        };
  1162	        return match reports(&p.recovery_dir, name) {
  1163	            Ok(found) if found.iter().any(|r| report_id(r).as_deref() == Some(&id)) => {
  1164	                Detected::Finish
  1165	            }
  1166	            Ok(_) => Detected::Rebuild,
  1167	            Err(e) => Detected::Error(e),
  1168	        };
  1169	    }
  1170	    match &record {
  1171	        StoredRecord::Valid(r) if r.awaits_migration || !r.isolated => return Detected::Rebuild,
  1172	        StoredRecord::Unreadable(_) => return Detected::Rebuild,
  1173	        StoredRecord::Valid(_) | StoredRecord::Missing => {}
  1174	    }
  1175	    let mut error = None;
  1176	    for signal in legacy_traces(&p.served).await {
  1177	        match signal {
  1178	            Ok(true) => return Detected::Rebuild,
  1179	            Ok(false) => {}
  1180	            Err(e) => error = error.or(Some(e)),
  1181	        }
  1182	    }
  1183	    match reports(&p.recovery_dir, name) {
  1184	        Ok(found) if !found.is_empty() => return Detected::Rebuild,
  1185	        Ok(_) => {}
  1186	        Err(e) => error = error.or(Some(e)),
  1187	    }
  1188	    error.map_or(Detected::Clean, Detected::Error)
  1189	}

  1191	/// The pre-release signals of a store, each evaluated on its own:
  1192	/// alternates, `refs/mirror/*`, and `hideRefs` naming them.
  1193	async fn legacy_traces(served: &Path) -> Vec<Result<bool, String>> {
  1194	    let quick = Duration::from_secs(15);
  1195	    let info = served.join("objects").join("info");
  1196	    let mut alternates = Ok(false);
  1197	    for file in ["alternates", "http-alternates"] {
  1198	        match tokio::fs::symlink_metadata(info.join(file)).await {
  1199	            Ok(_) => {
  1200	                alternates = Ok(true);
  1201	                break;
  1202	            }
  1203	            Err(e) if e.kind() == std::io::ErrorKind::NotFound => {}
  1204	            Err(e) => alternates = Err(format!("the alternates check failed: {}", e.kind())),
  1205	        }
  1206	    }
  1207	    let refs = run_in(
  1208	        served,
  1209	        served,
  1210	        &[
  1211	            "for-each-ref",
  1212	            "--count=1",
  1213	            "--format=%(refname)",
  1214	            "refs/mirror",
  1215	        ],
  1216	        None,
  1217	        quick,
  1218	        None,
  1219	    )
  1220	    .await
  1221	    .map(|out| !out.is_empty());
  1222	    let config = run_in(
  1223	        served,
  1224	        served,
  1225	        &["config", "--local", "--list", "-z"],
  1226	        None,
  1227	        quick,
  1228	        None,
  1229	    )
  1230	    .await
  1231	    .map(|out| hides_mirror_refs(&out));
  1232	    vec![alternates, refs, config]
  1233	}

  1241	/// `fsync` a directory, so the entries just created, renamed or removed in

  1255	/// Write `bytes` to `path` and `fsync` it.
  1256	fn write_synced(path: &Path, bytes: &[u8]) -> std::io::Result<()> {
  1257	    use std::io::Write as _;
  1258	    let mut f = std::fs::File::create(path)?;
  1259	    f.write_all(bytes)?;
  1260	    f.sync_all()
  1261	}

  1263	/// Write a journal durably: a temporary file, `fsync`, rename, `fsync` the
  1264	/// directory.
  1265	fn write_journal(path: &Path, j: &Journal) -> Result<(), String> {
  1266	    let parent = path.parent().ok_or("no journal directory")?;
  1267	    std::fs::create_dir_all(parent).map_err(|e| format!("journal directory: {e}"))?;
  1268	    let tmp = path.with_extension("json.tmp");
  1269	    let bytes = serde_json::to_vec_pretty(j).map_err(|e| e.to_string())?;
  1270	    write_synced(&tmp, &bytes).map_err(|e| format!("journal not written: {e}"))?;
  1271	    std::fs::rename(&tmp, path).map_err(|e| format!("journal not written: {e}"))?;
  1272	    sync_dir(parent).map_err(|e| format!("journal not synced: {e}"))
  1273	}
  1274	
  1275	/// Create `path` holding `bytes`, durably, only if nothing is there: a
  1276	/// temporary file, `fsync`, `hard_link` (which, unlike rename, never
  1277	/// replaces), `fsync` the directory. `Ok(false)` when an entry already
  1278	/// exists (it is left as it is).
  1279	fn create_exclusive(path: &Path, bytes: &[u8]) -> Result<bool, String> {
  1280	    let parent = path.parent().ok_or("no parent directory")?;
  1281	    std::fs::create_dir_all(parent).map_err(|e| format!("directory: {e}"))?;
  1282	    let tmp = with_suffix(path, &format!(".{}.tmp", uuid::Uuid::new_v4().simple()));
  1283	    write_synced(&tmp, bytes).map_err(|e| format!("not written: {e}"))?;
  1284	    let linked = std::fs::hard_link(&tmp, path);
  1285	    let _ = std::fs::remove_file(&tmp);
  1286	    match linked {
  1287	        Ok(()) => {
  1288	            sync_dir(parent).map_err(|e| format!("not synced: {e}"))?;
  1289	            Ok(true)
  1290	        }
  1291	        Err(e) if e.kind() == std::io::ErrorKind::AlreadyExists => Ok(false),
  1292	        Err(e) => Err(format!("not written: {e}")),
  1293	    }
  1294	}

  1296	/// Take the store's cross-process lock, polling `try_lock` (off the
  1297	/// runtime) for at most `wait`.
  1298	async fn take_lock(path: PathBuf, wait: Duration) -> std::io::Result<std::fs::File> {
  1299	    tokio::task::spawn_blocking(move || {
  1300	        if let Some(parent) = path.parent() {
  1301	            std::fs::create_dir_all(parent)?;
  1302	        }
  1303	        let file = std::fs::OpenOptions::new()
  1304	            .create(true)
  1305	            .write(true)
  1306	            .truncate(false)
  1307	            .open(&path)?;
  1308	        let deadline = std::time::Instant::now() + wait;
  1309	        loop {
  1310	            match file.try_lock() {
  1311	                Ok(()) => return Ok(file),
  1312	                Err(std::fs::TryLockError::WouldBlock) => {
  1313	                    if std::time::Instant::now() >= deadline {
  1314	                        return Err(std::io::Error::new(
  1315	                            std::io::ErrorKind::TimedOut,
  1316	                            "another process held it past the deadline",
  1317	                        ));
  1318	                    }
  1319	                    std::thread::sleep(Duration::from_millis(50));
  1320	                }
  1321	                Err(std::fs::TryLockError::Error(e)) => return Err(e),
  1322	            }
  1323	        }
  1324	    })
  1325	    .await
  1326	    .map_err(std::io::Error::other)?
  1327	}

  1329	/// A fresh recovery stem `<name>.git.<ts>` that names nothing yet.
  1330	fn fresh_recovery(plugin: &Path, p: &Paths, name: &str) -> (u64, String) {
  1331	    let mut ts = now_secs();
  1332	    loop {
  1333	        let stem = format!("{name}.git.{ts}");
  1334	        let taken = std::fs::symlink_metadata(p.recovery_dir.join(&stem)).is_ok()
  1335	            || std::fs::symlink_metadata(p.recovery_dir.join(format!("{stem}.migration.json")))
  1336	                .is_ok();
  1337	        if !taken {
  1338	            return (ts, relative(plugin, &p.recovery_dir.join(&stem)));
  1339	        }
  1340	        ts += 1;
  1341	    }
  1342	}

  1371	/// Gate a store with a `failed` journal holding `reason` and no attempt
  1372	/// counted, created exclusively (an existing journal is never replaced, and
  1373	/// already gates). `Ungated` when nothing could be written.
  1374	fn gate(plugin: &Path, p: &Paths, owner: &str, name: &str, reason: &str, kind: &Kind) -> Outcome {
  1375	    let j = new_journal(
  1376	        plugin,
  1377	        p,
  1378	        name,
  1379	        Stage::Failed,
  1380	        Some(redact(plugin, reason)),
  1381	        kind,
  1382	    );
  1383	    let written = serde_json::to_vec_pretty(&j)
  1384	        .map_err(|e| e.to_string())
  1385	        .and_then(|bytes| create_exclusive(&p.journal, &bytes));
  1386	    match written {
  1387	        Ok(_) => {
  1388	            tracing::error!(owner = %owner, name = %name, reason = %redact(plugin, reason), "forge: store gated without migrating");
  1389	            Outcome::Failed
  1390	        }
  1391	        Err(e) => {
  1392	            tracing::error!(owner = %owner, name = %name, error = %redact(plugin, &e), "forge: gate journal not written");
  1393	            Outcome::Ungated
  1394	        }
  1395	    }
  1396	}

  1398	/// The journal's recovery (and staging) path, if each lies where it must:
  1399	/// `mirror-recovery/<owner>/<name>.git.<digits>` and
  1400	/// `mirror-work/staging/<owner>/<name>.git.<alphanumerics>`, as plain
  1401	/// relative components, with the parent directory (when it exists)
  1402	/// canonicalising to the same place under the canonical plugin directory.
  1403	fn contained(plugin: &Path, owner: &str, name: &str, j: &Journal) -> Result<PathBuf, String> {
  1404	    fn check(
  1405	        plugin: &Path,
  1406	        rel: &str,
  1407	        base: &[&str],
  1408	        owner: &str,
  1409	        leaf_ok: impl Fn(&str) -> bool,
  1410	    ) -> Result<PathBuf, String> {
  1411	        use std::path::Component;
  1412	        let parts: Vec<&str> = Path::new(rel)
  1413	            .components()
  1414	            .map(|c| match c {
  1415	                Component::Normal(s) => s.to_str().ok_or(()),
  1416	                _ => Err(()),
  1417	            })
  1418	            .collect::<Result<_, _>>()
  1419	            .map_err(|()| format!("journal path {rel:?} is not plain"))?;
  1420	        let ok = parts.len() == base.len() + 2
  1421	            && parts[..base.len()] == *base
  1422	            && parts[base.len()] == owner
  1423	            && leaf_ok(parts[base.len() + 1]);
  1424	        if !ok {
  1425	            return Err(format!(
  1426	                "journal path {rel:?} is outside {}",
  1427	                base.join("/")
  1428	            ));
  1429	        }
  1430	        let parent: PathBuf = base
  1431	            .iter()
  1432	            .fold(plugin.to_path_buf(), |d, s| d.join(s))
  1433	            .join(owner);
  1434	        if let Ok(real) = std::fs::canonicalize(&parent) {
  1435	            let root =
  1436	                std::fs::canonicalize(plugin).map_err(|e| format!("plugin directory: {e}"))?;
  1437	            let want = base.iter().fold(root, |d, s| d.join(s)).join(owner);
  1438	            if real != want {
  1439	                return Err(format!(
  1440	                    "journal path {rel:?} resolves outside {}",
  1441	                    base.join("/")
  1442	                ));
  1443	            }
  1444	        }
  1445	        Ok(plugin.join(rel))
  1446	    }
  1447	    let stem = format!("{name}.git.");
  1448	    let recovery = check(plugin, &j.recovery, &["mirror-recovery"], owner, |leaf| {
  1449	        leaf.strip_prefix(&stem).is_some_and(all_digits)
  1450	    })?;
  1451	    if let Some(s) = &j.staging {
  1452	        check(plugin, s, &["mirror-work", "staging"], owner, |leaf| {
  1453	            leaf.strip_prefix(&stem)
  1454	                .is_some_and(|u| !u.is_empty() && u.bytes().all(|b| b.is_ascii_alphanumeric()))
  1455	        })?;
  1456	    }
  1457	    Ok(recovery)
  1458	}

  1473	/// Migrate (or resume, or finish) one store of `kind` under its lock.
  1474	async fn migrate_store(plugin: &Path, owner: &str, name: &str, kind: &Kind) -> Outcome {
  1475	    let Some(p) = Paths::of(plugin, owner, name) else {
  1476	        return Outcome::Skipped;
  1477	    };
  1478	    let limits = Limits::for_plugin(plugin);
  1479	    let _lock = match take_lock(p.lock.clone(), limits.lock_wait).await {
  1480	        Ok(f) => f,
  1481	        // No lock: still gate the store (decision 21; a journal only adds
  1482	        // denial), never replacing a journal that is there.
  1483	        Err(e) => {
  1484	            return gate(
  1485	                plugin,
  1486	                &p,
  1487	                owner,
  1488	                name,
  1489	                &format!("the migration lock was not taken: {e}"),
  1490	                kind,
  1491	            );
  1492	        }
  1493	    };
  1494	    // Re-read everything under the lock: another instance may have finished.
  1495	    let journal = match read_journal(&p.journal) {
  1496	        JournalRead::Present(j) if j.class != kind.class() => {
  1497	            // Another pass owns it (a mirror journal seen by the fork pass,
  1498	            // or the reverse): it gates, and is left alone here.
  1499	            tracing::warn!(owner = %owner, name = %name, class = %j.class, "forge: migration journal of another class; store stays gated");
  1500	            return Outcome::Failed;
  1501	        }
  1502	        JournalRead::Present(j) => j,
  1503	        JournalRead::Bad(e) => {
  1504	            tracing::error!(owner = %owner, name = %name, error = %e, "forge: migration journal unusable; store stays gated");
  1505	            return Outcome::Failed;
  1506	        }
  1507	        JournalRead::Absent => match detect_for(plugin, owner, name, kind).await {
  1508	            Detected::Skip | Detected::Clean => return Outcome::Skipped,
  1509	            Detected::Finish => return finished(plugin, &p, owner, name),
  1510	            Detected::Error(e) => {
  1511	                return gate(
  1512	                    plugin,
  1513	                    &p,
  1514	                    owner,
  1515	                    name,
  1516	                    &format!("{DETECTION_ERROR}: {e}"),
  1517	                    kind,
  1518	                );
  1519	            }
  1520	            Detected::Rebuild => {
  1521	                // Persist the journal before any branch below can refuse
  1522	                // the store: every `Failed` from here on relies on a
  1523	                // journal on disk to gate it.
  1524	                let j = new_journal(plugin, &p, name, Stage::Building, None, kind);
  1525	                if let Err(e) = write_journal(&p.journal, &j) {
  1526	                    tracing::error!(owner = %owner, name = %name, error = %redact(plugin, &e), "forge: migration journal not written; store not migrated");
  1527	                    return Outcome::Ungated;
  1528	                }
  1529	                j
  1530	            }
  1531	        },
  1532	    };
  1533	    let recovery = match contained(plugin, owner, name, &journal) {
  1534	        Ok(r) => r,
  1535	        Err(e) => {
  1536	            tracing::error!(owner = %owner, name = %name, error = %redact(plugin, &e), "forge: migration journal refused; store stays gated");
  1537	            return Outcome::Failed;
  1538	        }
  1539	    };
  1540	    if journal.state == Stage::Failed
  1541	        && journal
  1542	            .reason
  1543	            .as_deref()
  1544	            .is_some_and(|r| r.starts_with(DETECTION_ERROR))
  1545	    {
  1546	        // A store gated because it could not be examined: examine it again.
  1547	        match detect_for(plugin, owner, name, kind).await {
  1548	            Detected::Clean => {
  1549	                return match std::fs::remove_file(&p.journal) {
  1550	                    Ok(()) => {
  1551	                        let _ = p.journal.parent().map(sync_dir);
  1552	                        tracing::info!(owner = %owner, name = %name, "forge: store examined and clean; gate removed");
  1553	                        Outcome::Skipped
  1554	                    }
  1555	                    Err(e) => {
  1556	                        tracing::error!(owner = %owner, name = %name, error = %e, "forge: gate journal not removed");
  1557	                        Outcome::Failed
  1558	                    }
  1559	                };
  1560	            }
  1561	            Detected::Error(e) => {
  1562	                tracing::warn!(owner = %owner, name = %name, error = %redact(plugin, &e), "forge: store still cannot be examined; stays gated");
  1563	                return Outcome::Failed;
  1564	            }
  1565	            Detected::Skip => {
  1566	                tracing::warn!(owner = %owner, name = %name, "forge: store not examined; its gate stays");
  1567	                return Outcome::Failed;
  1568	            }
  1569	            Detected::Finish => return finished(plugin, &p, owner, name),
  1570	            Detected::Rebuild => {}
  1571	        }
  1572	    }
  1573	    if served_is_ours(&p.served, &journal.id, kind.mirror_config()) {
  1574	        // The rebuilt store is in place (a crash after the second rename,
  1575	        // or after the `published` write): publish and finish, never
  1576	        // rebuild it. A journal in any state, `published` included, whose
  1577	        // id the served store does not carry is never finished.
  1578	        return publish(plugin, &p, owner, name, journal);
  1579	    }
  1580	    // Once the journal reached `moved` the old store is only ever read
  1581	    // from recovery, whatever the `moved` field says.
  1582	    let was_moved = journal.moved || matches!(journal.state, Stage::Moved | Stage::Published);
  1583	    if journal.attempts >= MAX_ATTEMPTS {
  1584	        tracing::warn!(owner = %owner, name = %name, attempts = journal.attempts, "forge: migration gave up; store stays gated");
  1585	        return Outcome::Failed;
  1586	    }
  1587	    let (served_present, recovery_present) = match (dir_state(&p.served), dir_state(&recovery)) {
  1588	        (Ok(s), Ok(r)) => (s, r),
  1589	        (Err(e), _) | (_, Err(e)) => {
  1590	            // The journal stays and gates; nothing is moved or rebuilt.
  1591	            tracing::error!(owner = %owner, name = %name, error = %e, "forge: migration paths not checked; store stays gated");
  1592	            return Outcome::Failed;
  1593	        }
  1594	    };
  1595	    let moved = match (served_present, recovery_present) {
  1596	        (true, true) => {
  1597	            // Something created the store in the gap despite the tombstone:
  1598	            // never overwrite it, never read it as the old store. Set
  1599	            // staging aside and leave the journal.
  1600	            if let Some(s) = journal.staging.as_deref().map(|s| plugin.join(s)) {
  1601	                if is_dir(&s) {
  1602	                    let _ = std::fs::rename(&s, with_suffix(&recovery, ".rebuilt"));
  1603	                }
  1604	            }
  1605	            tracing::error!(owner = %owner, name = %name, "forge: a store appeared during migration; left for the operator");
  1606	            return Outcome::Failed;
  1607	        }
  1608	        (true, false) if was_moved => {
  1609	            return fail(
  1610	                plugin,
  1611	                &p,
  1612	                owner,
  1613	                name,
  1614	                journal,
  1615	                "the old store was moved but its recovery copy is gone",
  1616	            );
  1617	        }
  1618	        (true, false) => false,
  1619	        (false, true) => true,
  1620	        (false, false) => {
  1621	            return fail(
  1622	                plugin,
  1623	                &p,
  1624	                owner,
  1625	                name,
  1626	                journal,
  1627	                "neither the served store nor its recovery copy exists",
  1628	            );
  1629	        }
  1630	    };
  1631	    if let Kind::Fork(plan) = kind {
  1632	        if let Some(why) = plan.gate() {
  1633	            // The fork's ancestors are not all known: with no complete held
  1634	            // set to filter against, a rebuild could publish a ref reaching
  1635	            // held. The journal is on disk and gates.
  1636	            tracing::warn!(owner = %owner, name = %name, reason = %redact(plugin, why), "forge: fork not rebuilt; its ancestors cannot be checked; store stays gated");
  1637	            return Outcome::Failed;
  1638	        }
  1639	    }
  1640	    rebuild(
  1641	        plugin, &p, owner, name, journal, &recovery, moved, limits, kind,
  1642	    )
  1643	    .await
  1644	}

  1646	/// `finish`, logged.
  1647	fn finished(plugin: &Path, p: &Paths, owner: &str, name: &str) -> Outcome {
  1648	    match finish(plugin, p, owner, name) {
  1649	        Ok(()) => Outcome::Migrated,
  1650	        Err(e) => {
  1651	            tracing::error!(owner = %owner, name = %name, error = %redact(plugin, &e), "forge: migration not finished");
  1652	            gated_or_ungated(plugin, owner, name)
  1653	        }
  1654	    }
  1655	}

  1657	/// `Failed` when a journal is on disk to gate the store, else `Ungated`

  1660	    if journal_exists(plugin, owner, name) {
  1661	        Outcome::Failed
  1662	    } else {
  1663	        Outcome::Ungated
  1664	    }

  1667	/// The rebuilt store is in `repos/`: journal `published`, then finish.
  1668	fn publish(plugin: &Path, p: &Paths, owner: &str, name: &str, mut j: Journal) -> Outcome {
  1669	    if j.state != Stage::Published {
  1670	        j.state = Stage::Published;
  1671	        if let Err(e) = write_journal(&p.journal, &j) {
  1672	            tracing::error!(owner = %owner, name = %name, error = %redact(plugin, &e), "forge: migration journal not written");
  1673	        }
  1674	    }
  1675	    finished(plugin, p, owner, name)
  1676	}

  1701	/// Record a failed attempt in the journal (the attempt was counted when it
  1702	/// started); the store stays gated.
  1703	fn fail(plugin: &Path, p: &Paths, owner: &str, name: &str, mut j: Journal, why: &str) -> Outcome {
  1704	    let why = redact(plugin, why);
  1705	    j.state = Stage::Failed;
  1706	    j.reason = Some(why.clone());
  1707	    if let Err(e) = write_journal(&p.journal, &j) {
  1708	        tracing::error!(owner = %owner, name = %name, error = %e, "forge: migration journal not written");
  1709	    }
  1710	    tracing::error!(owner = %owner, name = %name, attempts = j.attempts, error = %why, "forge: migration failed; store stays gated");
  1711	    gated_or_ungated(plugin, owner, name)
  1712	}

  1714	/// Remove every staging store of `<name>` (`<name>.git.<alphanumerics>`;
  1715	/// safe under the lock: the engine builds staging under the same lock).
  1716	async fn clear_staging(staging_dir: &Path, name: &str) {
  1717	    let Ok(mut entries) = tokio::fs::read_dir(staging_dir).await else {
  1718	        return;
  1719	    };
  1720	    let prefix = format!("{name}.git.");
  1721	    while let Ok(Some(e)) = entries.next_entry().await {
  1722	        let f = e.file_name().to_string_lossy().into_owned();
  1723	        let ours = f
  1724	            .strip_prefix(&prefix)
  1725	            .is_some_and(|u| !u.is_empty() && u.bytes().all(|b| b.is_ascii_alphanumeric()));
  1726	        if ours {
  1727	            if let Err(err) = tokio::fs::remove_dir_all(e.path()).await {
  1728	                tracing::warn!(error = %err, "forge: stale staging store not removed");
  1729	            }
  1730	        }
  1731	    }
  1732	}

  1734	tokio::task_local! {
  1735	    /// The process groups (leader pids) a migration build has spawned and
  1736	    /// not yet seen finish, so a budget timeout can kill all of them.
  1737	    static GROUPS: std::sync::Arc<std::sync::Mutex<Vec<u32>>>;
  1738	}

  1740	/// Note a spawned process group, inside a build.
  1741	fn note_group(pid: Option<u32>) {
  1742	    if let Some(pid) = pid {
  1743	        let _ = GROUPS.try_with(|g| {
  1744	            g.lock()
  1745	                .unwrap_or_else(std::sync::PoisonError::into_inner)
  1746	                .push(pid);
  1747	        });
  1748	    }
  1749	}

  1751	/// Forget a process group that finished normally, inside a build.
  1752	fn forget_group(pid: Option<u32>) {
  1753	    if let Some(pid) = pid {
  1754	        let _ = GROUPS.try_with(|g| {
  1755	            g.lock()
  1756	                .unwrap_or_else(std::sync::PoisonError::into_inner)
  1757	                .retain(|p| *p != pid);
  1758	        });
  1759	    }
  1760	}

  1762	/// Rebuild one store from its old store (`source`: in `repos/`, or already
  1763	/// moved to `recovery`), verify, report, swap and finish.
  1764	#[allow(clippy::too_many_arguments)]
  1765	async fn rebuild(
  1766	    plugin: &Path,
  1767	    p: &Paths,
  1768	    owner: &str,
  1769	    name: &str,
  1770	    mut j: Journal,
  1771	    recovery: &Path,
  1772	    moved: bool,
  1773	    limits: Limits,
  1774	    kind: &Kind,
  1775	) -> Outcome {
  1776	    let started = std::time::Instant::now();
  1777	    let source = if moved {
  1778	        recovery.to_path_buf()
  1779	    } else {
  1780	        p.served.clone()
  1781	    };
  1782	    clear_staging(&p.staging_dir, name).await;
  1783	    let staging = p
  1784	        .staging_dir
  1785	        .join(format!("{name}.git.{}", uuid::Uuid::new_v4().simple()));
  1786	    // The attempt counts now, before anything can crash.
  1787	    j.attempts = j.attempts.saturating_add(1);
  1788	    j.state = Stage::Building;
  1789	    j.moved = moved;
  1790	    j.reason = None;
  1791	    j.staging = Some(relative(plugin, &staging));
  1792	    if let Err(e) = write_journal(&p.journal, &j) {
  1793	        tracing::error!(owner = %owner, name = %name, error = %e, "forge: migration journal not written; store not migrated");
  1794	        // A journal may already gate the store; if none does, the caller
  1795	        // must gate it another way.
  1796	        return gated_or_ungated(plugin, owner, name);
  1797	    }
  1798	    #[cfg(test)]
  1799	    if test_hooks::get(plugin).abort_in_build {
  1800	        std::process::abort();
  1801	    }
  1802	    let record_bytes = match MirrorStore::new(plugin).load(owner, name) {
  1803	        StoredRecord::Unreadable(_) => MirrorStore::new(plugin)
  1804	            .file(owner, name)
  1805	            .map(|f| read_regular(&f).map_err(|e| e.kind().to_string())),
  1806	        _ => None,
  1807	    };
  1808	    let groups = std::sync::Arc::new(std::sync::Mutex::new(Vec::new()));
  1809	    let attempt = GROUPS.scope(
  1810	        std::sync::Arc::clone(&groups),
  1811	        tokio::time::timeout(
  1812	            limits.store_budget,
  1813	            build(
  1814	                plugin,
  1815	                &source,
  1816	                &staging,
  1817	                limits.size_cap,
  1818	                limits.size_poll,
  1819	                kind,
  1820	            ),
  1821	        ),
  1822	    );
  1823	    let built = match attempt.await {
  1824	        Ok(Ok(b)) => b,
  1825	        Ok(Err(e)) => {
  1826	            remove_dir(&staging).await;
  1827	            return fail(plugin, p, owner, name, j, &e);
  1828	        }
  1829	        Err(_) => {
  1830	            let left: Vec<u32> = std::mem::take(
  1831	                &mut *groups
  1832	                    .lock()
  1833	                    .unwrap_or_else(std::sync::PoisonError::into_inner),
  1834	            );
  1835	            for pid in left {
  1836	                kill_group(Some(pid)).await;
  1837	            }
  1838	            remove_dir(&staging).await;
  1839	            return fail(
  1840	                plugin,
  1841	                p,
  1842	                owner,
  1843	                name,
  1844	                j,
  1845	                "the migration ran past its time budget",
  1846	            );
  1847	        }
  1848	    };
  1849	    // The marker: always for a mirror-class store and a followed fork; for a
  1850	    // fork, only if the old fork had one.
  1851	    let marker = kind.mirror_config()
  1852	        || std::fs::symlink_metadata(source.join(crate::PUBLICATION_MARKER))
  1853	            .is_ok_and(|m| m.is_file());
  1854	    if let Err(e) = seal(&staging, &j.id, marker) {
  1855	        remove_dir(&staging).await;
  1856	        return fail(plugin, p, owner, name, j, &e);
  1857	    }
  1858	    j.state = Stage::Verified;
  1859	    if let Err(e) = write_journal(&p.journal, &j) {
  1860	        remove_dir(&staging).await;
  1861	        return fail(plugin, p, owner, name, j, &e);
  1862	    }
  1863	    if let Err(e) = write_report(
  1864	        plugin,
  1865	        recovery,
  1866	        owner,
  1867	        name,
  1868	        &j.id,
  1869	        &built,
  1870	        record_bytes,
  1871	        kind,
  1872	    ) {
  1873	        remove_dir(&staging).await;
  1874	        return fail(plugin, p, owner, name, j, &e);
  1875	    }
  1876	    if !moved {
  1877	        let renamed = std::fs::create_dir_all(&p.recovery_dir)
  1878	            .and_then(|()| std::fs::rename(&p.served, recovery))
  1879	            .and_then(|()| sync_dir(&p.recovery_dir))
  1880	            .and_then(|()| p.served.parent().map_or(Ok(()), sync_dir));
  1881	        if let Err(e) = renamed {
  1882	            if is_dir(&p.served) {
  1883	                remove_dir(&staging).await;
  1884	                return fail(
  1885	                    plugin,
  1886	                    p,
  1887	                    owner,
  1888	                    name,
  1889	                    j,
  1890	                    &format!("the old store was not moved: {e}"),
  1891	                );
  1892	            }
  1893	            tracing::error!(owner = %owner, name = %name, error = %e, "forge: old store moved but not synced");
  1894	        }
  1895	    }
  1896	    // Written before the second rename on every path (normal and resumed):
  1897	    // a crash after it is resolved by the store's migration id.
  1898	    j.state = Stage::Moved;
  1899	    j.moved = true;
  1900	    if let Err(e) = write_journal(&p.journal, &j) {
  1901	        tracing::error!(owner = %owner, name = %name, error = %e, "forge: migration journal not written");
  1902	    }
  1903	    let placed = p
  1904	        .served
  1905	        .parent()
  1906	        .map_or(Ok(()), std::fs::create_dir_all)
  1907	        .and_then(|()| std::fs::rename(&staging, &p.served))
  1908	        .and_then(|()| p.served.parent().map_or(Ok(()), sync_dir));
  1909	    if let Err(e) = placed {
  1910	        if !served_is_ours(&p.served, &j.id, kind.mirror_config()) {
  1911	            return fail(
  1912	                plugin,
  1913	                p,
  1914	                owner,
  1915	                name,
  1916	                j,
  1917	                &format!("the rebuilt store was not placed: {e}"),
  1918	            );
  1919	        }
  1920	    }
  1921	    let outcome = publish(plugin, p, owner, name, j);
  1922	    if outcome == Outcome::Migrated {
  1923	        tracing::info!(
  1924	            owner = %owner,
  1925	            name = %name,
  1926	            ms = u64::try_from(started.elapsed().as_millis()).unwrap_or(u64::MAX),
  1927	            copied = built.copied.len(),
  1928	            dropped = built.dropped.len(),
  1929	            held = built.held.len(),
  1930	            "forge: migrated"
  1931	        );
  1932	    }
  1933	    outcome
  1934	}

  1936	/// Write the migration id, then (when `marked`) the marker, into staging,
  1937	/// durably.
  1938	fn seal(staging: &Path, id: &str, marked: bool) -> Result<(), String> {
  1939	    let marker = crate::PUBLICATION_MARKER;
  1940	    write_synced(
  1941	        &staging.join(MIGRATION_ID_FILE),
  1942	        format!("{id}\n").as_bytes(),
  1943	    )
  1944	    .map_err(|e| format!("could not write the migration id: {e}"))?;
  1945	    if !marked {
  1946	        return sync_dir(staging).map_err(|e| format!("could not sync staging: {e}"));
  1947	    }
  1948	    let tmp = staging.join(format!("{marker}.tmp"));
  1949	    write_synced(&tmp, format!("{marker}\n").as_bytes())
  1950	        .and_then(|()| std::fs::rename(&tmp, staging.join(marker)))
  1951	        .and_then(|()| sync_dir(staging))
  1952	        .map_err(|e| format!("could not write the publication marker: {e}"))
  1953	}

  1958	            tracing::warn!(error = %e, "forge: staging store not removed");
  1959	        }
  1960	    }

  1963	/// Steps 10 to 12: clear the record's awaits-migration flag (editing the
  1964	/// JSON, every other field unchanged), wipe the candidate, delete the
  1965	/// journal. An unreadable record is left as it is.
  1966	fn finish(plugin: &Path, p: &Paths, owner: &str, name: &str) -> Result<(), String> {
  1967	    let store = MirrorStore::new(plugin);
  1968	    if let StoredRecord::Valid(r) = store.load(owner, name) {
  1969	        if r.awaits_migration {
  1970	            let file = store.file(owner, name).ok_or("unsafe record key")?;
  1971	            let bytes = read_regular(&file).map_err(|e| format!("record not read: {e}"))?;
  1972	            let mut v: serde_json::Value =
  1973	                serde_json::from_slice(&bytes).map_err(|e| format!("record not parsed: {e}"))?;
  1974	            if let Some(o) = v.as_object_mut() {
  1975	                o.remove(AWAITS_MIGRATION_KEY);
  1976	            }
  1977	            let tmp = file.with_extension("json.tmp");
  1978	            let out = serde_json::to_vec_pretty(&v).map_err(|e| e.to_string())?;
  1979	            write_synced(&tmp, &out).map_err(|e| format!("record not written: {e}"))?;
  1980	            std::fs::rename(&tmp, &file).map_err(|e| format!("record not written: {e}"))?;
  1981	            if let Some(dir) = file.parent() {
  1982	                sync_dir(dir).map_err(|e| format!("record not synced: {e}"))?;
  1983	            }
  1984	        }
  1985	    }
  1986	    if let Err(e) = std::fs::remove_dir_all(&p.candidate) {
  1987	        if e.kind() != std::io::ErrorKind::NotFound {
  1988	            tracing::warn!(owner = %owner, name = %name, error = %e, "forge: candidate not removed after migration");
  1989	        }
  1990	    }
  1991	    match std::fs::remove_file(&p.journal) {
  1992	        Ok(()) => {
  1993	            let _ = p.journal.parent().map(sync_dir);
  1994	            Ok(())
  1995	        }
  1996	        Err(e) if e.kind() == std::io::ErrorKind::NotFound => Ok(()),
  1997	        Err(e) => Err(format!("journal not removed: {e}")),
  1998	    }
  1999	}

  2012	/// What [`build`] made.
  2013	#[derive(Debug, Default)]
  2014	struct Built {
  2015	    /// Refs copied into staging, by name.
  2016	    copied: BTreeMap<String, String>,
  2017	    /// Refs left out.
  2018	    dropped: Vec<DroppedRef>,
  2019	    /// The held set, sorted.
  2020	    held: Vec<String>,
  2021	    /// Every object of the source absent from staging, sorted.
  2022	    dropped_objects: Vec<String>,
  2023	    /// The `HEAD` set in staging.

  2027	/// Whether `r` is a ref name safe on a push command line. The names come from
  2028	/// `for-each-ref`, so git already accepted them; this refuses anything that
  2029	/// could be read as an option or a refspec modifier all the same.
  2030	fn safe_ref(r: &str) -> bool {
  2031	    r.starts_with("refs/")
  2032	        && r.len() <= 1024
  2033	        && !r.ends_with('/')
  2034	        && !r.ends_with('.')
  2035	        && !r.ends_with(".lock")
  2036	        && !r.contains("..")
  2037	        && !r.contains("//")
  2038	        && !r.contains("/.")
  2039	        && !r.contains("@{")
  2040	        && r.bytes().all(|b| {
  2041	            b > b' ' && b != 0x7f && !matches!(b, b'~' | b'^' | b':' | b'?' | b'*' | b'[' | b'\\')
  2042	        })
  2043	}
  2044	
  2045	fn is_sha40(s: &str) -> bool {
  2046	    s.len() == 40
  2047	        && s.bytes()
  2048	            .all(|b| b.is_ascii_digit() || (b'a'..=b'f').contains(&b))
  2049	}
  2050	
  2051	/// Whether `r` is a root: a branch or a tag.
  2052	fn is_root(r: &str) -> bool {
  2053	    r.starts_with("refs/heads/") || r.starts_with("refs/tags/")
  2054	}

  2056	/// One `for-each-ref` line, `<sha> <name>`: the name `None` when it is not
  2057	/// UTF-8.
  2058	fn parse_ref_line(line: &[u8]) -> Option<(String, Option<String>, String)> {
  2059	    let at = line.iter().position(|b| *b == b' ')?;
  2060	    let sha = String::from_utf8_lossy(&line[..at]).into_owned();
  2061	    let raw = &line[at + 1..];
  2062	    let name = std::str::from_utf8(raw).ok().map(str::to_string);
  2063	    Some((sha, name, String::from_utf8_lossy(raw).into_owned()))
  2064	}

  2066	/// `^<sha>` lines for `rev-list --stdin`: the roots, excluded.
  2067	fn exclude_input(roots: &[String]) -> Vec<u8> {
  2068	    let mut input = Vec::with_capacity(roots.len() * 42);
  2069	    for sha in roots {
  2070	        input.push(b'^');
  2071	        input.extend_from_slice(sha.as_bytes());
  2072	        input.push(b'\n');
  2073	    }
  2074	    input
  2075	}

  2077	/// Steps 3 to 7 and the dropped set: initialise staging (the fixed served
  2078	/// config for a mirror-class store or a followed fork, an allow-list of the
  2079	/// old config for a fork), choose the refs, push them by SHA from `source`
  2080	/// under the size cap, set `HEAD`, verify, and list what was left behind.
  2081	///
  2082	/// Mirror class: the roots R are the branches and tags that will be copied
  2083	/// (safe names, valid SHAs). The held set H is every object any ref of
  2084	/// `source` reaches that R does not ([`held_set`]). A ref outside R is
  2085	/// copied only if it reaches nothing in H, so the copy holds R's closure and
  2086	/// nothing else. A followed fork first drops any root that reaches the
  2087	/// inherited held set (the union of its mirror-class ancestors' `.held`
  2088	/// files). A fork copies every ref but `refs/mirror/*` and
  2089	/// `refs/replace/*`, each one only if it reaches nothing in the inherited
  2090	/// held set beyond the ancestors' roots it holds; every copied ref is then a
  2091	/// root of the rebuild.
  2092	async fn build(
  2093	    plugin: &Path,
  2094	    source: &Path,
  2095	    staging: &Path,
  2096	    size_cap: u64,
  2097	    size_poll: SizePoll,
  2098	    kind: &Kind,
  2099	) -> Result<Built, String> {
  2100	    init_bare(staging).await?;
  2101	    if kind.mirror_config() {
  2102	        write_served_config(staging).await?;
  2103	        keep_parent(source, staging).await?;
  2104	    }
  2105	    #[cfg(test)]
  2106	    if let Some(token) = test_hooks::get(plugin).slow_child {
  2107	        let alias = format!("alias.b1slow=!sleep {token} & sleep {token}");
  2108	        run_in(
  2109	            source,
  2110	            source,
  2111	            &["-c", &alias, "b1slow"],
  2112	            None,
  2113	            STORE_BUDGET,
  2114	            None,
  2115	        )
  2116	        .await?;
  2117	    }
  2118	    #[cfg(not(test))]
  2119	    let _ = plugin;
  2120	    let listing = run_in(
  2121	        source,
  2122	        source,
  2123	        &["for-each-ref", "--format=%(objectname) %(refname)"],
  2124	        None,
  2125	        STORE_BUDGET,
  2126	        None,
  2127	    )
  2128	    .await?;
  2129	    let refs: Vec<(String, Option<String>, String)> = listing
  2130	        .split(|b| *b == b'\n')
  2131	        .filter(|l| !l.is_empty())
  2132	        .filter_map(parse_ref_line)
  2133	        .collect();
  2134	    let mut built = Built::default();
  2135	    // What verification checks staging against: the objects that must be
  2136	    // absent, and the roots whose closure staging must lie within.
  2137	    let (check_held, roots) = match kind {
  2138	        Kind::Mirror => select_mirror(source, refs, &mut built, None).await?,
  2139	        Kind::Fork(plan) => {
  2140	            let inherited = fork::inherited_held(plan)?;
  2141	            let ancestor_roots = fork::present_roots(source, plan).await?;
  2142	            if plan.followed() {
  2143	                let (own, roots) = select_mirror(
  2144	                    source,
  2145	                    refs,
  2146	                    &mut built,
  2147	                    Some((&inherited, &ancestor_roots)),
  2148	                )
  2149	                .await?;
  2150	                (own.union(&inherited).cloned().collect(), roots)
  2151	            } else {
  2152	                fork::select(source, refs, &mut built, &inherited, &ancestor_roots).await?;
  2153	                let mut roots: Vec<String> = built.copied.values().cloned().collect();
  2154	                roots.sort();
  2155	                roots.dedup();
  2156	                (inherited, roots)
  2157	            }
  2158	        }
  2159	    };
  2160	    push_refs(source, staging, &built.copied, size_cap, size_poll).await?;
  2161	    if !kind.mirror_config() {
  2162	        // After the push: the fork's `transfer.hideRefs = refs/forge/` would
  2163	        // make receive-pack refuse its pull-request heads.
  2164	        fork::write_fork_config(source, staging).await?;
  2165	    }
  2166	    built.head = choose_head(source, &built.copied).await?;
  2167	    if let Some(h) = &built.head {
  2168	        run_in(
  2169	            staging,
  2170	            staging,
  2171	            &["symbolic-ref", "HEAD", h],
  2172	            None,
  2173	            Duration::from_secs(15),
  2174	            None,
  2175	        )
  2176	        .await?;
  2177	    }
  2178	    verify_with_roots(source, staging, &built.copied, &check_held, &roots).await?;
  2179	    built.dropped_objects = dropped_objects(source, staging).await?;
  2180	    let mut held: Vec<String> = match kind {
  2181	        Kind::Mirror => check_held.into_iter().collect(),
  2182	        // A fork's report lists the held objects it actually left behind.
  2183	        Kind::Fork(_) => built
  2184	            .dropped_objects
  2185	            .iter()
  2186	            .filter(|id| check_held.contains(*id))
  2187	            .cloned()
  2188	            .collect(),
  2189	    };
  2190	    held.sort();
  2191	    built.held = held;
  2192	    Ok(built)
  2193	}

  2195	/// Mirror-class ref selection into `built`: roots (branches and tags) are
  2196	/// copied, `refs/mirror/*`, pull-request heads and replacements never, and
  2197	/// any other ref only if it reaches nothing held. With `inherited` (a
  2198	/// followed fork: the inherited held set and the ancestors' roots present in
  2199	/// `source`), a root that reaches an inherited held object is dropped first.
  2200	/// Returns the held set and the copied roots.
  2201	async fn select_mirror(
  2202	    source: &Path,
  2203	    refs: Vec<(String, Option<String>, String)>,
  2204	    built: &mut Built,
  2205	    inherited: Option<(&HashSet<String>, &[String])>,
  2206	) -> Result<(HashSet<String>, Vec<String>), String> {
  2207	    let mut roots = Vec::new();
  2208	    let mut others = Vec::new();
  2209	    for (sha, name, lossy) in refs {
  2210	        let reason = match name.as_deref() {
  2211	            None => Some("unsafe-name"),
  2212	            Some(r) if !safe_ref(r) || !is_sha40(&sha) => Some("unsafe-name"),
  2213	            Some(r) if r.starts_with("refs/mirror/") => Some("mirror"),
  2214	            Some(r) if r.starts_with("refs/forge/heads/") => Some("pull-request-head"),
  2215	            // A replacement names its target, which may be held, and means
  2216	            // nothing without it: never copied.
  2217	            Some(r) if r.starts_with("refs/replace/") => Some("outside-roots"),
  2218	            Some(r) if is_root(r) => {
  2219	                if let Some((held, ancestor_roots)) = inherited {
  2220	                    if reaches_held(source, &sha, ancestor_roots, held).await? {
  2221	                        built.dropped.push(DroppedRef {
  2222	                            name: r.to_string(),
  2223	                            sha,
  2224	                            reason: "reaches-held",
  2225	                        });
  2226	                        continue;
  2227	                    }
  2228	                }
  2229	                roots.push(sha.clone());
  2230	                built.copied.insert(r.to_string(), sha);
  2231	                continue;
  2232	            }
  2233	            Some(r) => {
  2234	                others.push((r.to_string(), sha));
  2235	                continue;
  2236	            }
  2237	        };
  2238	        if let Some(reason) = reason {
  2239	            built.dropped.push(DroppedRef {
  2240	                name: lossy,
  2241	                sha,
  2242	                reason,
  2243	            });
  2244	        }
  2245	    }
  2246	    roots.sort();
  2247	    roots.dedup();
  2248	    let held = held_set(source, &roots).await?;
  2249	    for (r, sha) in others {
  2250	        if reaches_held(source, &sha, &roots, &held).await? {
  2251	            built.dropped.push(DroppedRef {
  2252	                name: r,
  2253	                sha,
  2254	                reason: "outside-roots",
  2255	            });
  2256	        } else {
  2257	            built.copied.insert(r, sha);
  2258	        }
  2259	    }
  2260	    Ok((held, roots))
  2261	}

  2263	/// Carry the old store's `forge.parent` (validated) into staging, so a
  2264	/// followed fork keeps its lineage through a mirror-class rebuild.
  2265	async fn keep_parent(source: &Path, staging: &Path) -> Result<(), String> {
  2266	    let parent = crate::forks::read_fork_parent_checked(source)
  2267	        .map_err(|e| format!("the old config could not be read: {}", e.kind()))?;
  2268	    if let Some(parent) = parent {
  2269	        run_in(
  2270	            staging,
  2271	            staging,
  2272	            &["config", "--local", "forge.parent", &parent.full()],
  2273	            None,
  2274	            Duration::from_secs(15),
  2275	            None,
  2276	        )
  2277	        .await?;
  2278	    }
  2279	    Ok(())
  2280	}

  2282	/// The held set of a store: every object any ref reaches
  2283	/// (`rev-list --objects --all`) outside the full closure of the roots. The
  2284	/// closure is subtracted in a second pass because `--not <roots>` only
  2285	/// marks the boundary commits' trees uninteresting: a blob the held history
  2286	/// shares with deeper root history (C16) would otherwise count as held.
  2287	async fn held_set(source: &Path, roots: &[String]) -> Result<HashSet<String>, String> {
  2288	    let mut held = HashSet::new();
  2289	    let cap = |set: &HashSet<String>| {
  2290	        if set.len() >= MAX_HELD_IDS {
  2291	            Err(format!("the held set passed {MAX_HELD_IDS} objects"))
  2292	        } else {
  2293	            Ok(())
  2294	        }
  2295	    };
  2296	    for_each_line(
  2297	        source,
  2298	        &[
  2299	            "rev-list",
  2300	            "--objects",
  2301	            "--no-object-names",
  2302	            "--all",
  2303	            "--stdin",
  2304	        ],
  2305	        Some(exclude_input(roots)),
  2306	        STORE_BUDGET,
  2307	        |id| {
  2308	            cap(&held)?;
  2309	            held.insert(id.to_string());
  2310	            Ok(Flow::Go)
  2311	        },
  2312	    )
  2313	    .await?;
  2314	    if held.is_empty() || roots.is_empty() {
  2315	        return Ok(held);
  2316	    }
  2317	    let mut input = Vec::with_capacity(roots.len() * 41);
  2318	    for sha in roots {
  2319	        input.extend_from_slice(sha.as_bytes());
  2320	        input.push(b'\n');
  2321	    }
  2322	    for_each_line(
  2323	        source,
  2324	        &["rev-list", "--objects", "--no-object-names", "--stdin"],
  2325	        Some(input),
  2326	        STORE_BUDGET,
  2327	        |id| {
  2328	            held.remove(id);
  2329	            Ok(Flow::Go)
  2330	        },
  2331	    )
  2332	    .await?;
  2333	    Ok(held)
  2334	}

  2336	/// Whether anything `sha` reaches beyond the roots is held.
  2337	async fn reaches_held(
  2338	    source: &Path,
  2339	    sha: &str,
  2340	    roots: &[String],
  2341	    held: &HashSet<String>,
  2342	) -> Result<bool, String> {
  2343	    let mut hit = false;
  2344	    for_each_line(
  2345	        source,
  2346	        &["rev-list", "--objects", "--no-object-names", sha, "--stdin"],
  2347	        Some(exclude_input(roots)),
  2348	        STORE_BUDGET,
  2349	        |id| {
  2350	            if held.contains(id) {
  2351	                hit = true;
  2352	                return Ok(Flow::Stop);
  2353	            }
  2354	            Ok(Flow::Go)
  2355	        },
  2356	    )
  2357	    .await?;
  2358	    Ok(hit)
  2359	}

  2361	/// Push exactly `refs` (name to SHA) from `source` into the empty `staging`,
  2362	/// by SHA, in batches, with the fixed receive-pack and no hooks, killing
  2363	/// the push once staging grows past `size_cap`.
  2364	async fn push_refs(
  2365	    source: &Path,
  2366	    staging: &Path,
  2367	    refs: &BTreeMap<String, String>,
  2368	    size_cap: u64,
  2369	    size_poll: SizePoll,
  2370	) -> Result<(), String> {
  2371	    let target = staging.to_str().ok_or("non-UTF-8 staging path")?;
  2372	    let specs: Vec<String> = refs.iter().map(|(r, sha)| format!("{sha}:{r}")).collect();
  2373	    let receive = format!("--receive-pack={RECEIVE_PACK}");
  2374	    let cap: Option<(u64, DirMeasure)> = Some((size_cap, crate::sizecap::dir_size));
  2375	    for batch in specs.chunks(PUSH_BATCH) {
  2376	        let mut args: Vec<&str> = vec![
  2377	            "-c",
  2378	            "push.gpgSign=false",
  2379	            "-c",
  2380	            "push.followTags=false",
  2381	            "-c",
  2382	            "push.recurseSubmodules=no",
  2383	            "push",
  2384	            "--porcelain",
  2385	            "--no-verify",
  2386	            &receive,
  2387	            "--",
  2388	            target,
  2389	        ];
  2390	        args.extend(batch.iter().map(String::as_str));
  2391	        let out = run_output_env(
  2392	            source,
  2393	            staging,
  2394	            &args,
  2395	            Some("file"),
  2396	            STORE_BUDGET,
  2397	            cap,
  2398	            size_poll,
  2399	            &MIGRATION_ENV,
  2400	        )
  2401	        .await?;
  2402	        if !out.status.success() {
  2403	            let err = String::from_utf8_lossy(&out.stderr);
  2404	            let lines: Vec<&str> = err
  2405	                .lines()
  2406	                .map(str::trim)
  2407	                .filter(|l| !l.is_empty() && !l.starts_with("hint:"))
  2408	                .take(4)
  2409	                .collect();
  2410	            return Err(format!("push into staging failed: {}", lines.join(" | ")));
  2411	        }
  2412	        // The push can finish between two measurements: measure the
  2413	        // completed staging store once more.
  2414	        let d = staging.to_path_buf();
  2415	        let size = tokio::task::spawn_blocking(move || crate::sizecap::dir_size(&d))
  2416	            .await
  2417	            .map_err(|e| format!("staging not measured: {e}"))?;
  2418	        if size > size_cap {
  2419	            return Err(GREW_PAST_CAP.to_string());
  2420	        }
  2421	    }
  2422	    Ok(())
  2423	}

  2425	/// `HEAD` for the rebuilt store: the source's symbolic `HEAD` if it names a
  2426	/// copied branch, else `refs/heads/main` if copied, else the first copied
  2427	/// branch, else none.
  2428	async fn choose_head(
  2429	    source: &Path,
  2430	    copied: &BTreeMap<String, String>,
  2431	) -> Result<Option<String>, String> {
  2432	    let out = run_output(
  2433	        source,
  2434	        source,
  2435	        &["symbolic-ref", "-q", "HEAD"],
  2436	        None,
  2437	        Duration::from_secs(15),
  2438	        None,
  2439	    )
  2440	    .await?;
  2441	    let named = String::from_utf8_lossy(&out.stdout).trim().to_string();
  2442	    if out.status.success() && named.starts_with("refs/heads/") && copied.contains_key(&named) {
  2443	        return Ok(Some(named));
  2444	    }
  2445	    if copied.contains_key("refs/heads/main") {
  2446	        return Ok(Some("refs/heads/main".into()));
  2447	    }
  2448	    Ok(copied
  2449	        .keys()
  2450	        .find(|r| r.starts_with("refs/heads/"))
  2451	        .cloned())
  2452	}

  2454	/// Step 7, failing closed on any miss: every staging ref is exactly the one
  2455	/// chosen; no object of `held` is present (checked whatever `held` holds);
  2456	/// every object in staging lies in the closure, in `source`, of the chosen
  2457	/// branches and tags; nothing is borrowed through alternates; and no object
  2458	/// file is shared with the source.
  2459	#[cfg(test)]
  2460	pub(crate) async fn verify(
  2461	    source: &Path,
  2462	    staging: &Path,
  2463	    want: &BTreeMap<String, String>,
  2464	    held: &HashSet<String>,
  2465	) -> Result<(), String> {
  2466	    let mut roots: Vec<String> = want
  2467	        .iter()
  2468	        .filter(|(r, _)| is_root(r))
  2469	        .map(|(_, sha)| sha.clone())
  2470	        .collect();
  2471	    roots.sort();
  2472	    roots.dedup();
  2473	    verify_with_roots(source, staging, want, held, &roots).await
  2474	}
  2475	
  2476	/// [`verify`] with the roots given: every object in staging must lie in the
  2477	/// closure of `roots` in `source` (a fork's roots are every ref it copies).
  2478	async fn verify_with_roots(
  2479	    source: &Path,
  2480	    staging: &Path,
  2481	    want: &BTreeMap<String, String>,
  2482	    held: &HashSet<String>,
  2483	    roots: &[String],
  2484	) -> Result<(), String> {
  2485	    let listing = run_in(
  2486	        staging,
  2487	        staging,
  2488	        &["for-each-ref", "--format=%(refname) %(objectname)"],
  2489	        None,
  2490	        STORE_BUDGET,

   238	    /// Marker gate (defence in depth): a served repository with a mirror
   239	    /// record but no [`PUBLICATION_MARKER`] predates candidate isolation
   240	    /// and may hold commits the mirror never approved. A repository with
   241	    /// anything at its migration journal path ([`migrate::journal_path`]),
   242	    /// in any state, `published` included, is refused first, marked or not.
   243	    /// If the boot migration did not complete, every repository under a
   244	    /// 64-hex owner is refused, marked or not, and so is every fork (any
   245	    /// repository whose config names a `forge.parent` or cannot be read). Then one `lstat` for a marked
   246	    /// mirror (the marker must be a regular file) and two for any other
   247	    /// repository. The record path is
   248	    /// `mirror::MirrorStore`'s layout, checked without the `mirror` feature
   249	    /// so a plugin directory that was mirrored once stays gated. `owner` and
   250	    /// `repo` are already validated path segments (`repo::repo_git_dir`).
   251	    /// A record path that cannot be checked (any error but "not found")
   252	    /// keeps the gate closed.
   253	    async fn unpublished_mirror(&self, owner: &str, repo: &str, dir: &Path) -> bool {
   254	        // Decision 21: a migration journal in any state (`published`
   255	        // included, until `finish` removes it), or any entry there, gates the
   256	        // store, marked or not, record or not. This is what keeps a lost-record legacy store
   257	        // whose migration failed from being served.
   258	        if migrate::journal_gates(&self.plugin_dir, owner, repo).await {
   259	            return true;
   260	        }
   261	        // The boot migration did not complete: every store under a 64-hex
   262	        // owner is refused, marked or not (a marked, flagged store may be one
   263	        // detection wanted rebuilt).
   264	        if self.migration_incomplete && mirror_record::is_hex64(owner) {
   265	            return true;
   266	        }
   267	        // Nor every fork (B2): forks live under any owner, and one the pass
   268	        // could not check may still hold a legacy mirror's held objects. A
   269	        // config that cannot be read may be a fork's.
   270	        if self.migration_incomplete {
   271	            let dir = dir.to_path_buf();
   272	            let fork_or_unknown = tokio::task::spawn_blocking(move || {
   273	                !matches!(forks::read_fork_parent_checked(&dir), Ok(None))
   274	            })
   275	            .await
   276	            .unwrap_or(true);
   277	            if fork_or_unknown {
   278	                return true;
   279	            }
   280	        }
   281	        // The marker is a regular file at the store root, not a symlink: the
   282	        // same test detection applies.
   283	        let marked = tokio::fs::symlink_metadata(dir.join(PUBLICATION_MARKER))
   284	            .await
   285	            .is_ok_and(|m| m.is_file());
   286	        if marked {
   287	            return false;
   288	        }
   289	        self.has_mirror_record(owner, repo).await.unwrap_or(true)
   290	    }

The rebuild verifies inherited held-object exclusion, but the broader claim is only partly supported. In particular, cleanliness is treated as permanent despite ordinary forks remaining writable. This is a static review of the supplied code; the reported test results were not independently verified.

File references below use repository filenames. For `lib.rs`, references use the actual diff line numbers rather than the renumbered combined excerpt.

New material findings, ranked by severity:

1. **HIGH — CONFIRMED: subsequent writes invalidate permanent cleanliness exemptions.**  
   Evidence: `migrate_fork.rs:95` excludes stamped reports from triggers; `detect` returns `Clean` when those triggers are empty and also exempts stores recognised by `rebuilt_against`. `migrate.rs:2748` records ancestor coverage, but nothing binds that coverage to the fork’s current refs or objects. `lib.rs:662` applies the additional fork refusal only when migration is incomplete. The supplied smart-HTTP handler permits authorised namespace writes subject to the journal gate.

   **Failure scenario:** a malicious fork owner retains a held commit from the legacy period. After migration, they push that commit and its objects back into their ordinary fork. On the next boot, the stamped ancestor—or the unchanged migration ID and ancestor coverage—causes detection to skip examination. The commit remains available by SHA. A subsequently created fork can inherit it and receive the same stamped-report exemption.

   This requires ordinary remote write permission to the attacker’s own fork, not plugin-directory access. It does not demonstrate recovery of previously unknown secret bytes, but it defeats the stated object-exclusion claim. A narrower claim covering only objects present at the initial migration would avoid this particular contradiction.

2. **MEDIUM — CONFIRMED: failed ordinary-fork ancestors do not necessarily gate descendants.**  
   Evidence: `migrate_fork.rs:plan_for`, particularly the `if is_hex64(o)` block around line 224, checks ancestor journals only for 64-hex owners. `migrate.rs:865` permits a completed pass containing `Failed` outcomes when journals successfully gate those individual stores.

   **Failure scenario:** `carol/sample` fails its fork rebuild, for example because its selected history exceeds the size cap. Its descendant contains only approved objects, has readable lineage and no journal. The descendant can be classified clean and served despite Carol’s outstanding journal.

   This contradicts the unqualified “ancestor … failed is refused” requirement. It does **not** independently establish held-object disclosure: the descendant still collects the original mirror’s reports.

3. **MEDIUM — CONFIRMED: ancestor-root subtraction can prevent correct ref removal and cause persistent refusal.**  
   Evidence: `migrate.rs:2140`, `migrate.rs:2220` and `migrate.rs:2344` use the combined ancestor roots as exclusions; `migrate.rs:2503` separately checks staging against the inherited held set.

   **Failure scenario:** mirror M holds object H; followed fork F initially publishes a branch reaching H during its mirror-class rebuild. F’s mirror report records that branch as a root. The fork pass subsequently removes it from F, but a descendant still has that root. Subtracting F’s stale root hides H from the descendant’s ref filter. Verification detects H in staging and rejects the entire rebuild, leaving even approved descendant content unavailable.

   This is an availability defect, not a disclosure bypass. The worker report already acknowledges it.

Each “Check especially” item:

1. **Trigger completeness — PARTLY.**  
   Evidence: `migrate_fork.rs:plan_for`, `mirror_reports`, `read_report` and `detect`; `migrate.rs:1080`, `migrate.rs:2831`, `migrate.rs:2905`.

New material findings, ranked by severity:

1. **HIGH — CONFIRMED: subsequent writes invalidate permanent cleanliness exemptions.**  
   Evidence: `migrate_fork.rs:95` excludes stamped reports from triggers; `detect` returns `Clean` when those triggers are empty and also exempts stores recognised by `rebuilt_against`. `migrate.rs:2748` records ancestor coverage, but nothing binds that coverage to the fork’s current refs or objects. `lib.rs:662` applies the additional fork refusal only when migration is incomplete. The supplied smart-HTTP handler permits authorised namespace writes subject to the journal gate.

   **Failure scenario:** a malicious fork owner retains a held commit from the legacy period. After migration, they push that commit and its objects back into their ordinary fork. On the next boot, the stamped ancestor—or the unchanged migration ID and ancestor coverage—causes detection to skip examination. The commit remains available by SHA. A subsequently created fork can inherit it and receive the same stamped-report exemption.

   This requires ordinary remote write permission to the attacker’s own fork, not plugin-directory access. It does not demonstrate recovery of previously unknown secret bytes, but it defeats the stated object-exclusion claim. A narrower claim covering only objects present at the initial migration would avoid this particular contradiction.

2. **MEDIUM — CONFIRMED: failed ordinary-fork ancestors do not necessarily gate descendants.**  
   Evidence: `migrate_fork.rs:plan_for`, particularly the `if is_hex64(o)` block around line 224, checks ancestor journals only for 64-hex owners. `migrate.rs:865` permits a completed pass containing `Failed` outcomes when journals successfully gate those individual stores.

3. **MEDIUM — CONFIRMED: ancestor-root subtraction can prevent correct ref removal and cause persistent refusal.**

Verification detects H in staging and rejects the entire rebuild, leaving even approved descendant content unavailable.
