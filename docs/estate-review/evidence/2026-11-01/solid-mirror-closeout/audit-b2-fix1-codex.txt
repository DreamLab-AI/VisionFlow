### F1. Medium. A fork whose `forge.parent` fails `valid_owner`/`valid_repo` is never swept or gated, and its ancestor gets stamped. CONFIRMED (code path); PLAUSIBLE (configuration)

**Where:**
- `forks.rs:91-104`: `parse_fork_parent` accepts a lineage only if `compare::valid_owner` and `compare::valid_repo` pass (`compare.rs:32-55`). `valid_repo` refuses a trailing `.git`. `valid_owner` refuses an owner over 64 bytes, a reserved owner, and a leading `-`, `_` or `.`.
- Repository names under `repos/` follow the looser `valid_name_segment`. Mirror names follow `is_repo_name` (`mirror_record.rs:25-28`), which allows `foo.git`. Follow entries are validated only by `is_repo_name` (`mirror.rs:337-338`), so an operator may follow a repository named `foo.git` (served as `repos/<hex>/foo.git.git`).
- `forks.rs:290`: a fork without a `name` field takes the source name unvalidated, so `carol/foo.git` is a valid fork destination. `forks.rs:398` writes `forge.parent = <hex>/foo.git` into the fork.
- `read_fork_parent_checked` returns `Ok(None)` ("not a fork") for that config (`forks.rs:122-130`). So:
  - the sweep classes it `Lineage::Root` and it is never a target (`migrate_fork.rs:127-129`, `141-145`);
  - the incomplete-pass rule treats it as not a fork (`lib.rs:665-677`);
  - it never blocks stamping, so the legacy parent's report is stamped `forksCleanAt` on the first complete pass (`migrate_fork.rs:189-191`, `604-611`). After that no boot re-examines the parent's forks.

**Both ends are reachable, verified on the routes:**
- `parse_route` strips `.git` only once, both for the fork route (`router.rs:555-558`, the same at `423e8c6`, where the forks in question were made) and for the reader routes (`router.rs:595-597`, e.g. `Route::Raw`).
  - `POST /api/repos/<hex>/foo.git.git/fork` forks the store named `foo.git`.
  - `/<prefix>/carol/foo.git.git/raw/<sha>/…` reaches `resolve_repo("carol", "foo.git")`, which uses `valid_name_segment`.
- Only the JSON action API refuses such a name (`ok_repo`, `api.rs:546`). Raw, HTML and archive do not.

**Scenario:**
1. Before B, the operator followed a repository named `foo.git` under a 64-hex owner, and a user forked it, by default to `carol/foo.git`.
2. The fork is a `clone --local` hardlink of the legacy store, so it holds every held object.
3. After B2's boot, the mirror is rebuilt but the fork is untouched. Any held commit, tree or blob is served with 200 by SHA through carol's raw, HTML and archive readers. Carol's JSON action API refuses the name.

Test 7b shows that the readers serve unreachable objects. A descendant of carol inherits the same unparseable lineage (`carol/foo.git`).

**Who can reach it:** anonymous readers. The producers are an operator name ending in `.git` plus any fork made before migration. For forks of forks, an owner id the forge accepts as a path segment but `valid_owner` rejects is another producer.

**Fix:** for migration and for the incomplete-pass rule, parse lineage with the validator the readers use (`valid_name_segment` for both parts). Treat a `forge.parent` key that is present but unparseable as a fork of unknown lineage: give it the orphan treatment (check it against every mirror-class report) and gate it while the pass is incomplete. Add a fixture with a mirror named `<x>.git`, whose test is red now. Optionally, make `h_api_fork` refuse to write a lineage `parse_fork_parent` would reject.

### F2. Low (documented residual, but realistic). Objects pruned from a legacy parent but kept in a fork's hardlinked packs are never triggered. PLAUSIBLE

**Where:** the trigger is presence of a `.dropped` object (`migrate_fork.rs:374-386`). D is computed against the parent as it was at migration time.

**Why it is realistic:**
- Before Commit A, the legacy engine ran `gc` on the served store after a failed fetch (CHANGELOG part 1).
- That pruned unreachable held objects from the mirror: held tips that upstream force-pushed away, and orphans of approved force moves.
- A fork taken earlier keeps them in its own hardlinked pack, because `gc` repacks the parent and leaves the fork's pack alone.
- If the parent's current held set was fetched after the fork, the fork holds no D object. It is left byte-identical and keeps serving the pruned, formerly held objects by SHA.

**Within the formal claim, but not the intent:** these objects are outside "the held set" as it is computed at migration, but they are content that was never approved.

**Who can reach it:** anonymous readers who know or can guess the SHA. Upstream PR commits are often public.

**Fix (option):** for a fork whose lineage reaches a mirror-class ancestor with a report, also trigger when the fork holds any object its own refs do not reach. That means comparing `cat-file --batch-all-objects` with `rev-list --objects --all` in the fork, streamed and capped like `outside_roots`. A rebuild copies only ref closures, so it removes them. The cost is an occasional rebuild of a fork that only has its own garbage.

### F3. Low. A gate partway up the lineage blocks only the reports collected so far. PLAUSIBLE (transient errors only)

**Where:** `plan_for` returns at the first gate with the reports gathered up to that point (`migrate_fork.rs:225-252`). `sweep` then blocks only `plan.report_ids()`, and blocks all reports only when none were collected (`migrate_fork.rs:176-181`).

**Scenario:**
- Take `dave → F' (64-hex followed fork, with a report) → carol → M`, where checking carol's directory fails transiently at plan time but not during listing.
- M's report is not blocked, so it is stamped.
- On later boots M's dropped set is no longer a trigger for dave. Dave is still triggered through F''s report, and the rebuild filter still uses every plan report, stamped ones included (`inherited_held` iterates `plan.reports`).
- So the window needs a lineage where M is the only trigger and the transient error hits exactly between listing and planning.

**Fix:** on any `plan.gate`, block everything (`blocked.insert(String::new())`), not just the ids collected.

- The gated-plan guard runs before `rebuild` (`1631-1639`), so a journalled fork with a gated ancestor is never rebuilt with an empty H.

- **Gap:** F1 (the store is never a target in the first place).

**4. Incomplete-pass fork rule (`lib.rs:665-677`).**
- **Gated now:**

  - any repository, under any owner, whose config names a **parseable** `forge.parent` or cannot be read.

**5. Cycles and transitivity.**
- Plans read only mirror-class reports, and all of those exist before the fork pass starts (`migrate.rs:834-837`).
- A grandchild is planned against the mirror ancestor directly, never against its parent fork's rebuild. Detection is therefore order-independent.
- Cycles stop on the `visited` set. The cycle test covers this.

**6. `.fork-*.tmp` sweep (`migrate_fork.rs:634-676`).**

- The source is a direct entry of a `valid_name_segment` owner directory. Symlinked entries are skipped, because `symlink_metadata` reports them as not directories.

- The sweep runs at boot, before any fork build in this process.

**7. CHANGELOG.** Accurate apart from two points:

## Residuals (recorded, not fixed)

- **Codex Medium 3 (stale roots, availability):** a followed fork's stale root in a descendant's `--not` list can make the descendant's rebuild fail verification and stay refused. In the CHANGELOG.
- **Pruned parent, reachable:** a pruned object that a fork's own ref reaches is kept (no report lists it). Same class as risk 4. In the CHANGELOG.
- **Stamping can stay blocked for good, which keeps F2 armed.** A fork of unknown lineage, or a gate anywhere in a lineage (with item 4, a fork that has given up at `attempts: 3` gates its descendants for good), blocks stamping for every report as long as it exists. Every fork of an unstamped parent is then re-checked on every boot, including F2's unreachable-object check. A fork that later accumulates ordinary unreachable objects (a force-pushed or deleted branch) is then rebuilt once into recovery, possibly long after migration; `rebuilt_against` keeps it from being rebuilt again. That is a real availability and disk cost, not only I/O.
- **One extra boot to clear.** A descendant that sorts before its gated ancestor gets a gate journal on the boot where the ancestor is still gated, and is re-examined only on the next boot.
- **Unsafe-named refs:** a ref whose name is unsafe on a push command line is dropped by the rebuild (`unsafe-name`) but cannot be excluded from the reachability walk by a glob, so it still counts as reaching. In the CHANGELOG.
- **Filesystem writers, outside the threat model (decision 32):** report deletion or truncation, `.dropped`/`.held` counts not checked against the report on read, symlinked owner or recovery directories in the tmp sweep, timestamp collisions in recovery names, the first-versus-last `forge.parent` disagreement with git, and `.held` read after `lstat` rather than through `read_regular`.

     4	//! hardlinks the mirror's packs, held objects included, and keeps serving

   131	/// The fork sweep. `mirror_complete` says whether the mirror-class pass
   132	/// completed; reports are stamped only if it did and this pass did too.
   133	pub(super) async fn sweep(plugin: &Path, mirror_complete: bool) -> Swept {

   135	    let (stores, stores_listed) = served_stores(plugin);
   136	    let mut listed = stores_listed;
   137	    let mut lineage = BTreeMap::new();
   138	    for (owner, name) in &stores {
   139	        let dir = plugin.join("repos").join(owner).join(format!("{name}.git"));
   140	        let l = match read_lineage_checked(&dir) {
   141	            Ok(StoredLineage::Parent(p)) => Lineage::Parent(p.owner, p.name),
   142	            Ok(StoredLineage::Unknown(raw)) => Lineage::Unknown(raw),

   151	    }

   153	    // store is in recovery mid-migration names its parent in the journal).

   170	            continue;
   171	        };

   173	            if j.class == "fork" {
   174	                if let Some(parent) = j.parent {
   175	                    targets.entry((owner, name)).or_insert(parent);
   176	                }
   177	            }
   178	        }
   179	    }

   206	/// The report ids a fork's plan and outcome keep from being stamped; the

   208	/// holds only the reports collected before the gate, and the ancestors
   209	/// beyond are unknown), and so does a fork of unknown lineage.
   210	fn stamp_blocks(plan: &Plan, outcome: Outcome) -> Vec<String> {
   211	    if plan.gate.is_some() || plan.unknown {
   212	        return vec![String::new()];
   213	    }
   214	    match outcome {
   215	        Outcome::Migrated | Outcome::Skipped => Vec::new(),
   216	        Outcome::Failed | Outcome::Ungated => {
   217	            let mut ids = plan.report_ids();
   218	            if plan.reports.is_empty() {
   219	                // Gated before its ancestors were known: block them all.

   227	/// The plan of fork `<owner>/<name>` whose parent is `parent`: walk the
   228	/// lineage to its root (cycle-safe, at most one step per store), collecting
   229	/// every mirror-class ancestor's reports.
   230	fn plan_for(
   231	    plugin: &Path,
   232	    owner: &str,
   233	    name: &str,
   234	    parent: &str,
   235	    lineage: &BTreeMap<(String, String), Lineage>,
   236	    every: &mut Option<Result<Vec<AncestorReport>, String>>,
   237	) -> Plan {
   238	    let mut plan = Plan {
   239	        parent: parent.to_string(),
   240	        followed: is_hex64(owner)
   241	            && !matches!(
   242	                MirrorStore::new(plugin).load(owner, name),
   243	                StoredRecord::Missing
   244	            ),
   245	        ..Plan::default()
   246	    };
   247	    let mut visited = BTreeSet::from([(owner.to_string(), name.to_string())]);
   248	    let mut next = parse_lineage_value(parent).map(|p| (p.owner, p.name));
   249	    let mut orphan = false;
   250	    if next.is_none() {
   251	        // A lineage that does not parse: its ancestors are unknown.
   252	        plan.unknown = true;
   253	        orphan = true;
   254	    }
   255	    while let Some(at) = next.take() {
   256	        if visited.len() > lineage.len() + 1 || !visited.insert(at.clone()) {
   257	            break; // a cycle, or longer than the store count
   258	        }
   259	        let (o, n) = (&at.0, &at.1);
   260	        // An ancestor behind a journal, under any owner (a fork that failed
   261	        // its own rebuild included), gates its descendants.
   262	        if journal_exists(plugin, o, n) {
   263	            plan.gate = Some(format!("ancestor {o}/{n} is behind a migration journal"));
   264	            return plan;
   265	        }
   266	        if is_hex64(o) {
   267	            match mirror_reports(plugin, o, n) {
   268	                Ok(found) => plan.reports.extend(found),
   269	                Err(e) => {
   270	                    plan.gate = Some(format!("ancestor {o}/{n}'s migration report: {e}"));
   271	                    return plan;
   272	                }
   273	            }
   274	        }
   275	        let dir = plugin.join("repos").join(o).join(format!("{n}.git"));
   276	        match dir_state(&dir) {
   277	            Ok(true) => match lineage.get(&at) {
   278	                Some(Lineage::Parent(po, pn)) => next = Some((po.clone(), pn.clone())),
   279	                Some(Lineage::Unknown(_)) => {
   280	                    plan.unknown = true;
   281	                    orphan = true;
   282	                }
   283	                Some(Lineage::Root) => {}
   284	                Some(Lineage::Unreadable) | None => {
   285	                    plan.gate = Some(format!("ancestor {o}/{n}'s lineage could not be read"));
   286	                    return plan;
   287	                }
   288	            },
   289	            Ok(false) => orphan = true,
   290	            Err(e) => {
   291	                plan.gate = Some(format!("ancestor {o}/{n}: {e}"));
   292	                return plan;
   293	            }
   294	        }
   295	    }
   296	    if orphan {
   297	        // The chain stops at a store that is gone: its own ancestors are
   298	        // unknown, so check against every mirror-class report.
   299	        match every.get_or_insert_with(|| every_mirror_report(plugin)) {
   300	            Ok(all) => plan.reports.extend(all.iter().cloned()),
   301	            Err(e) => {
   302	                plan.gate = Some(format!("the migration reports could not be listed: {e}"));
   303	                return plan;
   304	            }
   305	        }
   306	    }
   307	    let mut seen = HashSet::new();
   308	    plan.reports.retain(|r| seen.insert(r.id.clone()));
   309	    plan
   310	}

   351	/// One report, if it is a mirror-class report.
   352	fn read_report(path: &Path) -> Result<Option<AncestorReport>, String> {
   353	    let bytes = read_regular(path).map_err(|e| format!("not read: {}", e.kind()))?;
   354	    let v: serde_json::Value =
   355	        serde_json::from_slice(&bytes).map_err(|e| format!("not parsed: {e}"))?;
   356	    if v.get("class").and_then(|c| c.as_str()) != Some("mirror") {
   357	        return Ok(None);
   358	    }
   359	    let id = v
   360	        .get("id")
   361	        .and_then(|i| i.as_str())
   362	        .ok_or("no id")?
   363	        .to_string();
   364	    let file = path
   365	        .to_str()
   366	        .and_then(|p| p.strip_suffix(".migration.json"))
   367	        .ok_or("not a report name")?;
   368	    let stem = PathBuf::from(file);
   369	    let (held, dropped) = (with_suffix(&stem, ".held"), with_suffix(&stem, ".dropped"));
   370	    for f in [&held, &dropped] {
   371	        if !std::fs::symlink_metadata(f).is_ok_and(|m| m.is_file()) {
   372	            return Err("its held or dropped list is missing".into());
   373	        }
   374	    }
   375	    let roots = v
   376	        .get("copied")
   377	        .and_then(|c| c.as_array())
   378	        .map(|refs| {
   379	            refs.iter()
   380	                .filter(|r| {
   381	                    r.get("ref")
   382	                        .and_then(|n| n.as_str())
   383	                        .is_some_and(super::is_root)
   384	                })
   385	                .filter_map(|r| r.get("sha").and_then(|s| s.as_str()))
   386	                .filter(|s| super::is_sha40(s))
   387	                .map(str::to_string)
   388	                .collect()
   389	        })
   390	        .unwrap_or_default();
   391	    Ok(Some(AncestorReport {
   392	        id,
   393	        path: path.to_path_buf(),
   394	        held,
   395	        dropped,
   396	        roots,
   397	        stamped: v.get("forksCleanAt").is_some(),
   398	    }))
   399	}

   408	        Ok(true) => {}
   409	        Ok(false) => return Detected::Skip,
   410	        Err(e) => return Detected::Error(e),
   411	    }
   412	    if let Some(g) = &plan.gate {
   413	        return Detected::Error(g.clone());
   414	    }
   415	    let triggers = plan.triggers();
   416	    if triggers.is_empty() {
   417	        return Detected::Clean;
   418	    }
   419	    if rebuilt_against(plugin, owner, name, &served, &triggers) {
   420	        return Detected::Clean;
   421	    }
   422	    let files: Vec<PathBuf> = triggers.iter().map(|r| r.dropped.clone()).collect();
   423	    match holds_any(&served, files).await {
   424	        Ok(true) => Detected::Rebuild,
   425	        // F2: an object pruned from the parent before migration is in no
   426	        // report, but a fork taken earlier still holds it in its hardlinked
   427	        // packs, unreachable from its own refs. A rebuild copies only ref
   428	        // closures, so it removes such objects.
   429	        Ok(false) => match holds_unreachable(&served).await {
   430	            Ok(true) => Detected::Rebuild,
   431	            Ok(false) => Detected::Clean,
   432	            Err(e) => Detected::Error(e),
   433	        },
   434	        Err(e) => Detected::Error(e),
   435	    }
   436	}

   438	/// Whether the store at `git_dir` holds any object the refs a rebuild keeps
   439	/// do not reach. `cat-file --batch-all-objects` lists every object once (it
   440	/// is deduplicated across packs and loose objects), and every object such a
   441	/// ref reaches is among them, so it lists more than the `rev-list --objects`
   442	/// walk exactly when one is outside it. The walk excludes `refs/mirror/*`
   443	/// and `refs/replace/*`, which [`select`] drops: a ref the rebuild drops must
   444	/// not make an object count as reachable. Both walks are streamed and
   445	/// counted, never held, with replace objects and grafts disabled; either
   446	/// failing is an error (the fork is then gated, never found clean).
   447	async fn holds_unreachable(git_dir: &Path) -> Result<bool, String> {
   448	    let mut all: u64 = 0;
   449	    super::for_each_line(
   450	        git_dir,
   451	        &[
   452	            "cat-file",
   453	            "--batch-all-objects",
   454	            "--batch-check=%(objectname)",
   455	        ],
   456	        None,
   457	        STORE_BUDGET,
   458	        |_| {
   459	            all += 1;
   460	            Ok(super::Flow::Go)
   461	        },
   462	    )
   463	    .await?;
   464	    let mut reached: u64 = 0;
   465	    super::for_each_line(
   466	        git_dir,
   467	        &[
   468	            "rev-list",
   469	            "--objects",
   470	            "--exclude=refs/mirror/*",
   471	            "--exclude=refs/replace/*",
   472	            "--all",
   473	        ],
   474	        None,
   475	        STORE_BUDGET,
   476	        |_| {
   477	            reached += 1;
   478	            Ok(super::Flow::Go)
   479	        },
   480	    )
   481	    .await?;
   482	    Ok(all > reached)
   483	}

   485	/// Whether the served fork carries the migration id of a fork report that
   486	/// lists every one of `triggers` among its ancestors: it was rebuilt against
   487	/// them, and what it still holds of their dropped sets its own refs reach
   488	/// (risk 4), so it is not rebuilt again.
   489	fn rebuilt_against(
   490	    plugin: &Path,
   491	    owner: &str,
   492	    name: &str,
   493	    served: &Path,
   494	    triggers: &[&AncestorReport],
   495	) -> bool {
   496	    let Some(id) = store_migration_id(served) else {
   497	        return false;
   498	    };
   499	    let dir = plugin.join("mirror-recovery").join(owner);
   500	    let Ok(found) = reports(&dir, name) else {
   501	        return false;
   502	    };
   503	    found.iter().any(|path| {
   504	        let Some(v) = read_regular(path)
   505	            .ok()
   506	            .and_then(|b| serde_json::from_slice::<serde_json::Value>(&b).ok())
   507	        else {
   508	            return false;
   509	        };
   510	        let covered: BTreeSet<&str> = v
   511	            .get("ancestors")
   512	            .and_then(|a| a.as_array())
   513	            .map(|a| a.iter().filter_map(|x| x.as_str()).collect())
   514	            .unwrap_or_default();
   515	        v.get("class").and_then(|c| c.as_str()) == Some("fork")
   516	            && v.get("id").and_then(|i| i.as_str()) == Some(id.as_str())
   517	            && triggers.iter().all(|t| covered.contains(t.id.as_str()))
   518	    })
   519	}

   543	/// The inherited held set: the union of the ancestors' `.held` files,
   544	/// bounded by [`MAX_HELD_IDS`].
   545	pub(super) fn inherited_held(plan: &Plan) -> Result<HashSet<String>, String> {
   546	    use std::io::BufRead;
   547	    let mut held = HashSet::new();
   548	    for r in &plan.reports {
   549	        let m = std::fs::symlink_metadata(&r.held).map_err(|e| format!("held list: {e}"))?;
   550	        if !m.file_type().is_file() {
   551	            return Err("a held list is not a regular file".into());
   552	        }
   553	        let f = std::fs::File::open(&r.held).map_err(|e| format!("held list: {e}"))?;
   554	        for line in std::io::BufReader::new(f).lines() {
   555	            let line = line.map_err(|e| format!("held list: {e}"))?;
   556	            if line.is_empty() {
   557	                continue;
   558	            }
   559	            if !super::is_sha40(&line) {
   560	                return Err("a held list holds something other than object ids".into());
   561	            }
   562	            if held.len() >= MAX_HELD_IDS {
   563	                return Err(format!(
   564	                    "the inherited held set passed {MAX_HELD_IDS} objects"
   565	                ));
   566	            }
   567	            held.insert(line);
   568	        }
   569	    }
   570	    Ok(held)
   571	}

   573	/// The ancestors' roots that `source` holds (checked first: `rev-list
   574	/// --not` fails on an object it does not have, C12).
   575	pub(super) async fn present_roots(source: &Path, plan: &Plan) -> Result<Vec<String>, String> {
   576	    let mut all: Vec<String> = plan
   577	        .reports
   578	        .iter()
   579	        .flat_map(|r| r.roots.iter().cloned())
   580	        .collect();
   581	    all.sort();
   582	    all.dedup();
   583	    if all.is_empty() {
   584	        return Ok(all);
   585	    }
   586	    let mut input = Vec::with_capacity(all.len() * 41);
   587	    for sha in &all {
   588	        input.extend_from_slice(sha.as_bytes());
   589	        input.push(b'\n');
   590	    }
   591	    let out = super::run_with_input(
   592	        source,
   593	        &["cat-file", "--batch-check=%(objectname) %(objecttype)"],
   594	        input,
   595	        STORE_BUDGET,
   596	    )
   597	    .await?;
   598	    if !out.status.success() {
   599	        return Err("git cat-file --batch-check failed".into());
   600	    }
   601	    let present: Vec<String> = String::from_utf8_lossy(&out.stdout)
   602	        .lines()
   603	        .filter(|l| !l.ends_with(" missing"))
   604	        .filter_map(|l| l.split(' ').next())
   605	        .filter(|id| super::is_sha40(id))
   606	        .map(str::to_string)
   607	        .collect();
   608	    Ok(present)
   609	}

   611	/// Fork ref selection into `built`: every ref but `refs/mirror/*` and
   612	/// `refs/replace/*` (and names unsafe on a push command line), each copied
   613	/// only if it reaches nothing in `held` beyond `ancestor_roots` (D1: a ref
   614	/// that does is dropped and reported as `reaches-held`).
   615	pub(super) async fn select(
   616	    source: &Path,
   617	    refs: Vec<(String, Option<String>, String)>,
   618	    built: &mut Built,
   619	    held: &HashSet<String>,
   620	    ancestor_roots: &[String],
   621	) -> Result<(), String> {
   622	    for (sha, name, lossy) in refs {
   623	        let reason = match name.as_deref() {
   624	            None => "unsafe-name",
   625	            Some(r) if !super::safe_ref(r) || !super::is_sha40(&sha) => "unsafe-name",
   626	            Some(r) if r.starts_with("refs/mirror/") => "mirror",
   627	            Some(r) if r.starts_with("refs/replace/") => "replace",
   628	            Some(r) => {
   629	                if super::reaches_held(source, &sha, ancestor_roots, held).await? {
   630	                    "reaches-held"
   631	                } else {
   632	                    built.copied.insert(r.to_string(), sha);
   633	                    continue;
   634	                }
   635	            }
   636	        };
   637	        built.dropped.push(DroppedRef {
   638	            name: lossy,
   639	            sha,
   640	            reason,
   641	        });
   642	    }
   643	    Ok(())
   644	}

   646	/// A fork's config: an allow-list of the old one (`forge.parent`,
   647	/// `http.receivepack` when a boolean, and `uploadpack.hideRefs` /
   648	/// `transfer.hideRefs` entries equal to `refs/forge/`). The old config is
   649	/// never copied whole: it is legacy-written and may name hooks or
   650	/// alternates. No served config: `receive.denyDeletes` would stop the owner
   651	/// deleting branches.
   652	pub(super) async fn write_fork_config(source: &Path, staging: &Path) -> Result<(), String> {
   653	    let bytes = read_regular(&source.join("config"))
   654	        .map_err(|e| format!("the old config could not be read: {}", e.kind()))?;
   655	    let text = String::from_utf8_lossy(&bytes);
   656	    let parent = match stored_lineage(&text) {
   657	        StoredLineage::Parent(p) => p.full(),
   658	        // Kept as read, so the rebuilt fork stays one of unknown lineage.
   659	        StoredLineage::Unknown(raw) => raw,
   660	        StoredLineage::None => return Err("the old config names no forge.parent".into()),
   661	    };
   662	    let mut sets: Vec<(&str, String)> = vec![("forge.parent", parent)];
   663	    for (section, key, value) in config_entries(&text) {
   664	        match (section.as_str(), key.as_str()) {
   665	            ("http", "receivepack") if matches!(value.as_str(), "true" | "false") => {
   666	                sets.push(("http.receivepack", value));
   667	            }
   668	            ("uploadpack", "hiderefs") if value == FORGE_REFS => {
   669	                sets.push(("uploadpack.hideRefs", value));
   670	            }
   671	            ("transfer", "hiderefs") if value == FORGE_REFS => {
   672	                sets.push(("transfer.hideRefs", value));
   673	            }
   674	            _ => {}
   675	        }
   676	    }
   677	    for (key, value) in sets {
   678	        run_in(
   679	            staging,
   680	            staging,
   681	            &["config", "--local", "--add", key, &value],
   682	            None,
   683	            Duration::from_secs(15),
   684	            None,
   685	        )
   686	        .await?;
   687	    }
   688	    Ok(())
   689	}

   691	/// Stamp `forksCleanAt` into every unstamped mirror-class report whose id
   692	/// is not `blocked` (a fork checked against it was not found clean).
   693	fn stamp_clean(
   694	    plugin: &Path,
   695	    blocked: &BTreeSet<String>,
   696	    every: &mut Option<Result<Vec<AncestorReport>, String>>,
   697	) {
   698	    let all = match every.get_or_insert_with(|| every_mirror_report(plugin)) {
   699	        Ok(all) => all,
   700	        Err(e) => {
   701	            tracing::warn!(error = %e, "forge: migration reports not listed; none stamped");
   702	            return;
   703	        }
   704	    };
   705	    for r in all
   706	        .iter()
   707	        .filter(|r| !r.stamped && !blocked.contains(&r.id))
   708	    {
   709	        if let Err(e) = stamp(&r.path) {
   710	            tracing::warn!(error = %e, "forge: migration report not stamped");
   711	        }
   712	    }
   713	}

   715	/// Add `forksCleanAt` to the report at `path`, every other field kept: a
   716	/// temporary file, `fsync`, rename, `fsync` the directory.
   717	fn stamp(path: &Path) -> Result<(), String> {
   718	    let bytes = read_regular(path).map_err(|e| format!("not read: {}", e.kind()))?;
   719	    let mut v: serde_json::Value =
   720	        serde_json::from_slice(&bytes).map_err(|e| format!("not parsed: {e}"))?;
   721	    let o = v.as_object_mut().ok_or("not an object")?;
   722	    o.insert("forksCleanAt".into(), now_secs().into());
   723	    let out = serde_json::to_vec_pretty(&v).map_err(|e| e.to_string())?;
   724	    let tmp = with_suffix(path, ".tmp");
   725	    write_synced(&tmp, &out).map_err(|e| format!("not written: {e}"))?;
   726	    std::fs::rename(&tmp, path).map_err(|e| format!("not written: {e}"))?;
   727	    path.parent()
   728	        .map_or(Ok(()), sync_dir)
   729	        .map_err(|e| format!("not synced: {e}"))
   730	}

   732	/// D4: move every `repos/<owner>/.fork-*.tmp` directory older than
   733	/// [`PARTIAL_FORK_AGE`] to `mirror-recovery/<owner>/<entry>.<ts>`. Cleanup
   734	/// only (smart-HTTP refuses such paths), so errors are logged.
   735	fn sweep_partial_forks(plugin: &Path) {
   736	    let Ok(owners) = super::names_in(&plugin.join("repos")) else {
   737	        return;
   738	    };
   739	    for (owner, owner_dir) in owners {
   740	        if !crate::ownership::valid_name_segment(&owner) {
   741	            continue;
   742	        }
   743	        let Ok(entries) = super::names_in(&owner_dir) else {
   744	            continue;
   745	        };
   746	        for (file, entry) in entries {
   747	            if !(file.starts_with(".fork-") && file.ends_with(".tmp")) {
   748	                continue;
   749	            }
   750	            let Ok(meta) = std::fs::symlink_metadata(&entry) else {
   751	                continue;
   752	            };
   753	            let old = meta
   754	                .modified()
   755	                .ok()
   756	                .and_then(|t| t.elapsed().ok())
   757	                .is_some_and(|age| age >= PARTIAL_FORK_AGE);
   758	            if !meta.is_dir() || !old {
   759	                continue;
   760	            }
   761	            let dir = plugin.join("mirror-recovery").join(&owner);
   762	            let dest = dir.join(format!("{file}.{}", now_secs()));
   763	            let moved = std::fs::create_dir_all(&dir)
   764	                .and_then(|()| std::fs::rename(&entry, &dest))
   765	                .and_then(|()| sync_dir(&dir))
   766	                .and_then(|()| sync_dir(&owner_dir));
   767	            match moved {
   768	                Ok(()) => {
   769	                    tracing::info!(owner = %owner, entry = %file, "forge: stale partial fork moved to recovery");
   770	                }
   771	                Err(e) => {
   772	                    tracing::warn!(owner = %owner, entry = %file, error = %e, "forge: stale partial fork not moved");
   773	                }
   774	            }
   775	        }
   776	    }
   777	}

    57	/// `(section, key, value)` triples of a git config file (section and key
    58	/// lowercased).
    59	pub(crate) fn config_entries(conf: &str) -> Vec<(String, String, String)> {
    60	    let mut out = Vec::new();
    61	    let mut section = String::new();
    62	    for raw in conf.lines() {
    63	        let line = raw.trim();
    64	        if line.is_empty() || line.starts_with('#') || line.starts_with(';') {
    65	            continue;
    66	        }
    67	        if let Some(h) = line.strip_prefix('[') {
    68	            let name = h.split(']').next().unwrap_or("");
    69	            section = name
    70	                .split_whitespace()
    71	                .next()
    72	                .unwrap_or("")
    73	                .to_ascii_lowercase();
    74	            continue;
    75	        }
    76	        if let Some((k, v)) = line.split_once('=') {
    77	            out.push((
    78	                section.clone(),
    79	                k.trim().to_ascii_lowercase(),
    80	                v.trim().trim_matches('"').to_string(),
    81	            ));
    82	        }
    83	    }
    84	    out
    85	}

    87	/// Parse `forge.parent` out of a bare repository's config text. The value
    88	/// must be exactly `<owner>/<name>` with both parts passing the name rules
    89	/// (JSS `readForkParent`).
    90	#[must_use]
    91	pub fn parse_fork_parent(conf: &str) -> Option<ForkParent> {
    92	    let (_, _, v) = config_entries(conf)
    93	        .into_iter()
    94	        .find(|(s, k, _)| s == "forge" && k == "parent")?;
    95	    let mut it = v.split('/');
    96	    let (o, n, extra) = (it.next()?, it.next()?, it.next());
    97	    if extra.is_some() || !valid_owner(o) || !valid_repo(n) {
    98	        return None;
    99	    }
   100	    Some(ForkParent {
   101	        owner: o.to_string(),
   102	        name: n.to_string(),
   103	    })
   104	}

   114	/// A store's lineage as the boot migration and the incomplete-pass rule

    37	    /// Marker gate (defence in depth): a served repository with a mirror
    38	    /// record but no [`PUBLICATION_MARKER`] predates candidate isolation
    39	    /// and may hold commits the mirror never approved. A repository with
    40	    /// anything at its migration journal path ([`migrate::journal_path`]),
    41	    /// in any state, `published` included, is refused first, marked or not.
    42	    /// If the boot migration did not complete, every repository under a
    43	    /// 64-hex owner is refused, marked or not, and so is every fork (any
    44	    /// repository whose config names a `forge.parent` or cannot be read). Then one `lstat` for a marked
    45	    /// mirror (the marker must be a regular file) and two for any other
    46	    /// repository. The record path is
    47	    /// `mirror::MirrorStore`'s layout, checked without the `mirror` feature
    48	    /// so a plugin directory that was mirrored once stays gated. `owner` and
    49	    /// `repo` are already validated path segments (`repo::repo_git_dir`).
    50	    /// A record path that cannot be checked (any error but "not found")
    51	    /// keeps the gate closed.
    52	    async fn unpublished_mirror(&self, owner: &str, repo: &str, dir: &Path) -> bool {
    53	        // Decision 21: a migration journal in any state (`published`
    54	        // included, until `finish` removes it), or any entry there, gates the
    55	        // store, marked or not, record or not. This is what keeps a lost-record legacy store
    56	        // whose migration failed from being served.
    57	        if migrate::journal_gates(&self.plugin_dir, owner, repo).await {
    58	            return true;
    59	        }
    60	        // The boot migration did not complete: every store under a 64-hex
    61	        // owner is refused, marked or not (a marked, flagged store may be one
    62	        // detection wanted rebuilt).
    63	        if self.migration_incomplete && mirror_record::is_hex64(owner) {
    64	            return true;
    65	        }
    66	        // Nor every fork (B2): forks live under any owner, and one the pass
    67	        // could not check may still hold a legacy mirror's held objects. A
    68	        // config that cannot be read may be a fork's, and a `forge.parent`
    69	        // that does not parse is a fork of unknown lineage.
    70	        if self.migration_incomplete {
    71	            let dir = dir.to_path_buf();
    72	            let fork_or_unknown = tokio::task::spawn_blocking(move || {
    73	                !matches!(
    74	                    forks::read_lineage_checked(&dir),
    75	                    Ok(forks::StoredLineage::None)
    76	                )
    77	            })
    78	            .await
    79	            .unwrap_or(true);
    80	            if fork_or_unknown {
    81	                return true;
    82	            }
    83	        }
    84	        // The marker is a regular file at the store root, not a symlink: the
    85	        // same test detection applies.
    86	        let marked = tokio::fs::symlink_metadata(dir.join(PUBLICATION_MARKER))
    87	            .await
    88	            .is_ok_and(|m| m.is_file());
    89	        if marked {
    90	            return false;
    91	        }
    92	        self.has_mirror_record(owner, repo).await.unwrap_or(true)
