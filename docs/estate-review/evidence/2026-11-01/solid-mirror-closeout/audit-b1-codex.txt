## Deviations from the design, with reasons

1. **More was hoisted than the list.** The record *types* moved, not only `load`, because migration's verdict must use the engine's parser (see step (a)). `write_marker` moved in (c), and `mirror` delegates to it. A shared `git_command` builder now backs the runner, with the same flags.
2. **Ref names are checked with a pure `safe_ref` function, not by spawning `git check-ref-format` per ref.**
   - The names come from `for-each-ref`, so git has already accepted them.
   - `safe_ref` refuses `:`, `+`-style modifiers, glob characters, `..`, `@{`, control characters and the rest.
   - A ref that fails it is dropped and reported as `unsafe-name`, never pushed.
3. **Resume from `moved` with staging present rebuilds from the recovery copy** instead of re-verifying the old staging. This is simpler and never trusts a partial staging store; the design allows either.
4. **The lock-failure gate journal** is written as `failed` with `attempts: 0`, so an environmental lock failure does not use up retries.
5. **Detection errors leave the store as it is.** If git fails on the trace check, the store is not gated by a new journal, and a warning is logged. Gating on a transient error would put a plain owner store at 503 for good after 3 boots.
6. **Memory.** The held set is capped at `MAX_HELD_IDS` = 16 M, and a store past the cap fails closed. The `.dropped` computation holds staging's object ids, and then the dropped ids, in memory with no cap (risk 2: measure later).
7. **`Detected::Finish`** (marked, flagged, report present) requires only that a `.migration.json` exist. The report is written only after verification passes, and the marker on served is written only by migration or the engine.
8. **Test 1's smart-HTTP check is fetch-by-want only.** It does not clone and then run `cat-file`. The object-store assertion (`cat-file -e <held>` fails in served) is the stronger proof (decision 15).
9. **Test 16 lives in the forge crate**: a self-spawning lib test with two real processes, not a server integration test. It therefore runs in gates 2 to 4, and gate 5's filter does not apply to it.
10. **CHANGELOG.** Part 2 is added under Security, and the new module under Changed. Part 1's sentence "Repositories mirrored before this change are not migrated yet…" was left as A wrote it, because it is A's entry. The lead may want to reword it, since forks are still not swept.

## Observations for the lead

- **Operator recourse after 3 failed attempts is not implemented.** Design §6's fsck runbook (a second fixed receive-pack constant with `receive.fsck.<id>=ignore`) is not in B1. The store stays at 503 behind its `failed` journal. +//! Boot migration of pre-release served stores, and the served-store
+//! plumbing it shares with the mirror engine. Kept outside the `mirror`
+//! feature: a plugin directory that was mirrored once must be migrated even
+//! when it is now served without the feature.
+//!
+//! # Shared plumbing
+//!
+//! The fixed `--receive-pack` command ([`RECEIVE_PACK`]), the fixed served
+//! config ([`SERVED_CONFIG`]), the cross-process lock path ([`lock_path`]),
+//! the legacy-config probe and the hardened, process-group `git` runner.
+//!
+//! # Migration
+//!
+//! [`crate::ForgeService::new`] runs it before returning. A mirror-class
+//! store (a 64-hex owner) is migrated when it has no
+//! [`crate::PUBLICATION_MARKER`] and shows any pre-release signal: a mirror
+//! record that is flagged, pre-release or unreadable; `refs/mirror/*`;
+//! `hideRefs` naming them; alternates; or an earlier migration report. Under
+//! the store's lock, with a journal ([`journal_path`]) recording each step:
+//!
+//! 1. a fresh store is initialised in `plugin_dir/mirror-work/staging/`;
+//! 2. every ref but `refs/mirror/*` and `refs/forge/heads/*` is pushed into
+//!    it by SHA from the old store, except a ref outside branches and tags
+//!    that reaches a *held* object (one the `refs/mirror` tips reach and no
+//!    branch or tag does);
+//! 3. it is verified at object level (no held object, no alternates, no
+//!    object file shared with the old store) and marked;
+//! 4. a report is written beside the recovery path
+//!    (`<name>.git.<ts>.migration.json`, `.held`, `.dropped`);
+//! 5. the old store is renamed to `plugin_dir/mirror-recovery/<owner>/<name>.git.<ts>`
+//!    and the new one into `repos/`;
+//! 6. the record's awaits-migration flag is removed, the candidate wiped and
+//!    the journal deleted.
+//!
+//! A crash at any step is resumed at the next boot. A failure leaves the old
+//! store in place behind a `failed` journal, which keeps every reader
+//! refusing it (503); after [`MAX_ATTEMPTS`] failures boot stops retrying.
+//! Recovery copies are never deleted automatically and must never be served:
+//! do not add `.forge` to the pod's dotfile allowlist.

+    Some(
+        plugin_dir
+            .join("mirror-work")
+            .join("migrations")
+            .join(owner)
+            .join(format!("{name}.json")),
+    )
+}
+
+/// The stage a migration reached, as its journal records it.
+#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
+#[serde(rename_all = "kebab-case")]
+enum Stage {
+    /// Staging is being built; the old store is still in `repos/`.
+    Building,
+    /// Staging passed verification and is marked; the old store is still in
+    /// `repos/`.
+    Verified,
+    /// The old store has been moved to recovery; `repos/` has no store.
+    Moved,
+    /// The rebuilt store is in `repos/`; the record flag, the candidate and
+    /// the journal remain to be cleared.
+    Published,
+    /// The last attempt failed; see the reason and the attempt count.
+    Failed,
+}
+
+/// The migration journal of one store (see [`journal_path`]). Paths are
+/// relative to the plugin directory.
+#[derive(Debug, Clone, Serialize, Deserialize)]
+#[serde(rename_all = "camelCase")]
+struct Journal {
+    id: String,
+    ts: u64,
+    class: String,
+    state: Stage,
+    #[serde(default, skip_serializing_if = "Option::is_none")]
+    staging: Option<String>,
+    recovery: String,
+    #[serde(default)]
+    attempts: u32,
+    #[serde(default, skip_serializing_if = "Option::is_none")]
+    reason: Option<String>,
+}
+
+/// Whether a reader must refuse `<owner>/<name>` because of its migration
+/// journal: one exists in any state but `published`, or cannot be read.
+/// "Not found" is the only answer that lets the reader go on (decision 21).
+pub(crate) async fn journal_gates(plugin_dir: &Path, owner: &str, name: &str) -> bool {
+    let Some(path) = journal_path(plugin_dir, owner, name) else {
+        return false;
+    };
+    match tokio::fs::read(&path).await {
+        Ok(bytes) => !matches!(
+            serde_json::from_slice::<Journal>(&bytes),
+            Ok(Journal {
+                state: Stage::Published,
+                ..
+            })
+        ),
+        Err(e) => e.kind() != std::io::ErrorKind::NotFound,
+    }
+}
+
+/// Whether any migration journal exists for `<owner>/<name>`, in any state
+/// (the tombstone). An entry that cannot be checked counts as present.
+pub(crate) fn journal_exists(plugin_dir: &Path, owner: &str, name: &str) -> bool {
+    let Some(path) = journal_path(plugin_dir, owner, name) else {
+        return false;
+    };
+    match std::fs::symlink_metadata(path) {
+        Ok(_) => true,
+        Err(e) => e.kind() != std::io::ErrorKind::NotFound,
+    }
+}
+
+/// Migrate every pre-release served store under `plugin_dir`, synchronously.
+///
+/// Runs on a dedicated thread with its own current-thread `tokio` runtime and
+/// joins it, so it behaves the same from plain synchronous code, from inside
+/// actix's current-thread runtime and from a `#[tokio::test]`: no
+/// `block_in_place`, no nested `block_on` on the caller's thread. A failure to
+/// migrate one store is logged and leaves that store gated; it never fails
+/// the caller.
+pub(crate) fn run_at_boot(plugin_dir: &Path) {
+    let plugin = std::path::absolute(plugin_dir).unwrap_or_else(|_| plugin_dir.to_path_buf());
+    std::thread::scope(|scope| {
+        let worker = scope.spawn(|| {
+            match tokio::runtime::Builder::new_current_thread()
+                .enable_all()
+                .build()
+            {
+                Ok(rt) => rt.block_on(run(&plugin)),
+                Err(e) => tracing::error!(error = %e, "forge: migration runtime not built; legacy stores stay as they are"),
+            }
+        });
+        if worker.join().is_err() {
+            tracing::error!("forge: the migration thread panicked");
+        }
+    });
+}
+
+/// One boot pass: resume every journal, then migrate every store detected as
+/// needing it. Serial, one lock at a time.
+async fn run(plugin: &Path) {
+    let started = std::time::Instant::now();
+    let mut done = 0usize;
+    let mut failed = 0usize;
+    let mut seen = std::collections::BTreeSet::new();
+    for (owner, name) in journaled(plugin).await {
+        seen.insert((owner.clone(), name.clone()));
+        match migrate_one(plugin, &owner, &name).await {
+            Outcome::Migrated => done += 1,
+            Outcome::Failed => failed += 1,
+            Outcome::Skipped => {}
+        }
+    }
+    for (owner, name) in crate::repo::list_all(&plugin.join("repos")).await {
+        if seen.contains(&(owner.clone(), name.clone())) {
+            continue;
+        }
+        if matches!(detect(plugin, &owner, &name).await, Detected::None) {
+            continue;
+        }
+        match migrate_one(plugin, &owner, &name).await {
+            Outcome::Migrated => done += 1,
+            Outcome::Failed => failed += 1,
+            Outcome::Skipped => {}
+        }
+    }
+    if done + failed > 0 {
+        tracing::info!(
+            migrated = done,
+            failed,
+            ms = u64::try_from(started.elapsed().as_millis()).unwrap_or(u64::MAX),
+            "forge: legacy served stores migrated"
+        );
+    }
+}
+
+/// What one store's pass came to.
+#[derive(Debug, Clone, Copy, PartialEq, Eq)]
+enum Outcome {
+    Migrated,
+    Failed,
+    Skipped,
+}
+
+/// Every `(owner, name)` with a journal file.
+async fn journaled(plugin: &Path) -> Vec<(String, String)> {
+    let mut out = Vec::new();
+    let root = plugin.join("mirror-work").join("migrations");
+    let Ok(mut owners) = tokio::fs::read_dir(&root).await else {
+        return out;
+    };
+    while let Ok(Some(o)) = owners.next_entry().await {
+        let owner = o.file_name().to_string_lossy().into_owned();
+        if !valid_name_segment(&owner) {
+            continue;
+        }
+        let Ok(mut files) = tokio::fs::read_dir(o.path()).await else {
+            continue;
+        };
+        while let Ok(Some(f)) = files.next_entry().await {
+            let file = f.file_name().to_string_lossy().into_owned();
+            if let Some(name) = file.strip_suffix(".json") {
+                if valid_name_segment(name) {
+                    out.push((owner.clone(), name.to_string()));
+                }
+            }
+        }
+    }
+    out.sort();
+    out
+}
+
+/// What detection found for one store.
+#[derive(Debug, Clone, Copy, PartialEq, Eq)]
+enum Detected {
+    /// Nothing to do.
+    None,
+    /// A legacy store: rebuild it.
+    Rebuild,
+    /// Already rebuilt and marked, but the record still carries the flag
+    /// (a crash after the journal was removed, or an engine write in
+    /// between): finish only.
+    Finish,
+}
+
+/// Paths of one store under the plugin directory.
+struct Paths {
+    served: PathBuf,
+    staging_dir: PathBuf,
+    recovery_dir: PathBuf,
+    journal: PathBuf,
+    lock: PathBuf,
+    candidate: PathBuf,
+}
+
+impl Paths {
+    fn of(plugin: &Path, owner: &str, name: &str) -> Option<Self> {
+        Some(Self {
+            served: plugin.join("repos").join(owner).join(format!("{name}.git")),
+            staging_dir: plugin.join("mirror-work").join("staging").join(owner),
+            recovery_dir: plugin.join("mirror-recovery").join(owner),
+            journal: journal_path(plugin, owner, name)?,
+            lock: lock_path(plugin, owner, name)?,
+            candidate: plugin
+                .join("mirror-work")
+                .join("candidates")
+                .join(owner)
+                .join(format!("{name}.git")),
+        })
+    }
+}
+
+fn is_dir(p: &Path) -> bool {
+    std::fs::metadata(p).is_ok_and(|m| m.is_dir())
+}
+
+/// Whether a migration report exists for `<owner>/<name>` in recovery.
+fn has_report(recovery_dir: &Path, name: &str) -> bool {
+    let Ok(entries) = std::fs::read_dir(recovery_dir) else {
+        return false;
+    };
+    let prefix = format!("{name}.git.");
+    entries.flatten().any(|e| {
+        let f = e.file_name();
+        let f = f.to_string_lossy();
+        f.strip_prefix(&prefix)
+            .and_then(|rest| rest.strip_suffix(".migration.json"))
+            .is_some_and(|ts| !ts.is_empty() && ts.bytes().all(|b| b.is_ascii_digit()))
+    })
+}
+
+/// Legacy detection for a mirror-class store (64-hex owner): unmarked and
+/// showing any pre-release signal. A check that cannot be made is logged and
+/// the store is left as it is this boot.
+async fn detect(plugin: &Path, owner: &str, name: &str) -> Detected {
+    if !is_hex64(owner) || !is_repo_name(name) {
+        return Detected::None;
+    }
+    let Some(p) = Paths::of(plugin, owner, name) else {
+        return Detected::None;
+    };
+    if !is_dir(&p.served) {
+        return Detected::None;
+    }
+    let record = MirrorStore::new(plugin).load(owner, name);
+    if std::fs::metadata(p.served.join(crate::PUBLICATION_MARKER)).is_ok_and(|m| m.is_file()) {
+        let flagged = matches!(&record, StoredRecord::Valid(r) if r.awaits_migration);
+        return if flagged && has_report(&p.recovery_dir, name) {
+            Detected::Finish
+        } else {
+            Detected::None
+        };
+    }
+    match &record {
+        StoredRecord::Valid(r) if r.awaits_migration || !r.isolated => return Detected::Rebuild,
+        StoredRecord::Unreadable(_) => return Detected::Rebuild,
+        StoredRecord::Valid(_) | StoredRecord::Missing => {}
+    }
+    match legacy_traces(&p.served).await {
+        Ok(true) => return Detected::Rebuild,
+        Ok(false) => {}
+        Err(e) => {
+            tracing::warn!(owner = %owner, name = %name, error = %e, "forge: legacy check failed; store left as it is");
+            return Detected::None;
+        }
+    }
+    if has_report(&p.recovery_dir, name) {
+        return Detected::Rebuild;
+    }
+    Detected::None
+}
+
+/// `refs/mirror/*`, `hideRefs` naming them, or alternates.
+async fn legacy_traces(served: &Path) -> Result<bool, String> {
+    let quick = Duration::from_secs(15);
+    let info = served.join("objects").join("info");
+    for file in ["alternates", "http-alternates"] {
+        match tokio::fs::symlink_metadata(info.join(file)).await {
+            Ok(_) => return Ok(true),
+            Err(e) if e.kind() == std::io::ErrorKind::NotFound => {}
+            Err(e) => return Err(format!("the alternates check failed: {}", e.kind())),
+        }
+    }
+    let refs = run_in(
+        served,
+        served,
+        &[
+            "for-each-ref",
+            "--count=1",
+            "--format=%(refname)",
+            "refs/mirror",
+        ],
+        None,
+        quick,
+        None,
+    )
+    .await?;
+    if !refs.is_empty() {
+        return Ok(true);
+    }
+    let config = run_in(
+        served,
+        served,
+        &["config", "--local", "--list", "-z"],
+        None,
+        quick,
+        None,
+    )
+    .await?;
+    Ok(hides_mirror_refs(&config))
+}
+
+fn now_secs() -> u64 {
+    std::time::SystemTime::now()
+        .duration_since(std::time::UNIX_EPOCH)
+        .map_or(0, |d| d.as_secs())
+}
+
+/// Read a journal: `None` when absent, `Some(Err)` when present but not
+/// readable as a journal.
+fn read_journal(path: &Path) -> Option<Result<Journal, String>> {
+    match std::fs::read(path) {
+        Ok(bytes) => Some(serde_json::from_slice(&bytes).map_err(|e| e.to_string())),
+        Err(e) if e.kind() == std::io::ErrorKind::NotFound => None,
+        Err(e) => Some(Err(format!("cannot be read: {}", e.kind()))),
+    }
+}
+
+/// Write a journal atomically (temporary file, then rename).
+fn write_journal(path: &Path, j: &Journal) -> Result<(), String> {
+    if let Some(parent) = path.parent() {
+        std::fs::create_dir_all(parent).map_err(|e| format!("journal directory: {e}"))?;
+    }
+    let tmp = path.with_extension("json.tmp");
+    let bytes = serde_json::to_vec_pretty(j).map_err(|e| e.to_string())?;
+    std::fs::write(&tmp, bytes).map_err(|e| format!("journal not written: {e}"))?;
+    std::fs::rename(&tmp, path).map_err(|e| format!("journal not written: {e}"))
+}
+
+/// Take the store's cross-process lock (blocking, off the runtime).
+async fn take_lock(path: PathBuf) -> std::io::Result<std::fs::File> {
+    tokio::task::spawn_blocking(move || {
+        if let Some(parent) = path.parent() {
+            std::fs::create_dir_all(parent)?;
+        }
+        let file = std::fs::OpenOptions::new()
+            .create(true)
+            .write(true)
+            .truncate(false)
+            .open(&path)?;
+        file.lock()?;
+        Ok(file)
+    })
+    .await
+    .map_err(std::io::Error::other)?
+}
+
+/// A fresh recovery stem `<name>.git.<ts>` that names nothing yet.
+fn fresh_recovery(plugin: &Path, p: &Paths, name: &str) -> (u64, String) {
+    let mut ts = now_secs();
+    loop {
+        let stem = format!("{name}.git.{ts}");
+        let taken = p.recovery_dir.join(&stem).exists()
+            || p.recovery_dir
+                .join(format!("{stem}.migration.json"))
+                .exists();
+        if !taken {
+            let rel = p
+                .recovery_dir
+                .join(&stem)
+                .strip_prefix(plugin)
+                .map_or_else(|_| p.recovery_dir.join(&stem), Path::to_path_buf);
+            return (ts, rel.to_string_lossy().into_owned());
+        }
+        ts += 1;
+    }
+}
+
+/// Migrate (or resume, or finish) one store under its lock.
+async fn migrate_one(plugin: &Path, owner: &str, name: &str) -> Outcome {
+    let Some(p) = Paths::of(plugin, owner, name) else {
+        return Outcome::Skipped;
+    };
+    let _lock = match take_lock(p.lock.clone()).await {
+        Ok(f) => f,
+        Err(e) => {
+            // No lock: still gate the store (a journal only adds denial),
+            // unless a journal already does.
+            tracing::error!(owner = %owner, name = %name, error = %e, "forge: migration lock not taken; store gated");
+            if read_journal(&p.journal).is_none() {
+                let (ts, recovery) = fresh_recovery(plugin, &p, name);
+                let j = Journal {
+                    id: uuid::Uuid::new_v4().simple().to_string(),
+                    ts,
+                    class: "mirror".into(),
+                    state: Stage::Failed,
+                    staging: None,
+                    recovery,
+                    attempts: 0,
+                    reason: Some(format!(
+                        "the migration lock could not be taken: {}",
+                        e.kind()
+                    )),
+                };
+                if let Err(w) = write_journal(&p.journal, &j) {
+                    tracing::error!(owner = %owner, name = %name, error = %w, "forge: gate journal not written");
+                }
+            }
+            return Outcome::Failed;
+        }
+    };
+    // Re-read everything under the lock: another instance may have finished.
+    let journal = match read_journal(&p.journal) {
+        Some(Ok(j)) => j,
+        Some(Err(e)) => {
+            tracing::error!(owner = %owner, name = %name, error = %e, "forge: migration journal unreadable; store stays gated");
+            return Outcome::Failed;
+        }
+        None => match detect(plugin, owner, name).await {
+            Detected::None => return Outcome::Skipped,
+            Detected::Finish => {
+                return match finish(plugin, &p, owner, name) {
+                    Ok(()) => Outcome::Migrated,
+                    Err(e) => {
+                        tracing::error!(owner = %owner, name = %name, error = %e, "forge: migration not finished");
+                        Outcome::Failed
+                    }
+                }
+            }
+            Detected::Rebuild => {
+                let (ts, recovery) = fresh_recovery(plugin, &p, name);
+                Journal {
+                    id: uuid::Uuid::new_v4().simple().to_string(),
+                    ts,
+                    class: "mirror".into(),
+                    state: Stage::Building,
+                    staging: None,
+                    recovery,
+                    attempts: 0,
+                    reason: None,
+                }
+            }
+        },
+    };
+    let recovery = plugin.join(&journal.recovery);
+    match journal.state {
+        Stage::Published => {
+            return match finish(plugin, &p, owner, name) {
+                Ok(()) => Outcome::Migrated,
+                Err(e) => {
+                    tracing::error!(owner = %owner, name = %name, error = %e, "forge: migration not finished");
+                    Outcome::Failed
+                }
+            };
+        }
+        Stage::Failed if journal.attempts >= MAX_ATTEMPTS => {
+            tracing::warn!(owner = %owner, name = %name, attempts = journal.attempts, "forge: migration gave up; store stays gated");
+            return Outcome::Failed;
+        }
+        Stage::Moved if is_dir(&p.served) && is_dir(&recovery) => {
+            // Something created the store in the gap despite the tombstone:
+            // never overwrite it. Set staging aside and leave the journal.
+            if let Some(s) = journal.staging.as_deref().map(|s| plugin.join(s)) {
+                if is_dir(&s) {
+                    let aside = PathBuf::from(format!("{}.rebuilt", recovery.display()));
+                    let _ = std::fs::rename(&s, aside);
+                }
+            }
+            tracing::error!(owner = %owner, name = %name, "forge: a store appeared during migration; left for the operator");
+            return Outcome::Failed;
+        }
+        _ => {}
+    }
+    rebuild(plugin, &p, owner, name, journal).await
+}
+
+/// `p` relative to the plugin directory, for the journal.
+fn relative(plugin: &Path, p: &Path) -> String {
+    p.strip_prefix(plugin)
+        .unwrap_or(p)
+        .to_string_lossy()
+        .into_owned()
+}
+
+/// `msg` with the plugin directory replaced by `<plugin>`.
+fn redact(plugin: &Path, msg: &str) -> String {
+    match plugin.to_str() {
+        Some(s) if s.len() > 1 => msg.replace(s, "<plugin>"),
+        _ => msg.to_string(),
+    }
+}
+
+/// `base` with `suffix` appended to its last component.
+fn with_suffix(base: &Path, suffix: &str) -> PathBuf {
+    let mut s = base.as_os_str().to_os_string();
+    s.push(suffix);
+    PathBuf::from(s)
+}
+
+/// Record a failed attempt in the journal; the store stays gated.
+fn fail(plugin: &Path, p: &Paths, owner: &str, name: &str, mut j: Journal, why: &str) -> Outcome {
+    let why = redact(plugin, why);
+    j.state = Stage::Failed;
+    j.attempts = j.attempts.saturating_add(1);
+    j.reason = Some(why.clone());
+    if let Err(e) = write_journal(&p.journal, &j) {
+        tracing::error!(owner = %owner, name = %name, error = %e, "forge: migration journal not written");
+    }
+    tracing::error!(owner = %owner, name = %name, attempts = j.attempts, error = %why, "forge: migration failed; store stays gated");
+    Outcome::Failed
+}
+
+/// Remove every staging store of `<name>` (safe under the lock: the engine
+/// builds staging under the same lock).
+async fn clear_staging(staging_dir: &Path, name: &str) {
+    let Ok(mut entries) = tokio::fs::read_dir(staging_dir).await else {
+        return;
+    };
+    let prefix = format!("{name}.git.");
+    while let Ok(Some(e)) = entries.next_entry().await {
+        if e.file_name().to_string_lossy().starts_with(&prefix) {
+            if let Err(err) = tokio::fs::remove_dir_all(e.path()).await {
+                tracing::warn!(error = %err, "forge: stale staging store not removed");
+            }
+        }
+    }
+}
+
+/// Rebuild one store from its old store (in `repos/`, or already moved to
+/// recovery), verify, report, swap and finish.
+async fn rebuild(plugin: &Path, p: &Paths, owner: &str, name: &str, mut j: Journal) -> Outcome {
+    let started = std::time::Instant::now();
+    let recovery = plugin.join(&j.recovery);
+    let moved = !is_dir(&p.served);
+    if moved && !is_dir(&recovery) {
+        return fail(
+            plugin,
+            p,
+            owner,
+            name,
+            j,
+            "neither the served store nor its recovery copy exists",
+        );
+    }
+    let source = if moved {
+        recovery.clone()
+    } else {
+        p.served.clone()
+    };
+    clear_staging(&p.staging_dir, name).await;
+    let staging = p
+        .staging_dir
+        .join(format!("{name}.git.{}", uuid::Uuid::new_v4().simple()));
+    j.state = Stage::Building;
+    j.staging = Some(relative(plugin, &staging));
+    if let Err(e) = write_journal(&p.journal, &j) {
+        tracing::error!(owner = %owner, name = %name, error = %e, "forge: migration journal not written; store not migrated");
+        return Outcome::Failed;
+    }
+    let record_bytes = match MirrorStore::new(plugin).load(owner, name) {
+        StoredRecord::Unreadable(_) => MirrorStore::new(plugin)
+            .file(owner, name)
+            .map(|f| std::fs::read(f).map_err(|e| e.kind().to_string())),
+        _ => None,
+    };
+    let built = match tokio::time::timeout(STORE_BUDGET, build(&source, &staging)).await {
+        Ok(Ok(b)) => b,
+        Ok(Err(e)) => {
+            remove_dir(&staging).await;
+            return fail(plugin, p, owner, name, j, &e);
+        }
+        Err(_) => {
+            remove_dir(&staging).await;
+            return fail(
+                plugin,
+                p,
+                owner,
+                name,
+                j,
+                "the migration ran past its time budget",
+            );
+        }
+    };
+    if let Err(e) = write_marker(&staging).await {
+        remove_dir(&staging).await;
+        return fail(plugin, p, owner, name, j, &e);
+    }
+    j.state = Stage::Verified;
+    if let Err(e) = write_journal(&p.journal, &j) {
+        remove_dir(&staging).await;
+        return fail(plugin, p, owner, name, j, &e);
+    }
+    if let Err(e) = write_report(plugin, &recovery, owner, name, &built, record_bytes) {
+        remove_dir(&staging).await;
+        return fail(plugin, p, owner, name, j, &e);
+    }
+    if !moved {
+        if let Err(e) = std::fs::create_dir_all(&p.recovery_dir)
+            .and_then(|()| std::fs::rename(&p.served, &recovery))
+        {
+            remove_dir(&staging).await;
+            return fail(
+                plugin,
+                p,
+                owner,
+                name,
+                j,
+                &format!("the old store was not moved: {e}"),
+            );
+        }
+        j.state = Stage::Moved;
+        if let Err(e) = write_journal(&p.journal, &j) {
+            tracing::error!(owner = %owner, name = %name, error = %e, "forge: migration journal not written");
+        }
+    }
+    let placed = p
+        .served
+        .parent()
+        .map_or(Ok(()), std::fs::create_dir_all)
+        .and_then(|()| std::fs::rename(&staging, &p.served));
+    if let Err(e) = placed {
+        return fail(
+            plugin,
+            p,
+            owner,
+            name,
+            j,
+            &format!("the rebuilt store was not placed: {e}"),
+        );
+    }
+    j.state = Stage::Published;
+    if let Err(e) = write_journal(&p.journal, &j) {
+        tracing::error!(owner = %owner, name = %name, error = %e, "forge: migration journal not written");
+    }
+    if let Err(e) = finish(plugin, p, owner, name) {
+        tracing::error!(owner = %owner, name = %name, error = %e, "forge: migration published but not finished");
+        return Outcome::Failed;
+    }
+    tracing::info!(
+        owner = %owner,
+        name = %name,
+        ms = u64::try_from(started.elapsed().as_millis()).unwrap_or(u64::MAX),
+        copied = built.copied.len(),
+        dropped = built.dropped.len(),
+        held = built.held.len(),
+        "forge: migrated"
+    );
+    Outcome::Migrated
+}

+async fn remove_dir(dir: &Path) {
+    if let Err(e) = tokio::fs::remove_dir_all(dir).await {
+        if e.kind() != std::io::ErrorKind::NotFound {
+            tracing::warn!(error = %e, "forge: staging store not removed");
+        }
+    }
+}

+/// Steps 10 to 12: clear the record's awaits-migration flag (editing the
+/// JSON, every other field unchanged), wipe the candidate, delete the
+/// journal. An unreadable record is left as it is.
+fn finish(plugin: &Path, p: &Paths, owner: &str, name: &str) -> Result<(), String> {
+    let store = MirrorStore::new(plugin);
+    if let StoredRecord::Valid(r) = store.load(owner, name) {
+        if r.awaits_migration {
+            let file = store.file(owner, name).ok_or("unsafe record key")?;
+            let bytes = std::fs::read(&file).map_err(|e| format!("record not read: {e}"))?;
+            let mut v: serde_json::Value =
+                serde_json::from_slice(&bytes).map_err(|e| format!("record not parsed: {e}"))?;
+            if let Some(o) = v.as_object_mut() {
+                o.remove(AWAITS_MIGRATION_KEY);
+            }
+            let tmp = file.with_extension("json.tmp");
+            let out = serde_json::to_vec_pretty(&v).map_err(|e| e.to_string())?;
+            std::fs::write(&tmp, out).map_err(|e| format!("record not written: {e}"))?;
+            std::fs::rename(&tmp, &file).map_err(|e| format!("record not written: {e}"))?;
+        }
+    }
+    if let Err(e) = std::fs::remove_dir_all(&p.candidate) {
+        if e.kind() != std::io::ErrorKind::NotFound {
+            tracing::warn!(owner = %owner, name = %name, error = %e, "forge: candidate not removed after migration");
+        }
+    }
+    match std::fs::remove_file(&p.journal) {
+        Ok(()) => Ok(()),
+        Err(e) if e.kind() == std::io::ErrorKind::NotFound => Ok(()),
+        Err(e) => Err(format!("journal not removed: {e}")),
+    }
+}

+/// A ref left out of the rebuilt store, and why.
+#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
+struct DroppedRef {
+    #[serde(rename = "ref")]
+    name: String,
+    sha: String,
+    reason: &'static str,
+}

+/// What [`build`] made.
+#[derive(Debug, Default)]
+struct Built {
+    /// Refs copied into staging, by name.
+    copied: BTreeMap<String, String>,
+    /// Refs left out.
+    dropped: Vec<DroppedRef>,
+    /// The held set, sorted.
+    held: Vec<String>,
+    /// Every object of the source absent from staging, sorted.
+    dropped_objects: Vec<String>,
+    /// The `HEAD` set in staging.
+    head: Option<String>,
+}

+/// Whether `r` is a ref name safe on a push command line. The names come from
+/// `for-each-ref`, so git already accepted them; this refuses anything that
+/// could be read as an option or a refspec modifier all the same.
+fn safe_ref(r: &str) -> bool {
+    r.starts_with("refs/")
+        && r.len() <= 1024
+        && !r.ends_with('/')
+        && !r.ends_with('.')
+        && !r.ends_with(".lock")
+        && !r.contains("..")
+        && !r.contains("//")
+        && !r.contains("/.")
+        && !r.contains("@{")
+        && r.bytes().all(|b| {
+            b > b' ' && b != 0x7f && !matches!(b, b'~' | b'^' | b':' | b'?' | b'*' | b'[' | b'\\')
+        })
+}
+
+fn is_sha40(s: &str) -> bool {
+    s.len() == 40
+        && s.bytes()
+            .all(|b| b.is_ascii_digit() || (b'a'..=b'f').contains(&b))
+}

+/// Steps 3 to 7 and the dropped set: initialise staging with the fixed
+/// served config, choose the refs, push them by SHA from `source`, set
+/// `HEAD`, verify, and list what was left behind.
+async fn build(source: &Path, staging: &Path) -> Result<Built, String> {
+    init_bare(staging).await?;
+    write_served_config(staging).await?;
+    let listing = run_in(
+        source,
+        source,
+        &["for-each-ref", "--format=%(objectname) %(refname)"],
+        None,
+        STORE_BUDGET,
+        None,
+    )
+    .await?;
+    let refs: Vec<(String, String)> = String::from_utf8_lossy(&listing)
+        .lines()
+        .filter_map(|l| l.split_once(' '))
+        .map(|(sha, r)| (sha.to_string(), r.to_string()))
+        .collect();
+    let held = held_set(
+        source,
+        refs.iter().any(|(_, r)| r.starts_with("refs/mirror/")),
+    )
+    .await?;
+    let mut built = Built::default();
+    for (sha, r) in refs {
+        let reason = if !safe_ref(&r) || !is_sha40(&sha) {
+            Some("unsafe-name")
+        } else if r.starts_with("refs/mirror/") {
+            Some("mirror")
+        } else if r.starts_with("refs/forge/heads/") {
+            Some("pull-request-head")
+        } else if r.starts_with("refs/heads/") || r.starts_with("refs/tags/") {
+            None
+        } else if !held.is_empty() && reaches_held(source, &sha, &held).await? {
+            Some("reaches-held")
+        } else {
+            None
+        };
+        match reason {
+            Some(reason) => built.dropped.push(DroppedRef {
+                name: r,
+                sha,
+                reason,
+            }),
+            None => {
+                built.copied.insert(r, sha);
+            }
+        }
+    }
+    push_refs(source, staging, &built.copied).await?;
+    built.head = choose_head(source, &built.copied).await?;
+    if let Some(h) = &built.head {
+        run_in(
+            staging,
+            staging,
+            &["symbolic-ref", "HEAD", h],
+            None,
+            Duration::from_secs(15),
+            None,
+        )
+        .await?;
+    }
+    verify(source, staging, &built.copied, &held).await?;
+    built.dropped_objects = dropped_objects(source, staging).await?;
+    let mut held: Vec<String> = held.into_iter().collect();
+    held.sort();
+    built.held = held;
+    Ok(built)
+}
+
+/// The held set of a mirror-class store (design §2.4): every object the
+/// `refs/mirror/*` tips reach that no branch or tag reaches, minus the full
+/// closure of the branches and tags. Empty when there are no such tips.
+async fn held_set(source: &Path, has_mirror_refs: bool) -> Result<HashSet<String>, String> {
+    let mut held = HashSet::new();
+    if !has_mirror_refs {
+        return Ok(held);
+    }
+    for_each_line(
+        source,
+        &[
+            "rev-list",
+            "--objects",
+            "--no-object-names",
+            "--glob=refs/mirror",
+            "--not",
+            "--branches",
+            "--tags",
+        ],
+        STORE_BUDGET,
+        |id| {
+            if held.len() >= MAX_HELD_IDS {
+                return Err(format!("the held set passed {MAX_HELD_IDS} objects"));
+            }
+            held.insert(id.to_string());
+            Ok(())
+        },
+    )
+    .await?;
+    if held.is_empty() {
+        return Ok(held);
+    }
+    for_each_line(
+        source,
+        &[
+            "rev-list",
+            "--objects",
+            "--no-object-names",
+            "--branches",
+            "--tags",
+        ],
+        STORE_BUDGET,
+        |id| {
+            held.remove(id);
+            Ok(())
+        },
+    )
+    .await?;
+    Ok(held)
+}
+
+/// Whether anything `sha` reaches beyond the branches and tags is held.
+async fn reaches_held(source: &Path, sha: &str, held: &HashSet<String>) -> Result<bool, String> {
+    first_line(
+        source,
+        &[
+            "rev-list",
+            "--objects",
+            "--no-object-names",
+            sha,
+            "--not",
+            "--branches",
+            "--tags",
+        ],
+        STORE_BUDGET,
+        |id| held.contains(id),
+    )
+    .await
+    .map(|hit| hit.is_some())
+}

+/// Push exactly `refs` (name to SHA) from `source` into the empty `staging`,
+/// by SHA, in batches, with the fixed receive-pack and no hooks.
+async fn push_refs(
+    source: &Path,
+    staging: &Path,
+    refs: &BTreeMap<String, String>,
+) -> Result<(), String> {
+    let target = staging.to_str().ok_or("non-UTF-8 staging path")?;
+    let specs: Vec<String> = refs.iter().map(|(r, sha)| format!("{sha}:{r}")).collect();
+    let receive = format!("--receive-pack={RECEIVE_PACK}");
+    for batch in specs.chunks(PUSH_BATCH) {
+        let mut args: Vec<&str> = vec![
+            "-c",
+            "push.gpgSign=false",
+            "-c",
+            "push.followTags=false",
+            "-c",
+            "push.recurseSubmodules=no",
+            "push",
+            "--porcelain",
+            "--no-verify",
+            &receive,
+            "--",
+            target,
+        ];
+        args.extend(batch.iter().map(String::as_str));
+        let out = run_output(source, source, &args, Some("file"), STORE_BUDGET, None).await?;
+        if !out.status.success() {
+            let err = String::from_utf8_lossy(&out.stderr);
+            let lines: Vec<&str> = err
+                .lines()
+                .map(str::trim)
+                .filter(|l| !l.is_empty())
+                .take(4)
+                .collect();
+            return Err(format!("push into staging failed: {}", lines.join(" | ")));
+        }
+    }
+    Ok(())
+}

+/// `HEAD` for the rebuilt store: the source's symbolic `HEAD` if it names a
+/// copied branch, else `refs/heads/main` if copied, else the first copied
+/// branch, else none.
+async fn choose_head(
+    source: &Path,
+    copied: &BTreeMap<String, String>,
+) -> Result<Option<String>, String> {
+    let out = run_output(
+        source,
+        source,
+        &["symbolic-ref", "-q", "HEAD"],
+        None,
+        Duration::from_secs(15),
+        None,
+    )
+    .await?;
+    let named = String::from_utf8_lossy(&out.stdout).trim().to_string();
+    if out.status.success() && named.starts_with("refs/heads/") && copied.contains_key(&named) {
+        return Ok(Some(named));
+    }
+    if copied.contains_key("refs/heads/main") {
+        return Ok(Some("refs/heads/main".into()));
+    }
+    Ok(copied
+        .keys()
+        .find(|r| r.starts_with("refs/heads/"))
+        .cloned())
+}

+/// Step 7, failing closed on any miss: every staging ref is exactly the one
+/// chosen, no held object is present, nothing is borrowed through
+/// alternates, and no object file is shared with the source.
+pub(crate) async fn verify(
+    source: &Path,
+    staging: &Path,
+    want: &BTreeMap<String, String>,
+    held: &HashSet<String>,
+) -> Result<(), String> {
+    let listing = run_in(
+        staging,
+        staging,
+        &["for-each-ref", "--format=%(refname) %(objectname)"],
+        None,
+        STORE_BUDGET,
+        None,
+    )
+    .await?;
+    let got: BTreeMap<String, String> = String::from_utf8_lossy(&listing)
+        .lines()
+        .filter_map(|l| l.split_once(' '))
+        .map(|(r, sha)| (r.to_string(), sha.to_string()))
+        .collect();
+    if &got != want {
+        return Err("the rebuilt store's refs differ from the refs chosen".into());
+    }
+    if !held.is_empty() {
+        let present = present_count(staging, held).await?;
+        if present > 0 {
+            return Err(format!("{present} held objects reached the rebuilt store"));
+        }
+    }
+    let info = staging.join("objects").join("info");
+    for file in ["alternates", "http-alternates"] {
+        match std::fs::symlink_metadata(info.join(file)) {
+            Ok(_) => return Err("the rebuilt store borrows objects through alternates".into()),
+            Err(e) if e.kind() == std::io::ErrorKind::NotFound => {}
+            Err(e) => return Err(format!("the alternates check failed: {}", e.kind())),
+        }
+    }
+    let (s, t) = (source.to_path_buf(), staging.to_path_buf());
+    let shared = tokio::task::spawn_blocking(move || shares_inodes(&s, &t))
+        .await
+        .map_err(|e| e.to_string())??;
+    if shared {
+        return Err("the rebuilt store shares object files with the old store".into());
+    }
+    Ok(())
+}
+
+/// How many of `ids` the store at `git_dir` holds (`cat-file --batch-check`).
+async fn present_count(git_dir: &Path, ids: &HashSet<String>) -> Result<usize, String> {
+    let mut input = Vec::with_capacity(ids.len() * 41);
+    for id in ids {
+        input.extend_from_slice(id.as_bytes());
+        input.push(b'\n');
+    }
+    let out = run_with_input(
+        git_dir,
+        &["cat-file", "--batch-check=%(objectname) %(objecttype)"],
+        input,
+        STORE_BUDGET,
+    )
+    .await?;
+    if !out.status.success() {
+        return Err("git cat-file --batch-check failed".into());
+    }
+    Ok(String::from_utf8_lossy(&out.stdout)
+        .lines()
+        .filter(|l| !l.ends_with(" missing"))
+        .count())
+}

+/// Whether any regular file under `staging/objects` is the same inode as a
+/// file under `source/objects` (a hardlink, as `clone --local` makes).
+#[cfg(unix)]
+fn shares_inodes(source: &Path, staging: &Path) -> Result<bool, String> {
+    use std::os::unix::fs::MetadataExt;
+    fn walk(dir: &Path, out: &mut Vec<std::fs::Metadata>) -> Result<(), String> {
+        let entries = match std::fs::read_dir(dir) {
+            Ok(e) => e,
+            Err(e) if e.kind() == std::io::ErrorKind::NotFound => return Ok(()),
+            Err(e) => return Err(format!("object directory not read: {}", e.kind())),
+        };
+        for e in entries {
+            let e = e.map_err(|e| e.to_string())?;
+            let m = std::fs::symlink_metadata(e.path()).map_err(|e| e.to_string())?;
+            if m.is_dir() {
+                walk(&e.path(), out)?;
+            } else if m.is_file() {
+                out.push(m);
+            }
+        }
+        Ok(())
+    }
+    let mut staged = Vec::new();
+    walk(&staging.join("objects"), &mut staged)?;
+    let linked: HashSet<(u64, u64)> = staged
+        .iter()
+        .filter(|m| m.nlink() > 1)
+        .map(|m| (m.dev(), m.ino()))
+        .collect();
+    if linked.is_empty() {
+        return Ok(false);
+    }
+    let mut old = Vec::new();
+    walk(&source.join("objects"), &mut old)?;
+    Ok(old.iter().any(|m| linked.contains(&(m.dev(), m.ino()))))
+}
+
+#[cfg(not(unix))]
+fn shares_inodes(_source: &Path, _staging: &Path) -> Result<bool, String> {
+    Ok(false)
+}

+/// Every object id in `source` that `staging` does not hold, sorted.
+async fn dropped_objects(source: &Path, staging: &Path) -> Result<Vec<String>, String> {
+    let all = [
+        "cat-file",
+        "--batch-all-objects",
+        "--batch-check=%(objectname)",
+    ];
+    let mut kept = HashSet::new();
+    for_each_line(staging, &all, STORE_BUDGET, |id| {
+        kept.insert(id.to_string());
+        Ok(())
+    })
+    .await?;
+    let mut dropped = Vec::new();
+    for_each_line(source, &all, STORE_BUDGET, |id| {
+        if !kept.contains(id) {
+            dropped.push(id.to_string());
+        }
+        Ok(())
+    })
+    .await?;
+    dropped.sort();
+    Ok(dropped)
+}

+/// Step 8: `<recovery>.held`, `<recovery>.dropped` and, last,
+/// `<recovery>.migration.json` beside the recovery path.
+fn write_report(
+    plugin: &Path,
+    recovery: &Path,
+    owner: &str,
+    name: &str,
+    built: &Built,
+    record_bytes: Option<Result<Vec<u8>, String>>,
+) -> Result<(), String> {
+    use base64::Engine as _;
+    if let Some(parent) = recovery.parent() {
+        std::fs::create_dir_all(parent).map_err(|e| format!("recovery directory: {e}"))?;
+    }
+    let stem = recovery
+        .file_name()
+        .map(|s| s.to_string_lossy().into_owned())
+        .ok_or("no recovery name")?;
+    let lines = |ids: &[String]| {
+        let mut s = String::with_capacity(ids.len() * 41);
+        for id in ids {
+            s.push_str(id);
+            s.push('\n');
+        }
+        s
+    };
+    std::fs::write(with_suffix(recovery, ".held"), lines(&built.held))
+        .map_err(|e| format!("held list not written: {e}"))?;
+    std::fs::write(
+        with_suffix(recovery, ".dropped"),
+        lines(&built.dropped_objects),
+    )
+    .map_err(|e| format!("dropped list not written: {e}"))?;
+    let record = match record_bytes {
+        None => serde_json::Value::Null,
+        Some(Ok(b)) => serde_json::json!({
+            "unreadable": true,
+            "bytesBase64": base64::engine::general_purpose::STANDARD.encode(b),
+        }),
+        Some(Err(why)) => serde_json::json!({ "unreadable": true, "bytesNotRead": why }),
+    };
+    let copied: Vec<serde_json::Value> = built
+        .copied
+        .iter()
+        .map(|(r, sha)| serde_json::json!({ "ref": r, "sha": sha }))
+        .collect();
+    let report = serde_json::json!({
+        "owner": owner,
+        "name": name,
+        "class": "mirror",
+        "recovery": relative(plugin, recovery),
+        "head": built.head,
+        "copied": copied,
+        "dropped": built.dropped,
+        "held": { "file": format!("{stem}.held"), "count": built.held.len() },
+        "droppedObjects": { "file": format!("{stem}.dropped"), "count": built.dropped_objects.len() },
+        "record": record,
+    });
+    let path = with_suffix(recovery, ".migration.json");
+    let tmp = with_suffix(recovery, ".migration.json.tmp");
+    let bytes = serde_json::to_vec_pretty(&report).map_err(|e| e.to_string())?;
+    std::fs::write(&tmp, bytes).map_err(|e| format!("report not written: {e}"))?;
+    std::fs::rename(&tmp, &path).map_err(|e| format!("report not written: {e}"))
+}

+/// Write [`crate::PUBLICATION_MARKER`] into a store: a temporary file, then

+        .await
+        .map_err(|e| format!("could not write the publication marker: {e}"))

+/// Run git on the store at `git_dir` and hand every stdout line to `each`,
+/// streaming (nothing is buffered whole). An error from `each`, a timeout or
+/// a failing exit stops git and is returned.
+async fn for_each_line(
+    git_dir: &Path,
+    args: &[&str],
+    timeout: Duration,
+    mut each: impl FnMut(&str) -> Result<(), String>,
+) -> Result<(), String> {
+    use tokio::io::AsyncBufReadExt;
+    let mut cmd = git_command(git_dir, git_dir, args);
+    cmd.stderr(std::process::Stdio::null());
+    let mut child = cmd
+        .spawn()
+        .map_err(|e| format!("git could not start: {e}"))?;
+    let pid = child.id();
+    let what = args.first().copied().unwrap_or("git");
+    let stdout = child.stdout.take().ok_or("git has no stdout")?;
+    let mut lines = tokio::io::BufReader::new(stdout).lines();
+    let work = async {
+        while let Some(line) = lines
+            .next_line()
+            .await
+            .map_err(|e| format!("git {what} output unreadable: {e}"))?
+        {
+            each(&line)?;
+        }
+        match child.wait().await {
+            Ok(st) if st.success() => Ok(()),
+            _ => Err(format!("git {what} failed")),
+        }
+    };
+    match tokio::time::timeout(timeout, work).await {
+        Ok(Ok(())) => Ok(()),
+        Ok(Err(e)) => {
+            kill_group(pid).await;
+            Err(e)
+        }
+        Err(_) => {
+            kill_group(pid).await;
+            Err(GIT_TIMED_OUT.to_string())
+        }
+    }
+}
+
+/// Run git on the store at `git_dir` with `input` on its stdin, and return
+/// its whole output.
+async fn run_with_input(
+    git_dir: &Path,
+    args: &[&str],
+    input: Vec<u8>,
+    timeout: Duration,
+) -> Result<std::process::Output, String> {
+    use tokio::io::AsyncWriteExt;
+    let mut cmd = git_command(git_dir, git_dir, args);
+    cmd.stdin(std::process::Stdio::piped());
+    let mut child = cmd
+        .spawn()
+        .map_err(|e| format!("git could not start: {e}"))?;
+    let pid = child.id();
+    let mut stdin = child.stdin.take().ok_or("git has no stdin")?;
+    let writer = tokio::spawn(async move {
+        let wrote = stdin.write_all(&input).await;
+        drop(stdin);
+        wrote
+    });
+    let waited = tokio::time::timeout(timeout, child.wait_with_output()).await;
+    let wrote = writer.await;
+    match waited {
+        Ok(Ok(out)) => {
+            if !matches!(wrote, Ok(Ok(()))) {
+                return Err("git's input was not written".into());
+            }
+            Ok(out)
+        }
+        Ok(Err(e)) => Err(format!("git failed: {e}")),
+        Err(_) => {
+            kill_group(pid).await;
+            Err(GIT_TIMED_OUT.to_string())
+        }
+    }
+}

+/// A bare store at `dir` holding one commit on `main`; returns its sha.
+fn bare_with_commit(home: &Path, dir: &Path, body: &str) -> String {
+    let work = home.join(format!("work-{}", uuid::Uuid::new_v4().simple()));
+    std::fs::create_dir_all(&work).unwrap();
+    git(&work, &["init", "--quiet", "-b", "main"]);
+    std::fs::write(work.join("f.txt"), body).unwrap();
+    git(&work, &["add", "-A"]);
+    git(&work, &["commit", "--quiet", "-m", "c"]);
+    let sha = git(&work, &["rev-parse", "HEAD"]);
+    std::fs::create_dir_all(dir.parent().unwrap()).unwrap();
+    git(
+        home,
+        &[
+            "clone",
+            "--quiet",
+            "--bare",
+            work.to_str().unwrap(),
+            dir.to_str().unwrap(),
+        ],
+    );
+    sha

+/// Decision 22: smart HTTP refuses a repository path whose name is not a
+/// valid segment (a crashed fork's `.fork-*.tmp` directory), instead of
+/// passing it on to the CGI, which exports every bare repository under
+/// `repos/`. A normal repository of the same owner is the positive control.
+#[tokio::test]
+async fn t22_smart_http_refuses_a_dot_named_bare_repo() {
+    let tmp = tempfile::tempdir().unwrap();
+    let home = tmp.path();
+    let plugin = home.join("plugin");
+    let tmp_sha = bare_with_commit(home, &plugin.join("repos/bob/.fork-x.tmp"), "secret\n");
+    let ok_sha = bare_with_commit(home, &plugin.join("repos/bob/real.git"), "public\n");
+    let forge = forge_with_backend(&plugin);
+    let adv = |path: &str| req("GET", path, "service=git-upload-pack");
+
+    let ok = forge
+        .handle(
+            adv("/forge/bob/real.git/info/refs"),
+            crate::ForgeAgent::Anonymous,
+        )
+        .await
+        .unwrap();
+    assert_eq!(
+        ok.status,
+        200,
+        "control: {}",
+        String::from_utf8_lossy(&ok.body)
+    );
+    assert!(
+        String::from_utf8_lossy(&ok.body).contains(&ok_sha),
+        "control: the normal repository is advertised"
+    );
+
+    for path in [
+        "/forge/bob/.fork-x.tmp/info/refs",
+        "/forge/bob/.fork-x.tmp/git-upload-pack",
+    ] {
+        let mut r = adv(path);
+        if path.ends_with("git-upload-pack") {
+            r.method = "POST".into();
+            r.query = String::new();
+            r.headers = vec![(
+                "content-type".into(),
+                "application/x-git-upload-pack-request".into(),
+            )];
+            let want = format!("want {tmp_sha}\n");
+            r.raw_body = bytes::Bytes::from(format!("{:04x}{want}00000009done\n", want.len() + 4));
+        }
+        let got = forge.handle(r, crate::ForgeAgent::Anonymous).await;
+        let (status, body) = match got {
+            Ok(resp) => (resp.status, resp.body.to_vec()),
+            Err(e) => (e.status_code(), e.to_string().into_bytes()),
+        };
+        let text = String::from_utf8_lossy(&body);
+        assert_eq!(status, 404, "{path} -> {status}: {text}");
+        assert!(
+            !text.contains(&tmp_sha),
+            "{path} advertised the tmp repo: {text}"
+        );
+        assert!(!body.windows(4).any(|w| w == b"PACK"), "{path} sent a pack");
+    }

+// ---- Commit B1 (c): boot migration of mirror-class stores ----------------
+//
+// Every fixture is C15-hard: the held objects sit in a pack with a `.keep`
+// file, and a non-mirror ref (`refs/misc/stash-held`) reaches the held
+// commit, so deleting `refs/mirror` plus `gc --prune=now` in place would
+// still leave them (test 5 pins this). The paths and JSON keys of the
+// journal and the recovery report are spelt out here, so these tests fail
+// on assertions, not on compile errors, before the migration exists.
+
+const APPROVED: &str = "b1-approved-public-bytes\n";
+const OLD: &str = "b1-old-approved-bytes\n";
+const NEW: &str = "b1-new-approved-bytes\n";
+const HELD: &str = "b1-held-secret-bytes\n";
+const HELD_SUBJECT: &str = "b1-held-subject";
+const MARKER: &str = "mirror-publication-v1";
+
+/// A legacy (pre-release) served store, in today's pre-release layout.
+struct Legacy {
+    _tmp: tempfile::TempDir,
+    home: PathBuf,
+    plugin: PathBuf,
+    owner: String,
+    served: PathBuf,
+    /// `main` one: `f.txt` = OLD, `public.txt` = APPROVED.
+    m1: String,
+    /// `main` two (the served `main`): `f.txt` = NEW.
+    m2: String,
+    /// The held side commit off `m2`: `f.txt` = OLD again (C16), `held.txt`.
+    held: String,
+    held_blob: String,
+    old_blob: String,
+    foreign: String,
+}

+/// How the fixture's `main` and tag got into the served store.
+#[derive(Clone, Copy, PartialEq, Eq)]
+enum Shape {
+    /// The legacy engine wrote `refs/heads/main`; the owner tagged in place.
+    Engine,
+    /// The owner pushed `main` and tag `v1` before the repository was
+    /// followed (decision 2's case, test 9).
+    OwnerPushed,
+}
+
+fn owner_of(seed: u8) -> String {
+    hex::encode([seed; 32])
+}

+fn commit(work: &Path, files: &[(&str, &str)], subject: &str) -> String {
+    for (f, body) in files {
+        std::fs::write(work.join(f), body).unwrap();
+    }
+    git(work, &["add", "-A"]);
+    git(work, &["commit", "--quiet", "-m", subject]);
+    git(work, &["rev-parse", "HEAD"])
+}
+
+fn legacy(seed: u8, shape: Shape) -> Legacy {
+    let tmp = tempfile::tempdir().unwrap();
+    let home = tmp.path().to_path_buf();
+    let plugin = home.join("plugin");
+    let owner = owner_of(seed);
+    let up = home.join("up");
+    std::fs::create_dir_all(&up).unwrap();
+    git(&up, &["init", "--quiet", "-b", "main"]);
+    let m1 = commit(
+        &up,
+        &[("f.txt", OLD), ("public.txt", APPROVED)],
+        "b1 approved one",
+    );
+    let old_blob = git(&up, &["rev-parse", "HEAD:f.txt"]);
+    let m2 = commit(&up, &[("f.txt", NEW)], "b1 approved two");
+    git(&up, &["checkout", "--quiet", "-b", "side"]);
+    let held = commit(&up, &[("f.txt", OLD), ("held.txt", HELD)], HELD_SUBJECT);
+    let held_blob = git(&up, &["rev-parse", "HEAD:held.txt"]);
+    git(&up, &["checkout", "--quiet", "main"]);
+    if shape == Shape::OwnerPushed {
+        git(&up, &["tag", "-a", "v1", "-m", "release one", &m2]);
+    }
+    let served = plugin.join("repos").join(&owner).join("sample.git");
+    std::fs::create_dir_all(served.parent().unwrap()).unwrap();
+    let s = served.to_str().unwrap();
+    git(&home, &["init", "--bare", "--quiet", "-b", "main", s]);
+    let up_s = up.to_str().unwrap();
+    if shape == Shape::OwnerPushed {
+        git(
+            &up,
+            &[
+                "push",
+                "--quiet",
+                s,
+                "main:main",
+                "refs/tags/v1:refs/tags/v1",
+            ],
+        );
+    }
+    git(
+        &served,
+        &["config", "--add", "uploadpack.hideRefs", "refs/mirror"],
+    );
+    git(
+        &served,
+        &["config", "--add", "transfer.hideRefs", "refs/mirror"],
+    );
+    git(
+        &served,
+        &[
+            "fetch",
+            "--quiet",
+            "--no-tags",
+            up_s,
+            "+refs/heads/*:refs/mirror/*",
+        ],
+    );
+    if shape == Shape::Engine {
+        git(&served, &["update-ref", "refs/heads/main", &m2]);
+        git(&served, &["tag", "-a", "v1", "-m", "release one", &m2]);
+    }
+    git(
+        &served,
+        &[
+            "notes",
+            "--ref=commits",
+            "add",
+            "-m",
+            "b1 note on approved",
+            &m2,
+        ],
+    );
+    let fork = home.join("forkup");
+    std::fs::create_dir_all(&fork).unwrap();
+    git(&fork, &["init", "--quiet", "-b", "feat"]);
+    let foreign = commit(&fork, &[("foreign.txt", "b1-foreign\n")], "b1 foreign");
+    git(
+        &served,
+        &[
+            "fetch",
+            "--quiet",
+            "--no-tags",
+            fork.to_str().unwrap(),
+            "+refs/heads/feat:refs/forge/heads/bob/feat",
+        ],
+    );
+    git(&served, &["update-ref", "refs/misc/stash-held", &held]);
+    git(&served, &["update-ref", "refs/misc/blob", &held_blob]);
+    git(&served, &["repack", "-a", "-d", "-q"]);
+    for e in std::fs::read_dir(served.join("objects/pack"))
+        .unwrap()
+        .flatten()
+    {
+        let p = e.path();
+        if p.extension().is_some_and(|x| x == "pack") {
+            std::fs::write(p.with_extension("keep"), b"b1 fixture\n").unwrap();
+        }
+    }
+    Legacy {
+        _tmp: tmp,
+        home,
+        plugin,
+        owner,
+        served,
+        m1,
+        m2,
+        held,
+        held_blob,
+        old_blob,
+        foreign,
+    }
+}

+/// The recovery entries `mirror-recovery/<owner>/sample.git.<ts>`.
+fn recovery_entries(plugin: &Path, owner: &str) -> Vec<PathBuf> {
+    let dir = plugin.join("mirror-recovery").join(owner);
+    let mut out: Vec<PathBuf> = std::fs::read_dir(dir)
+        .map(|rd| {
+            rd.flatten()
+                .map(|e| e.path())
+                .filter(|p| {
+                    let f = p.file_name().unwrap().to_string_lossy().into_owned();
+                    f.strip_prefix("sample.git.")
+                        .is_some_and(|ts| !ts.is_empty() && ts.bytes().all(|b| b.is_ascii_digit()))
+                })
+                .collect()
+        })
+        .unwrap_or_default();
+    out.sort();
+    out
+}

+/// Every HTML, JSON, raw and archive reader of the held commit: the
+/// responses that are 2xx or carry held bytes.
+async fn held_leaks(forge: &crate::ForgeService, o: &str, h: &str) -> Vec<String> {
+    let paths = [
+        format!("/forge/{o}/sample/raw/{h}/held.txt"),
+        format!("/forge/{o}/sample/blob/{h}/held.txt"),
+        format!("/forge/{o}/sample/tree/{h}"),
+        format!("/forge/{o}/sample/commit/{h}"),
+        format!("/forge/api/repos/{o}/sample/commit/{h}"),
+        format!("/forge/api/repos/{o}/sample/tree/{h}"),
+        format!("/forge/api/repos/{o}/sample/blob/{h}/held.txt"),
+        format!("/forge/{o}/sample/archive/{h}.tar.gz"),
+    ];
+    let mut leaks = Vec::new();
+    for p in paths {
+        let r = get(forge, p.clone()).await;
+        let bytes = contains(&r.body, HELD.trim_end().as_bytes())
+            || contains(&r.body, HELD_SUBJECT.as_bytes());
+        if (200..300).contains(&r.status) || bytes {
+            leaks.push(format!("{p} -> {} (held bytes: {bytes})", r.status));
+        }
+    }
+    leaks
+}

+/// What every migrated fixture must show: held denied on every reader,
+/// approved content served exactly, the marker, a recovery entry outside
+/// `repos/` with its report files, and no journal left.
+async fn assert_migrated(fx: &Legacy, forge: &crate::ForgeService) {
+    let (o, h) = (&fx.owner, &fx.held);
+    let leaks = held_leaks(forge, o, h).await;
+    assert!(
+        leaks.is_empty(),
+        "held commit served:\n{}",
+        leaks.join("\n")
+    );
+    let raw = get(forge, format!("/forge/{o}/sample/raw/{}/public.txt", fx.m2)).await;
+    assert_eq!(
+        (raw.status, raw.body.as_ref()),
+        (200, APPROVED.as_bytes()),
+        "approved raw: {}",
+        String::from_utf8_lossy(&raw.body)
+    );
+    assert!(
+        fx.served.join(MARKER).is_file(),
+        "the rebuilt store is not marked"
+    );
+    for spec in [h.as_str(), fx.held_blob.as_str()] {
+        assert!(!has(&fx.served, spec), "{spec} is in the served store");
+    }
+    assert!(!fx.served.join("objects/info/alternates").exists());
+    assert!(
+        !journal_of(&fx.plugin, o).exists(),
+        "journal left: {}",
+        std::fs::read_to_string(journal_of(&fx.plugin, o)).unwrap_or_default()
+    );
+    let entries = recovery_entries(&fx.plugin, o);
+    assert_eq!(entries.len(), 1, "recovery entries: {entries:?}");
+    assert!(
+        has(&entries[0], &fx.held_blob),
+        "the recovery copy keeps the old store whole"
+    );
+    for suffix in [".migration.json", ".held", ".dropped"] {
+        assert!(
+            sibling(&entries[0], suffix).is_file(),
+            "no {suffix} report file"
+        );
+    }
+    let held_list = std::fs::read_to_string(sibling(&entries[0], ".held")).unwrap();
+    assert!(
+        held_list.lines().any(|l| l == fx.held_blob),
+        ".held does not list the held blob"
+    );
+    let dropped = std::fs::read_to_string(sibling(&entries[0], ".dropped")).unwrap();
+    assert!(
+        dropped.lines().any(|l| l == fx.held_blob),
+        ".dropped lacks the held blob"
+    );
+    let mut walk = vec![fx.plugin.join("repos")];
+    while let Some(d) = walk.pop() {
+        for e in std::fs::read_dir(&d).unwrap().flatten() {
+            let name = e.file_name().to_string_lossy().into_owned();
+            assert!(
+                !name.contains(".migration.json") && !name.starts_with("sample.git."),
+                "recovery data under repos/: {}",
+                e.path().display()
+            );
+            if e.path().is_dir() && d == fx.plugin.join("repos") {
+                walk.push(e.path());
+            }
+        }
+    }
+}

+#[derive(Debug, Clone, PartialEq, Eq)]
+pub enum StoredRecord {
+    /// No record file: the repository is not (yet) a mirror.
+    Missing,
+    /// A record file exists but cannot be read or parsed. The repository is
+    /// still a mirror: readers refuse it, and the engine leaves the file in
+    /// place and treats the store as awaiting migration. The reason names
+    /// no path.
+    Unreadable(String),
+    /// A valid record.
+    Valid(Box<MirrorRecord>),

+impl MirrorStore {
+    /// A store rooted at `plugin_dir/mirror`.
+    #[must_use]
+    pub fn new(plugin_dir: impl AsRef<Path>) -> Self {
+        Self {
+            dir: plugin_dir.as_ref().join("mirror"),
+        }
+    }
+
+    /// `plugin_dir/mirror/<owner>/<name>.json`, for a 64-hex owner and a
+    /// followed repository name.
+    pub(crate) fn file(&self, owner: &str, name: &str) -> Option<PathBuf> {
+        if !is_hex64(owner) || !is_repo_name(name) {
+            return None;
+        }
+        Some(self.dir.join(owner).join(format!("{name}.json")))
+    }
+
+    /// `plugin_dir/mirror-work/locks/<owner>/<name>.lock`, the cross-process
+    /// advisory lock for one repository (design §3). Only a 64-hex owner and a
+    /// followed repository name have one here; the path itself is
+    /// [`crate::migrate::lock_path`], which boot migration shares.
+    #[cfg_attr(
+        not(feature = "mirror"),
+        expect(
+            dead_code,
+            reason = "the mirror engine's; migration only loads records"
+        )
+    )]
+    pub(crate) fn lock_file(&self, owner: &str, name: &str) -> Option<PathBuf> {
+        if !is_hex64(owner) || !is_repo_name(name) {
+            return None;
+        }
+        crate::migrate::lock_path(self.dir.parent()?, owner, name)
+    }
+
+    /// The record for `(owner, name)` when it is present and valid; `None`
+    /// when it is missing *or* cannot be read or parsed. Use [`Self::load`]
+    /// to tell those apart: an unreadable record still marks a mirror.
+    ///
+    /// # Examples
+    ///
+    /// ```
+    /// # #[cfg(feature = "mirror")] {
+    /// use solid_pod_rs_forge::mirror::MirrorStore;
+    ///
+    /// let dir = tempfile::tempdir().unwrap();
+    /// let store = MirrorStore::new(dir.path());
+    /// assert!(store.read(&"a".repeat(64), "nobody").is_none());
+    /// # }
+    /// ```
+    #[must_use]
+    #[cfg_attr(
+        not(feature = "mirror"),
+        expect(
+            dead_code,
+            reason = "the mirror engine's; migration only loads records"
+        )
+    )]
+    pub fn read(&self, owner: &str, name: &str) -> Option<MirrorRecord> {
+        match self.load(owner, name) {
+            StoredRecord::Valid(rec) => Some(*rec),
+            StoredRecord::Missing | StoredRecord::Unreadable(_) => None,
+        }
+    }
+
+    /// The record for `(owner, name)`, telling a missing file from one that
+    /// exists but cannot be read or parsed. An owner or name that is not a
+    /// safe record key (a 64-hex owner, a valid repository name) has no
+    /// record path, so no record can exist for it: [`StoredRecord::Missing`],
+    /// as the reader gate's own path check also finds. Otherwise `Missing`
+    /// means no directory entry exists; a symlink at the path, dangling or
+    /// not, is [`StoredRecord::Unreadable`].
+    ///
+    /// # Examples
+    ///
+    /// ```
+    /// # #[cfg(feature = "mirror")] {
+    /// use solid_pod_rs_forge::mirror::{MirrorStore, StoredRecord};
+    ///
+    /// let dir = tempfile::tempdir().unwrap();
+    /// let store = MirrorStore::new(dir.path());
+    /// let owner = "a".repeat(64);
+    /// assert!(matches!(store.load(&owner, "x"), StoredRecord::Missing));
+    /// assert!(matches!(store.load("alice", "x"), StoredRecord::Missing));
+    /// std::fs::create_dir_all(dir.path().join("mirror").join(&owner)).unwrap();
+    /// std::fs::write(dir.path().join("mirror").join(&owner).join("x.json"), b"{").unwrap();
+    /// assert!(matches!(store.load(&owner, "x"), StoredRecord::Unreadable(_)));
+    /// # }
+    /// ```
+    #[must_use]
+    pub fn load(&self, owner: &str, name: &str) -> StoredRecord {
+        let Some(path) = self.file(owner, name) else {
+            return StoredRecord::Missing;
+        };
+        // Missing only when no directory entry exists. An entry that is a
+        // symlink, dangling or not, is not a record this store wrote.
+        match std::fs::symlink_metadata(&path) {
+            Ok(m) if m.file_type().is_symlink() => {
+                return StoredRecord::Unreadable("is a symbolic link".into());
+            }
+            Ok(_) => {}
+            Err(e) if e.kind() == std::io::ErrorKind::NotFound => return StoredRecord::Missing,
+            Err(e) => return StoredRecord::Unreadable(format!("cannot be read: {}", e.kind())),
+        }
+        let bytes = match std::fs::read(path) {
+            Ok(b) => b,
+            // The entry existed a moment ago: not "no record".
+            Err(e) => return StoredRecord::Unreadable(format!("cannot be read: {}", e.kind())),
+        };
+        match serde_json::from_slice(&bytes) {
+            Ok(rec) => StoredRecord::Valid(Box::new(rec)),
+            Err(e) => StoredRecord::Unreadable(format!("is not a valid record: {e}")),
+        }
+    }
+
+    /// Save a record atomically (write a temporary file, then rename).
+    ///
+    /// # Errors
+    ///
+    /// An I/O error, or `InvalidInput` when the owner or name is unsafe as
+    /// a path segment.
+    #[cfg_attr(
+        not(feature = "mirror"),
+        expect(
+            dead_code,
+            reason = "the mirror engine's; migration only loads records"
+        )
+    )]
+    pub fn save(&self, rec: &MirrorRecord) -> std::io::Result<()> {
+        let path = self.file(&rec.pubkey, &rec.name).ok_or_else(|| {
+            std::io::Error::new(std::io::ErrorKind::InvalidInput, "unsafe mirror key")
+        })?;
+        if let Some(parent) = path.parent() {
+            std::fs::create_dir_all(parent)?;
+        }
+        let tmp = path.with_extension("json.tmp");
+        std::fs::write(&tmp, serde_json::to_vec_pretty(rec)?)?;
+        std::fs::rename(tmp, path)
+    }
+}

//! # solid-pod-rs-forge
//!
//! A clean-room Rust reimplementation of the JavaScriptSolidServer
//! `forge` plugin — a zero-build, server-rendered Git forge (a
//! Gogs/Gitea slice) composed almost entirely from primitives
//! [`solid-pod-rs`](solid_pod_rs) already ships: git smart-HTTP
//! ([`solid_pod_rs_git`]), write-as-commit provenance and Bitcoin
//! anchoring ([`solid_pod_rs::provenance`], [`solid_pod_rs::mrc20`]),
//! NIP-98 auth ([`solid_pod_rs::auth::nip98`]), `did:nostr` identity
//! ([`solid_pod_rs::did_nostr_types`]), and WAC gating (enforced by the
//! embedding server before [`ForgeService::handle`] is reached).
//!
//! ## IP posture
//!
//! Everything here is derived from the forge plugin's *published
//! behaviour* and expressed as fresh Rust on solid-pod-rs's own
//! primitives. JSS is cited by function/section name only — no upstream
//! JavaScript is transcribed. This mirrors how `solid_pod_rs::bitcoin_tx`
//! and [`solid_pod_rs::auth::nip98`] cite JSS while carrying an
//! independent implementation.
//!
//! ## Architecture rule — "words in pods, metadata in the forge"
//!
//! Issue/PR/comment *bodies* live in the author's own pod (WAC-governed,
//! author-owned); the forge keeps only a **spine index** of pointers.
//! Bodies are re-fetched at read time, bounded. Podless `did:nostr`
//! agents store bodies in forge-hosted storage instead.
//!
//! ## Native-only
//!
//! The forge shells to `git`/`git-http-backend`, touches the
//! filesystem, and runs a loopback HTTP client. It is never part of a
//! `core`/wasm build and adds zero dependencies to the core crate.
//!
//! ## Entry point
//!
//! The crate is framework-agnostic: [`ForgeService::handle`] consumes a
//! [`ForgeRequest`] and produces a [`ForgeResponse`]; the embedding
//! server (actix/axum/hyper) translates its native types at the edge and
//! WAC-gates the forge scope *before* dispatch — exactly as the server's
//! `handle_git` gates before invoking [`solid_pod_rs_git::GitHttpService`].

/// Load the persisted forge instance HMAC key, or generate + persist a
/// fresh one (`0600`). The key is 32 bytes of OS randomness (two v4
/// UUIDs, each 122 bits of entropy from the platform RNG). Persisting it
/// keeps minted tokens valid across restarts.
fn load_or_create_token_key(plugin_dir: &Path) -> Result<[u8; 32], ForgeError> {
    let path = plugin_dir.join(".forge-token-key");
    if let Ok(bytes) = std::fs::read(&path) {
        if bytes.len() == 32 {
            let mut key = [0u8; 32];
            key.copy_from_slice(&bytes);
            return Ok(key);
        }
    }
    let mut key = [0u8; 32];
    key[..16].copy_from_slice(uuid::Uuid::new_v4().as_bytes());
    key[16..].copy_from_slice(uuid::Uuid::new_v4().as_bytes());
    std::fs::write(&path, key)?;
    #[cfg(unix)]
    {
        use std::os::unix::fs::PermissionsExt;
        let _ = std::fs::set_permissions(&path, std::fs::Permissions::from_mode(0o600));
    }
    Ok(key)
}

                "forge: config.open_edit is ON: anyone can edit repos via the web-edit endpoint \
                 (no owner signature required). DEMO ONLY; never enable on a real forge."
            );
        }
        #[cfg(feature = "announce")]
        let announcer = Arc::new(nip34::Announcer::new(&cfg, &plugin_dir)?);
        #[cfg(feature = "anchoring")]
        let trails = Arc::new(trail::TrailStore::new(&cfg, &plugin_dir)?);
        Ok(Self {
            cfg,
            plugin_dir,
            repo_root,
            git,
            spine,
            loopback: None,
            hosted,
            token_key,
            nip98_replay: solid_pod_rs::auth::replay::Nip98ReplayCache::from_env(),
            #[cfg(feature = "announce")]
            announcer,
            #[cfg(feature = "anchoring")]
            trails,
            pr: pulls::PrExt::default(),
            locks: Arc::new(locks::ForgeLocks::default()),
        })
    }

    /// Resolve the caller identity from `req`'s `Authorization` header
    /// (forge token or NIP-98). The server may instead pass a
    /// [`ForgeAgent::Pod`] directly to [`Self::handle`] when it has a pod
    /// session; this helper is for the token/NIP-98 schemes.
    pub async fn resolve_agent(&self, req: &ForgeRequest) -> ForgeAgent {
        // The URL a NIP-98 event is checked against comes from the configured
        // origin when there is one, never from a forged `host_url`.
        let pinned = self.pinned_host_url(req.host_url.as_deref());
        if pinned.as_deref() != req.host_url.as_deref() {
            let mut r = req.clone();
            r.host_url = pinned;
            return auth::resolve_agent(
                &r,
                self.token_key.as_ref(),
                &self.nip98_replay,
                now_secs(),
            )
            .await;
        }
        auth::resolve_agent(req, self.token_key.as_ref(), &self.nip98_replay, now_secs()).await
    }

    /// The request origin the forge trusts: the origin of the configured
    /// `base_url` (scheme and authority, no path) when set, otherwise the
    /// embedder-supplied `host_url` unchanged (security review M1).
    fn pinned_host_url(&self, host_url: Option<&str>) -> Option<String> {
        match self.cfg.base_url.as_deref() {
            Some(b) => {
                let b = b.trim_end_matches('/');
                let end = b
                    .find("://")
                    .map(|i| i + 3)
                    .and_then(|s| b[s..].find('/').map(|j| s + j))
                    .unwrap_or(b.len());
                Some(b[..end].to_string())
            }
            None => host_url.map(str::to_string),
        }
    }

        self.cfg.normalized_prefix()

    #[must_use]
    pub fn plugin_dir(&self) -> &Path {
        &self.plugin_dir

    /// Single entry point. The embedding server maps its native request
    /// to a [`ForgeRequest`], WAC-gates the scope, and calls this.
    pub async fn handle(
        &self,
        mut req: ForgeRequest,
        agent: ForgeAgent,
    ) -> Result<ForgeResponse, ForgeError> {
        req.host_url = self.pinned_host_url(req.host_url.as_deref());
        // CORS preflight.
        if req.method.eq_ignore_ascii_case("OPTIONS") {
            return Ok(ForgeResponse {
                status: 204,
                headers: vec![
                    ("access-control-allow-origin".into(), "*".into()),
                    (
                        "access-control-allow-methods".into(),
                        "GET, POST, PUT, PATCH, DELETE, OPTIONS".into(),
                    ),
                    (
                        "access-control-allow-headers".into(),
                        "Content-Type, Authorization".into(),
                    ),
                ],
                body: bytes::Bytes::new(),
            });
        }

        let prefix = self.cfg.normalized_prefix();
        let Some(rel) = router::strip_prefix(&prefix, &req.path) else {
            return Ok(ForgeResponse::error(404, "not under forge prefix"));
        };
        // Percent-forms of . / \ NUL never name a real object (JSS dispatcher).
        if let Err(e) = guard::percent_guard(&rel) {
            return Ok(self.finish_page(e.to_response()));
        }
        let route = parse_route(&rel);
        if self.cfg.private_repos {
            if let Some(denied) = self.private_gate(&rel, &route, &agent) {
                return Ok(self.finish_page(denied));
            }
        }

        #[cfg(feature = "anchoring")]
        let scope = route
            .repo_page_scope()
            .map(|(o, r)| (o.to_string(), r.to_string()));
        let result = self.dispatch(route, &req, &agent).await;
        #[cfg(feature = "anchoring")]
        let result = match (scope, result) {
            (Some((o, r)), Ok(resp)) => Ok(self.decorate_repo_page(&o, &r, resp).await),
            (_, other) => other,
        };
        Ok(self.finish_page(result.unwrap_or_else(|e| e.to_response())))
    }

    /// Attach the page `Content-Security-Policy` and `nosniff` to HTML
    /// responses (JSS `sendHtml`).
    fn finish_page(&self, mut resp: ForgeResponse) -> ForgeResponse {
        let is_html = resp
            .headers
            .iter()
            .any(|(k, v)| k.eq_ignore_ascii_case("content-type") && v.starts_with("text/html"));
        if is_html {
            // Only a page that loads the vendored widget keeps the weaker
            // widget policy; every other page gets a strict nonce policy.
            // The marker is an internal header only a handler can set; page
            // content (which an attacker can influence) never selects the
            // weaker policy. It is stripped before the response leaves.
            let widget = resp
                .headers
                .iter()
                .any(|(k, v)| k.eq_ignore_ascii_case(WIDGET_PAGE_HEADER) && v == "widget");
            resp.headers
                .retain(|(k, _)| !k.eq_ignore_ascii_case(WIDGET_PAGE_HEADER));
            let csp = if widget {
                xlogin::build_csp(&self.cfg.csp_connect)
            } else {
                let nonce = uuid::Uuid::new_v4().simple().to_string();
                xlogin::build_strict_csp(&self.cfg.csp_connect, &nonce)
            };
            resp.headers.push(("content-security-policy".into(), csp));
            if !resp
                .headers
                .iter()
                .any(|(k, _)| k.eq_ignore_ascii_case("x-content-type-options"))
            {
                resp.headers
                    .push(("x-content-type-options".into(), "nosniff".into()));
            }
        }
        resp
    }

    /// Route → handler. Handlers return `Result` and errors are mapped to
    /// responses by the caller.
    async fn dispatch(
        &self,
        route: Route,
        req: &ForgeRequest,
        _agent: &ForgeAgent,
    ) -> Result<ForgeResponse, ForgeError> {
        match route {
            Route::Index => self.h_index_filtered(req, _agent).await,
            Route::OwnerIndex { owner } => self.h_owner(&owner).await,
            Route::GitSmart { rel_path } => self.h_git_smart(req, _agent, &rel_path).await,
            Route::RepoOverview { owner, repo } => self.h_overview(&owner, &repo).await,
            Route::Tree {
                owner,
                repo,
                rev,
                path,
            } => self.h_tree(&owner, &repo, &rev, &path).await,
            Route::Blob {
                owner,
                repo,
                rev,
                path,
            } => self.h_blob(&owner, &repo, &rev, &path).await,
            Route::Raw {
                owner,
                repo,
                rev,
                path,
            } => self.h_raw(&owner, &repo, &rev, &path).await,
            Route::Commits { owner, repo, rev } => self.h_commits(req, &owner, &repo, &rev).await,
            Route::Commit { owner, repo, sha } => self.h_commit(&owner, &repo, &sha).await,
            Route::Branches { owner, repo } => self.h_branches(&owner, &repo).await,
            Route::Tags { owner, repo } => self.h_tags(&owner, &repo).await,
            Route::BlocktrailsJson { owner, repo } => self.h_blocktrails_json(&owner, &repo).await,
            #[cfg(feature = "anchoring")]
            Route::ApiMarks { owner, repo, tail } => {
                self.h_api_marks(req, _agent, &owner, &repo, &tail).await
            }
            #[cfg(feature = "anchoring")]
            Route::Marks { owner, repo } => self.h_marks_page(req, &owner, &repo).await,
            #[cfg(not(feature = "anchoring"))]
            Route::ApiMarks { .. } | Route::Marks { .. } => Err(ForgeError::Unsupported(
                "anchoring is not compiled into this build".into(),
            )),
            Route::ApiMirror { owner, repo } => Ok(self.h_api_mirror(&owner, &repo)),
            Route::ApiNostr { owner, repo } => self.h_api_nostr(req, &owner, &repo).await,
            Route::ApiAnnounce { owner, repo } => {
                self.h_api_announce(req, _agent, &owner, &repo).await
            }
            Route::Issues { owner, repo } => {
                if req.method.eq_ignore_ascii_case("POST") {
                    self.h_issue_create(req, _agent, &owner, &repo).await
                } else {
                    self.h_issues_list(req, &owner, &repo).await
                }
            }
            Route::IssueNew { owner, repo } => self.h_issue_new_form(&owner, &repo).await,
            Route::IssueDetail { owner, repo, num } => {
                if req.method.eq_ignore_ascii_case("POST") {
                    self.h_issue_comment(req, _agent, &owner, &repo, num).await
                } else {
                    self.h_issue_detail(&owner, &repo, num).await
                }
            }
            Route::ApiReposList => self.h_api_repo_list(req, _agent, None).await,
            Route::ApiToken => self.h_api_token(req, _agent).await,
            Route::ApiHosted { hex, id } => self.h_api_hosted(req, _agent, &hex, &id).await,
            Route::ApiFork { owner, repo } => self.h_api_fork(req, _agent, &owner, &repo).await,
            Route::ApiCompare { owner, repo, spec } => {
                self.h_api_compare(_agent, &owner, &repo, &spec).await
            }
            Route::ApiPulls { owner, repo, tail } => {
                self.h_api_pulls(req, _agent, &owner, &repo, &tail).await
            }
            Route::Compare { owner, repo, spec } => {
                self.h_compare_page(_agent, &owner, &repo, &spec).await
            }
            Route::Pulls { owner, repo, tail } => {
                self.h_pulls_page(req, _agent, &owner, &repo, &tail).await
            }
            // Read features (readfeat): JSON API, search, releases, xlogin.
            Route::Xlogin => Ok(xlogin::xlogin_response(&req.method)),
            Route::ApiOwnerRepos { owner } => self.h_api_repo_list(req, _agent, Some(&owner)).await,
            Route::ApiRepo { owner, repo } => self.h_api_repo(req, _agent, &owner, &repo).await,
            Route::ApiRepoAction {
                owner,
                repo,
                action,
                tail,
            } => {
                self.h_api_repo_action(req, _agent, &owner, &repo, &action, &tail)
                    .await
            }
            Route::RepoSearch { owner, repo } => self.h_search_page(req, &owner, &repo).await,
            Route::RepoReleases { owner, repo } => self.h_releases_page(&owner, &repo).await,
            Route::RepoArchive { owner, repo, spec } => self.h_archive(&owner, &repo, &spec).await,
            Route::ApiEdit { owner, repo } => Ok(self.h_api_edit(req, _agent, &owner, &repo).await),
            Route::ApiPreview { owner, repo } => {
                Ok(self.h_api_preview(req, _agent, &owner, &repo).await)
            }
            // The remaining routes are implemented in later phases.
            _ => Err(ForgeError::NotFound("not implemented".into())),
        }
    }

    /// Resolve `<owner>/<repo>` to its bare git-dir, 404ing when the repo
    /// does not exist and 503ing when it is an unmigrated mirror (see
    /// [`Self::unpublished_mirror`]). Validates both segments against
    /// traversal.
    async fn resolve_repo(&self, owner: &str, repo: &str) -> Result<PathBuf, ForgeError> {
        let dir = repo::repo_git_dir(&self.repo_root, owner, repo)?;
        if !tokio::fs::metadata(&dir)
            .await
            .map(|m| m.is_dir())
            .unwrap_or(false)
        {
            return Err(ForgeError::NotFound(format!("repo {owner}/{repo}")));
        }
        if self.unpublished_mirror(owner, repo, &dir).await {
            return Err(unpublished_mirror_error(owner, repo));
        }
        Ok(dir)
    }

    /// Marker gate (defence in depth): a served repository with a mirror
    /// record but no [`PUBLICATION_MARKER`] predates candidate isolation
    /// and may hold commits the mirror never approved. A repository with a
    /// migration journal in any state but `published`
    /// ([`migrate::journal_path`]) is refused first, marked or not. One
    /// journal read, then one `stat` for a marked mirror and two for any
    /// other repository. The record path is
    /// `mirror::MirrorStore`'s layout, checked without the `mirror` feature
    /// so a plugin directory that was mirrored once stays gated. `owner` and
    /// `repo` are already validated path segments (`repo::repo_git_dir`).
    /// A record path that cannot be checked (any error but "not found")
    /// keeps the gate closed.
    async fn unpublished_mirror(&self, owner: &str, repo: &str, dir: &Path) -> bool {
        // Decision 21: a migration journal in any state but `published`
        // (building, moved, failed, unreadable) gates the store, marked or
        // not, record or not. This is what keeps a lost-record legacy store
        // whose migration failed from being served.
        if migrate::journal_gates(&self.plugin_dir, owner, repo).await {
            return true;
        }
        if tokio::fs::metadata(dir.join(PUBLICATION_MARKER))
            .await
            .is_ok()
        {
            return false;
        }
        self.has_mirror_record(owner, repo).await.unwrap_or(true)
    }

    /// Whether `<owner>/<repo>` has a mirror record, marked or not. The path
    /// is `mirror::MirrorStore`'s layout, checked without the `mirror`
    /// feature. `owner` and `repo` must already be validated path segments.
    ///
    /// Fails closed: only "not found" means no record. Any other error
    /// (permissions, I/O, a parent that is not a directory) is returned, and
    /// every caller treats it as "may be a mirror" (Codex round 3).
    ///
    /// # Errors
    ///
    /// The `stat` error, when it is anything but "not found".
    pub(crate) async fn has_mirror_record(
        &self,
        owner: &str,
        repo: &str,
    ) -> Result<bool, ForgeError> {
        let record = self
            .plugin_dir
            .join("mirror")
            .join(owner)
            .join(format!("{repo}.json"));
        // `symlink_metadata`: a dangling symlink is an entry, so a record.
        match tokio::fs::symlink_metadata(&record).await {
            Ok(_) => Ok(true),
            Err(e) if e.kind() == std::io::ErrorKind::NotFound => Ok(false),
            Err(e) => {
                tracing::warn!(owner = %owner, repo = %repo, error = %e, "forge: mirror record unreadable; treated as a mirror");
                Err(ForgeError::Busy(format!(
                    "'{owner}/{repo}' cannot be checked for a mirror record"
                )))
            }
        }
    }

    /// Refuse (409) any forge write into a mirror's served store: a foreign
    /// compare or pull request head fetched into it, a merge, a web edit, a
    /// fork onto its name. Only the mirror's publication writes there, and
    /// only approved history (Codex High 1); anything else would put objects
    /// in served that are readable by SHA and never passed a verdict.
    pub(crate) async fn refuse_mirror_write(
        &self,
        owner: &str,
        repo: &str,
    ) -> Result<(), ForgeError> {
        if self.has_mirror_record(owner, repo).await? {
            return Err(ForgeError::Conflict(format!(
                "'{owner}/{repo}' is a mirror: only its publication writes to it"
            )));
        }
        Ok(())
    }

    /// The bare git-dir of `<owner>/<repo>` for a reader that does not enter
    /// through [`Self::resolve_repo`] (smart-HTTP, a listing's summary, the
    /// pull request and compare internals, the head of a cross-repository
    /// compare): validated like it, and refused (503) when the repository
    /// exists and is an unmigrated mirror (see [`Self::unpublished_mirror`]).
    /// A missing repository is not an error here; the caller's git fails.
    pub(crate) async fn gated_git_dir(
        &self,
        owner: &str,
        repo: &str,
    ) -> Result<PathBuf, ForgeError> {
        let dir = repo::repo_git_dir(&self.repo_root, owner, repo)?;
        let present = tokio::fs::metadata(&dir).await.is_ok_and(|m| m.is_dir());
        if present && self.unpublished_mirror(owner, repo, &dir).await {
            return Err(unpublished_mirror_error(owner, repo));
        }
        Ok(dir)
    }

    // ---- Tier 1: index + git smart-HTTP ---------------------------------

    async fn h_owner(&self, owner: &str) -> Result<ForgeResponse, ForgeError> {
        let repos = repo::list_owner(&self.repo_root, owner).await;
        if repos.is_empty() {
            return Err(ForgeError::NotFound(format!("owner {owner}")));
        }
        let page = html::owner_page(&self.prefix(), owner, &repos);
        let pairs: Vec<(String, String)> = repos
            .iter()
            .map(|r| (owner.to_string(), r.clone()))
            .collect();
        Ok(ForgeResponse::html(
            200,
            self.decorate_listing(&page, &pairs),
        ))
    }

    /// Forward a git smart-HTTP request to the reused CGI service. The
    /// server has already WAC-gated the scope; auth for the CGI itself is
    /// the pod's existing `Basic nostr:`/NIP-98 path inside the git crate.
    async fn h_git_smart(
        &self,
        req: &ForgeRequest,
        agent: &ForgeAgent,
        rel_path: &str,
    ) -> Result<ForgeResponse, ForgeError> {
        let git_req = GitRequest {
            method: req.method.clone(),
            path: rel_path.to_string(),
            query: req.query.clone(),
            headers: req.headers.clone(),
            body: req.raw_body.clone(),
            host_url: req.host_url.clone(),
        };
        // Namespace push guard: a push (receive-pack) may only target the
        // caller's own namespace. Pushing into another owner's namespace
        // is `403` (JSS forge namespace guard). Reads are unaffected here;
        // the server's WAC gate governs private-repo read access.
        if git_req.is_write() {
            let owner = rel_path
                .trim_start_matches('/')
                .split('/')
                .next()
                .unwrap_or("");
            if !agent.can_write_namespace(owner) {
                return Err(ForgeError::Forbidden(format!(
                    "cannot push into namespace '{owner}'"
                )));
            }
            let name = rel_path
                .trim_start_matches('/')
                .split('/')
                .nth(1)
                .map_or("", |n| n.strip_suffix(".git").unwrap_or(n));
            // The migration tombstone: while any journal exists, in any
            // state, nothing but the migration writes the store.
            if migrate::journal_exists(&self.plugin_dir, owner, name) {
                return Err(ForgeError::Busy(format!(
                    "'{owner}/{name}' is being migrated"
                )));
            }
            // A mirrored repository is written by the mirror alone: a push
            // could race its ref updates and would be overwritten by the next
            // state anyway.
            #[cfg(feature = "mirror")]
            {
                // A record that exists but cannot be read is still a mirror's.
                if !matches!(
                    mirror::MirrorStore::new(&self.plugin_dir).load(owner, name),
                    mirror::StoredRecord::Missing
                ) {
                    return Err(ForgeError::Forbidden(format!(
                        "'{owner}/{name}' is a mirror and read-only"
                    )));
                }
            }
        }
        // Marker gate, after the write guard above: smart-HTTP bypasses
        // `resolve_repo`, so an unmigrated mirror is refused here too.
        {
            let mut parts = rel_path.trim_start_matches('/').split('/');
            if let (Some(owner), Some(name)) = (parts.next(), parts.next()) {
                let name = name.strip_suffix(".git").unwrap_or(name);
                // Any refusal stops the request here. The CGI exports every
                // bare repository under `repos/`, so a name the forge does not
                // accept as a repository (such as a crashed fork's
                // `.fork-*.tmp` directory) is 404, never the CGI's to serve
                // (decision 22). A missing repository is still the CGI's.
                match self.gated_git_dir(owner, name).await {
                    Ok(_) | Err(ForgeError::NotFound(_)) => {}
                    Err(ForgeError::PathTraversal(_)) => {
                        return Err(ForgeError::NotFound(format!("repo {owner}/{name}")));
                    }
                    Err(e) => return Err(e),
                }
            }
        }
        // A completed push to a default branch advances an anchored trail
        // (JSS `recordTip` on receive-pack exit). The CGI response is fully
        // buffered, so by the time `handle` returns the refs are updated.
        #[cfg(feature = "anchoring")]
        let pushed = git_req.method.eq_ignore_ascii_case("POST")
            && rel_path
                .trim_end_matches('/')
                .ends_with("/git-receive-pack");
        let resp = self.git.handle(git_req).await?;
        #[cfg(feature = "anchoring")]
        if pushed && resp.status < 300 {
            let mut parts = rel_path.trim_start_matches('/').split('/');
            if let (Some(owner), Some(name)) = (parts.next(), parts.next()) {
                let name = name.strip_suffix(".git").unwrap_or(name);
                self.record_pushed_tip(owner, name).await;
            }
        }
        Ok(ForgeResponse {
            status: resp.status,
            headers: resp.headers,
            body: resp.body,
        })
    }

    // ---- Tier 1: browse -------------------------------------------------

    async fn h_overview(&self, owner: &str, repo: &str) -> Result<ForgeResponse, ForgeError> {
        let dir = self.resolve_repo(owner, repo).await?;
        let prefix = self.prefix();
        // Description, search box and open-issue badge under the header.
        let open = spine::issues::load_issue_index(self.spine.as_ref(), owner, repo)
            .await
            .map(|i| i.count(spine::issues::IssueState::Open))
            .unwrap_or(0);
        let description = api::repo_description(&dir).await;
        let extras = html::repo_extras(&prefix, owner, repo, &description, open);
        if !repo::browse::has_commits(&dir).await {
            let page = html::repo_overview_page(&prefix, owner, repo, "main", &[], None);
            let page = self.decorate_overview(page, owner, repo).await;
            return Ok(ForgeResponse::html(
                200,
                html::inject_after_header(&page, &extras),
            ));
        }
        let branch = repo::browse::default_branch(&dir).await;
        let entries = repo::browse::list_tree(&dir, &branch, "").await?;
        // README detection (case-insensitive common names).
        let readme = self.find_readme(&dir, &branch, &entries).await;
        let page =
            html::repo_overview_page(&prefix, owner, repo, &branch, &entries, readme.as_deref());
        let page = self.decorate_overview(page, owner, repo).await;
        Ok(ForgeResponse::html(
            200,
            html::inject_after_header(&page, &extras),
        ))
    }

    /// Read a bounded, textual README from the root tree if one exists.
    async fn find_readme(
        &self,
        dir: &Path,
        rev: &str,
        entries: &[repo::browse::TreeEntry],
    ) -> Option<String> {
        let candidate = entries.iter().find(|e| {
            e.kind == repo::browse::EntryKind::File && {
                let n = e.name.to_ascii_lowercase();
                n == "readme" || n == "readme.md" || n == "readme.txt"
            }
        })?;
        let bytes =
            repo::browse::read_blob(dir, rev, &candidate.name, self.cfg.max_body_bytes as u64)
                .await
                .ok()?;
        if request::looks_textual(&bytes) {
            Some(String::from_utf8_lossy(&bytes).into_owned())
        } else {
            None
        }
    }

    async fn h_blob(
        &self,
        owner: &str,
        repo: &str,
        rev: &str,
        path: &str,
    ) -> Result<ForgeResponse, ForgeError> {
        let dir = self.resolve_repo(owner, repo).await?;
        // Cap the in-browser render; oversized/binary blobs get a download
        // link instead of buffering into the page.
        const BLOB_VIEW_MAX: u64 = 1024 * 1024;
        let content = match repo::browse::read_blob(&dir, rev, path, BLOB_VIEW_MAX).await {
            Ok(bytes) => {
                if request::looks_textual(&bytes) {
                    Some(String::from_utf8_lossy(&bytes).into_owned())
                } else {
                    None
                }
            }
            // Too large to inline — offer the raw download.
            Err(ForgeError::BadRequest(_)) => None,
            Err(e) => return Err(e),
        };
        Ok(ForgeResponse::html(
            200,
            html::blob_page(&self.prefix(), owner, repo, rev, path, content.as_deref()),
        ))
    }

    async fn h_raw(
        &self,
        owner: &str,
        repo: &str,
        rev: &str,
        path: &str,
    ) -> Result<ForgeResponse, ForgeError> {
        let dir = self.resolve_repo(owner, repo).await?;
        // Generous cap for raw downloads; still bounded to avoid OOM.
        const RAW_MAX: u64 = 25 * 1024 * 1024;
        let bytes = repo::browse::read_blob(&dir, rev, path, RAW_MAX).await?;
        let is_text = request::looks_textual(&bytes);
        let filename = path.rsplit('/').next().unwrap_or("download");
        Ok(ForgeResponse::raw_bytes(
            bytes::Bytes::from(bytes),
            is_text,
            filename,
        ))
    }

    /// `api/repos/<owner>/<repo>/mirror`: the mirror record, or 404 when the
    /// repository is not a mirror. Served without a repo-exists check: a
    /// followed repository has a record before it has a bare repository
    /// (no clone URL yet, a failing remote), and the record is the diagnosis
    /// the operator needs. Without the `mirror` feature there are no records.
    #[cfg(feature = "mirror")]
    fn h_api_mirror(&self, owner: &str, repo: &str) -> ForgeResponse {
        match mirror::MirrorStore::new(&self.plugin_dir).load(owner, repo) {
            mirror::StoredRecord::Valid(rec) => ForgeResponse::json(
                200,
                &serde_json::to_value(&rec).unwrap_or(serde_json::Value::Null),
            ),
            mirror::StoredRecord::Missing => {
                ForgeResponse::json(404, &serde_json::json!({"error": "not a mirror"}))
            }
            // Still a mirror: refused like every other reader of it.
            mirror::StoredRecord::Unreadable(_) => ForgeResponse::json(
                503,
                &serde_json::json!({"error": "the mirror record cannot be read"}),
            ),
        }
    }

    /// `blocktrails.json` for a repo-held git-mark trail: the committed
    /// document itself, re-serialised so only JSON goes out, with the
    /// wide-open CORS the hosted verifier needs. A repository without a trail
    /// answers 404 in the same shape and with the same CORS, so a browser
    /// client can tell "no trail" from "blocked".
    async fn h_blocktrails_json(
        &self,
        owner: &str,
        repo: &str,
    ) -> Result<ForgeResponse, ForgeError> {
        // A forge-held trail wins; its pending marks ride additively.
        #[cfg(feature = "anchoring")]
        if let Some(doc) = self.forge_blocktrails_json(owner, repo)? {
            let mut resp = ForgeResponse::with_type(
                200,
                "application/json; charset=utf-8",
                bytes::Bytes::from(doc),
            );
            resp.headers
                .push(("access-control-allow-origin".into(), "*".into()));
            resp.headers
                .push(("x-content-type-options".into(), "nosniff".into()));
            return Ok(resp);
        }
        let dir = self.resolve_repo(owner, repo).await?;
        let branch = repo::browse::default_branch(&dir).await;
        let (status, body) = match gitmark::read_repo_trail(&dir, &branch).await {
            Some(trail) => (200, trail.document_json()),
            None => (
                404,
                serde_json::json!({"error": "anchoring is not enabled for this repository"})
                    .to_string(),
            ),
        };
        let mut resp = ForgeResponse::with_type(
            status,
            "application/json; charset=utf-8",
            bytes::Bytes::from(body),
        );
        resp.headers
            .push(("access-control-allow-origin".into(), "*".into()));
        resp.headers
            .push(("x-content-type-options".into(), "nosniff".into()));
        Ok(resp)
    }

    /// Parse `{title?, resourceUrl?, body?}` from a JSON or form-encoded
    /// body. `resourceUrl` is the pod-hosted pointer (pod agents); `body`
    /// is the inline content (podless `did:nostr` agents).
    fn parse_issue_body(req: &ForgeRequest) -> (Option<String>, Option<String>, Option<String>) {
        let ct = req.header("content-type").unwrap_or("");
        let raw = String::from_utf8_lossy(&req.raw_body);
        let field_json = |v: &serde_json::Value, k: &str| {
            v.get(k).and_then(|x| x.as_str()).map(|s| s.to_string())
        };
        if ct.contains("application/json") {
            if let Ok(v) = serde_json::from_str::<serde_json::Value>(&raw) {
                return (
                    field_json(&v, "title"),
                    field_json(&v, "resourceUrl"),
                    field_json(&v, "body"),
                );
            }
        }
        let pairs = request::parse_form(&raw);
        let field = |k: &str| pairs.iter().find(|(kk, _)| kk == k).map(|(_, v)| v.clone());
        (field("title"), field("resourceUrl"), field("body"))
    }

    /// Build a verified [`ThreadPointer`] for `agent`'s contribution:
    /// - **Pod agent** → validate + loopback-verify the pod `resource_url`.
    /// - **Nostr agent** → store `body` inline in forge-hosted storage.
    /// - **Anonymous** → `401`.
    async fn make_pointer(
        &self,
        req: &ForgeRequest,
        agent: &ForgeAgent,
        owner: &str,
        repo: &str,
        resource_url: Option<&str>,
        body: Option<&str>,
    ) -> Result<spine::issues::ThreadPointer, ForgeError> {
        match agent {
            ForgeAgent::Anonymous => {
                Err(ForgeError::Unauthorised("authentication required".into()))
            }
            ForgeAgent::Nostr { pubkey_hex } => {
                // Podless: the body is submitted inline and hosted 0600.
                let body = body
                    .map(str::trim)
                    .filter(|b| !b.is_empty())
                    .ok_or_else(|| ForgeError::BadRequest("body required".into()))?;
                let doc = hosted_edit::hosted_doc(
                    "ForgeComment",
                    owner,
                    repo,
                    None,
                    None,
                    body,
                    &agent.author_id(),
                    now_secs(),
                );
                let rref = self.hosted.write_doc(pubkey_hex, &doc).await?;
                Ok(spine::issues::ThreadPointer {
                    author: agent.author_id(),
                    resource_url: rref,
                    at: now_secs(),
                    hosted: true,
                })
            }
            ForgeAgent::Pod { .. } => {
                let url = resource_url
                    .ok_or_else(|| ForgeError::BadRequest("resourceUrl required".into()))?;
                self.verify_pod_pointer(req, agent, owner, repo, url).await
            }
        }
    }

    /// Verify a pod-hosted body pointer: the URL must be in the caller's
    /// own forge area (SSRF guard) and unauthenticated-readable. Returns
    /// the validated `ThreadPointer` on success.
    async fn verify_pod_pointer(
        &self,
        req: &ForgeRequest,
        agent: &ForgeAgent,
        repo_owner: &str,
        repo: &str,
        resource_url: &str,
    ) -> Result<spine::issues::ThreadPointer, ForgeError> {
        let caller = agent
            .owner()
            .ok_or_else(|| ForgeError::Unauthorised("authentication required".into()))?;
        let host = req
            .host_url
            .as_deref()
            .ok_or_else(|| ForgeError::BadRequest("missing host".into()))?;
        // SSRF + own-area guard.
        bodies::own_area_ok(resource_url, host, caller, repo_owner, repo)?;
        // Confirm public readability with a single loopback GET.
        let lb = self
            .loopback
            .as_ref()
            .ok_or_else(|| ForgeError::Unsupported("pod body verification unavailable".into()))?;
        match lb
            .get(
                resource_url,
                self.cfg.max_body_bytes,
                self.cfg.fetch_timeout_secs,
            )
            .await
        {
            bodies::FetchResult::Body(_) => Ok(spine::issues::ThreadPointer {
                author: agent.author_id(),
                resource_url: resource_url.to_string(),
                at: now_secs(),
                hosted: false,
            }),
            bodies::FetchResult::Removed => Err(ForgeError::BadRequest(
                "pod body is not publicly readable".into(),
            )),
            bodies::FetchResult::TooLarge => {
                Err(ForgeError::BadRequest("pod body too large".into()))
            }
            bodies::FetchResult::Error(e) => {
                Err(ForgeError::Backend(format!("pod body fetch failed: {e}")))
            }
        }
    }

    async fn h_issue_create(
        &self,
        req: &ForgeRequest,
        agent: &ForgeAgent,
        owner: &str,
        repo: &str,
    ) -> Result<ForgeResponse, ForgeError> {
        self.resolve_repo(owner, repo).await?;
        let (title, resource_url, body) = Self::parse_issue_body(req);
        let title = title
            .map(|t| t.trim().to_string())
            .filter(|t| !t.is_empty())
            .ok_or_else(|| ForgeError::BadRequest("title required".into()))?;

        // Pod agents supply a pod pointer; podless nostr agents supply an
        // inline body stored in forge-hosted storage.
        let pointer = self
            .make_pointer(
                req,
                agent,
                owner,
                repo,
                resource_url.as_deref(),
                body.as_deref(),
            )
            .await?;

        let _guard = self.locks.issues.lock(owner, repo).await;
        let mut idx = spine::issues::load_issue_index(self.spine.as_ref(), owner, repo).await?;
        let entry = spine::issues::IssueEntry {
            number: 0,
            title,
            state: spine::issues::IssueState::Open,
            author: agent.author_id(),
            created_at: now_secs(),
            thread: vec![pointer],
            labels: Vec::new(),
        };
        let num = idx.allocate(entry);
        spine::issues::save_issue_index(self.spine.as_ref(), owner, repo, &idx).await?;

        let location = format!("{}/{}/{}/issues/{}", self.prefix(), owner, repo, num);
        Ok(ForgeResponse::redirect(303, &location))
    }

    async fn h_issue_comment(
        &self,
        req: &ForgeRequest,
        agent: &ForgeAgent,
        owner: &str,
        repo: &str,
        num: u64,
    ) -> Result<ForgeResponse, ForgeError> {
        self.resolve_repo(owner, repo).await?;
        let (_title, resource_url, body) = Self::parse_issue_body(req);
        let pointer = self
            .make_pointer(
                req,
                agent,
                owner,
                repo,
                resource_url.as_deref(),
                body.as_deref(),
            )
            .await?;

        let _guard = self.locks.issues.lock(owner, repo).await;
        let mut idx = spine::issues::load_issue_index(self.spine.as_ref(), owner, repo).await?;
        let entry = idx
            .issues
            .get_mut(&num)
            .ok_or_else(|| ForgeError::NotFound(format!("issue #{num}")))?;
        entry.thread.push(pointer);
        spine::issues::save_issue_index(self.spine.as_ref(), owner, repo, &idx).await?;

        let location = format!("{}/{}/{}/issues/{}", self.prefix(), owner, repo, num);
        Ok(ForgeResponse::redirect(303, &location))
    }

    /// `POST /api/token` — mint a forge push token for the (already
    /// authenticated) caller. The server resolves the caller via NIP-98 /
    /// pod session before calling `handle`; an anonymous caller is `401`.
    async fn h_api_token(
        &self,
        req: &ForgeRequest,
        agent: &ForgeAgent,
    ) -> Result<ForgeResponse, ForgeError> {
        if !req.method.eq_ignore_ascii_case("POST") {
            return Err(ForgeError::NotFound("token requires POST".into()));
        }
        let iat = now_secs();
        let ttl = self.cfg.token_ttl_secs;
        let token = token::mint(self.token_key.as_ref(), agent, iat, ttl).ok_or_else(|| {
            ForgeError::Unauthorised("authentication required to mint a token".into())
        })?;
        let v = serde_json::json!({
            "token": token,
            "tokenType": "Bearer",
            "expiresIn": ttl,
            "exp": iat + ttl,
            "agent": agent.author_id(),
        });
        Ok(ForgeResponse::json(200, &v))
    }

    /// M4: a page that loads the widget keeps the widget policy; any other
    /// HTML page gets the strict nonce policy with a fresh nonce.
    #[test]
    fn widget_pages_keep_the_widget_csp_and_others_get_a_nonce() {
        let (_td, svc) = service();
        let csp = |r: &ForgeResponse| {
            r.headers
                .iter()
                .find(|(k, _)| k == "content-security-policy")
                .map(|(_, v)| v.clone())
                .unwrap_or_default()
        };
        let plain = svc.finish_page(ForgeResponse::html(200, "<p>hi</p>".to_string()));
        let widget = svc.finish_page(
            ForgeResponse::html(200, "<p>w</p>".to_string())
                .with_header(WIDGET_PAGE_HEADER, "widget"),
        );
        // Text that merely mentions the widget (injected markup, a file
        // named xlogin.js) must not select the weak policy.
        let mention = svc.finish_page(ForgeResponse::html(
            200,
            "<p>&lt;script src=\"/forge/xlogin.js\"&gt;</p>".to_string(),
        ));
        assert!(csp(&mention).contains("script-src 'self' 'nonce-"));
        assert!(widget.headers.iter().all(|(k, _)| k != WIDGET_PAGE_HEADER));
        assert!(csp(&plain).contains("script-src 'self' 'nonce-"));
        assert!(!csp(&plain).contains("unsafe-inline' 'self'"));
        assert!(csp(&widget).contains("script-src 'unsafe-inline' 'self' https://esm.sh"));
        let again = svc.finish_page(ForgeResponse::html(200, "<p>hi</p>".to_string()));
        assert_ne!(csp(&plain), csp(&again), "the nonce is fresh per response");
    }

    fn git_available() -> bool {
        std::process::Command::new("git")
            .arg("--version")
            .stdout(std::process::Stdio::null())
            .stderr(std::process::Stdio::null())
            .status()
            .map(|s| s.success())
            .unwrap_or(false)
    }

    fn run_git(dir: &std::path::Path, args: &[&str]) {
        let ok = std::process::Command::new("git")
            .args(args)
            .current_dir(dir)
            .env("GIT_CONFIG_NOSYSTEM", "1")
            .stdout(std::process::Stdio::null())
            .stderr(std::process::Stdio::null())
            .status()
            .map(|s| s.success())
            .unwrap_or(false);
        assert!(ok, "git {args:?} failed in {}", dir.display());
    }

    /// Create `repos/<owner>/<name>.git` as a bare repo containing a
    /// README, a `src/lib.rs`, and a `v1.0` tag, via a working clone.
    fn seed_repo(td: &TempDir, owner: &str, name: &str) {
        let work = td.path().join(format!("work-{owner}-{name}"));
        std::fs::create_dir_all(&work).unwrap();
        run_git(&work, &["init", "-b", "main"]);
        std::fs::write(work.join("README.md"), "# Demo\nhello forge\n").unwrap();
        std::fs::create_dir_all(work.join("src")).unwrap();
        std::fs::write(work.join("src/lib.rs"), "pub fn f() -> u8 { 42 }\n").unwrap();
        run_git(&work, &["add", "-A"]);
        run_git(
            &work,
            &[
                "-c",
                "user.email=t@e.st",
                "-c",
                "user.name=Tester",
                "commit",
                "-m",
                "initial commit",
            ],
        );
        run_git(&work, &["tag", "v1.0"]);
        let bare = td
            .path()
            .join("repos")
            .join(owner)
            .join(format!("{name}.git"));
        std::fs::create_dir_all(bare.parent().unwrap()).unwrap();
        run_git(
            td.path(),
            &[
                "clone",
                "--bare",
                work.to_str().unwrap(),
                bare.to_str().unwrap(),
            ],
        );
    }

    use std::collections::HashMap;
    use std::sync::Mutex;

    struct MockLb {
        present: Mutex<HashMap<String, Vec<u8>>>,
    }
    impl MockLb {
        fn new() -> Self {
            Self {
                present: Mutex::new(HashMap::new()),
            }
        }
        fn put(&self, url: &str, body: &[u8]) {
            self.present
                .lock()
                .unwrap()
                .insert(url.into(), body.to_vec());
        }
        fn remove(&self, url: &str) {
            self.present.lock().unwrap().remove(url);
        }
    }
    #[async_trait::async_trait]
    impl bodies::LoopbackFetch for MockLb {
        async fn get(&self, url: &str, _max: usize, _to: u64) -> bodies::FetchResult {
            match self.present.lock().unwrap().get(url) {
                Some(b) => bodies::FetchResult::Body(b.clone()),
                None => bodies::FetchResult::Removed,
            }
        }
    }

    fn pod_agent(user: &str) -> ForgeAgent {
