**tracked_files uses `git ls-tree` without -z, mishandling special filenames**
<sub>slug: `other-logic-bug` · confidence: high</sub>

tracked_files() runs `git ls-tree -r -l --full-tree <rev>` and feeds stdout to parse_ls_tree(), which splits each line on the first tab. Without -z, git C-quotes any path containing non-ASCII bytes, spaces combined with specials, double-quotes, or control characters — emitting e.g. `"src/\303\251.rs"` (surrounding quotes, backslash-octal escapes) instead of the raw path. parse_ls_tree stores that quoted/escaped string literally as TrackedFile.path.
