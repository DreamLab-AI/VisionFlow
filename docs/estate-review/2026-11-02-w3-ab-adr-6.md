# agentbox ADR-2119 to ADR-2139

ADR-2121's `verified_paths` names a factrail lockfile that no longer exists, so a factrail bump (this record's own review trigger) can pass a staleness diff without tripping it. That is the most consequential defect in this group. The decisions themselves hold in source, and the other defects are also in record text:

- ADR-2119 still names `vault` as the corpus CLI, where the code uses `ontomark`.
- ADR-2122's Deviations section contradicts its own ER-9 correction about the apply class.
- ADR-2120 describes a Codex tmpfs that is now a volume.
- Four records carry a ruflo version-split note that no longer holds.
- Line citations have drifted in about 20 receipts.
- Two validator-labelling defects from earlier receipts remain open at pin: E080 is used for two different checks, and a comment gives E081 the wrong meaning.

This report assesses group ab-adr-6: 15 agentbox decision records, ADR-2119 to ADR-2139, with all 281 headed sections traced at agentbox `c57d9c0508f4`. All 15 are operative decisions. ADR-2122 is still `proposed`: its mechanism is built into every image but gated off. None is superseded or an imported copy.

## Findings

**F1. ADR-2119 Decision names the wrong corpus CLI (Drift).**
- **Trigger.** The 2026-10-31 owner decision made `ontomark` the one corpus CLI.
- **Consequence.** A reader of the Decision (`docs/adr/ADR-2119-…md:57`) is told to author through `vault`. At pin, `management-api/lib/ontology-apply.js:154-159` sends every verb except `propose`/`panel` to `ontomark`, and `flake.nix:956-960` bakes both. `dream.config.json:72` still tells the dream engine the evaluators exercise "the current vault CLI boundary" and that the "upstream vault crate" owns parsing.
- **Close.** Add a dated amendment to the Decision line and correct the `dream.config.json` discipline text.

**F2. ADR-2119 cites a guard script at the wrong path (Drift).** `:258` names `scripts/check-no-logseq-paths.sh`; at pin it is `scripts/ci/check-no-logseq-paths.sh` (`:10-12`, `:29-31`). Its content matches the claim. Close: fix the path.

**F3. ADR-2121 `verified_paths` names a deleted lockfile (Drift).**
- **Evidence.** Frontmatter line 11 lists `lib/lockfiles/factrail-57ac25b5.Cargo.lock`. At pin the rev is `d270a0a1…` (`lib/factrail.nix:36`) and the lockfile is `lib/lockfiles/factrail-d270a0a1.Cargo.lock`.
- **Consequence.** Any staleness diff over `verified_paths` silently skips the real lockfile, so a factrail bump, this record's own review trigger, would not trip it. The 2026-10-07 section's "still at rev 57ac25b5" is overtaken.
- **Close.** Replace the path in `verified_paths`.

**F4. ADR-2122 contradicts itself, and one invariant is not yet true (Drift, Open).**
- **Apply class.** The Deviations section says "The catalogue apply class is `boot`, not `rebuild`", but the catalogue is `rebuild` (`management-api/lib/system-manifest.js:98`), as the record's own ER-9 section says.
- **Obsolete owed item.** "The aoe-share copy for `ab-gateway` and `ab-ingress`" is still listed as owed, but AoE is retired (ADR-2153).
- **Open invariant.** The first Invariant ("No process other than `nostr-pod-bridge` holds … JunkieJarvis") is not yet true. dream-engine signs 31400/31402 as JunkieJarvis (`services/dream-engine/src/governance.rs:9-10`), and the ACL declares no agent-governance key (`config/custody/identity-port-acl.json:18-41`). The record admits this (ER-6 decided, W3b owed), so it is an Open item, not a hidden defect.
- **Gating.** The flag ships off (`agentbox.toml:2543`), so none of the flag-on behaviour can be confirmed from source.
- **Close.** Strike or annotate the boot-class bullet and the aoe-share item, and qualify the first invariant until W3b lands.

**F5. ADR-2120 describes a Codex tmpfs that no longer exists (Drift).** The Context and the 2026-10-13 receipt say the parent `/home/devuser/.codex` is a 512 MiB noexec tmpfs. At pin it is the `codex-home` named volume (`docker-compose.yml:147`, `:200-201`; `flake.nix:3876`), per ADR-2147. The decision itself (the `agentbox-codex-packages` volume) holds (`docker-compose.yml:148`, `:202-203`). Close: a dated note under Context.

**F6. Four records carry a superseded ruflo version-split note (Drift).** The 2026-10-23 corrections in ADR-2121, ADR-2134 and ADR-2135, and ADR-2123's Clarification, say the console plugin is at `856de8f3` while the npm runtime stays 3.57.0. Close: one dated note per record, or drop the numbers.

**F7. ADR-2129 cites the wrong SKILL.md lines (Drift).** Decision 4 cites `SKILL.md:157-165` and the 2026-10-13 correction `:159-167`. The `## Writes are still governed` section is at `skills/ontology-augment/SKILL.md:212`. The Context's "vault CLI" grounding path is overtaken by `ontomark` (`ontology-augment.sh:121-139`). **F8. Validator code labels are still ambiguous (Tension).** `E080` names both ADR-2138's relative-path rule (`scripts/agentbox-config-validate.js:645-670`) and ADR-2139's System One rules (`:1582-1624`). The `agentbox.toml:887` comment describes E081 as "local backend with an off-LAN url", but the validator's E081 is the `[system_one]`/`sovereign_system_one` mutual exclusion (`:1599-1601`). **F9. ADR-2139 frontmatter is internally inconsistent (Drift).** `acceptance_boundary` calls `2f15c531b` the verified commit; `verified_commit` is `4f3bd5325…`. Close: update the sentence.

**F10. **F11.
