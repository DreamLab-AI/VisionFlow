# Estate topology, agent events and federation contract

I assessed all 32 panels in three cross-repository estate topics, ES-01 (estate topology, 8), ES-02 (agent events from agentbox to VisionClaw, 12) and ES-03 (cross-repo federation contract, 12), by source tracing at the wave 2 pinned revisions. Every topic was restamped and every citation re-resolved from its symbol. Five panels are accurate, 26 corrected, one accurate-with-limits and none inaccurate-unfixed. The most important finding is that the live agentbox-to-VisionClaw forwarder sends the wrong wire shape: `agent-event-ws-subscriber.js` sends the publisher's bare event, while VisionClaw's ingest only accepts the JSON-RPC `notifications/agent_action` envelope, so by source every forwarded frame is classified `Malformed` and never reaches the hub or the beam render. Several corrections fix claims that were already wrong at the previous stamp, so a passing strict cite-check had shown only that the lines existed, not that they held the claim.

## Findings

1. **The agentbox-to-VisionClaw forward sends a bare event, not the JSON-RPC envelope (ES-02.2, Drift).**
   - Trigger: the publisher emits `event` with the bare `fullEvent` (`agentbox/management-api/utils/agent-event-publisher.js:173` @c57d9c0). The subscriber's listener forwards it with `this.ws.send(JSON.stringify(event))` (`agent-event-ws-subscriber.js:48,144-151`). This subscriber is the wired forwarder (`management-api/server.js:389-390`); the JSON-RPC-wrapping TCP bridge is retired from the route (`routes/agent-events.js:859`).
   - Consequence: `process_frame` deserialises into `AgentActionNotification {jsonrpc, method, params}` (`src/agent_events/schema.rs:26-29`, `src/agent_events/ingest.rs:101,149` @86cdd76). A bare event fails, comes back as `Malformed`, and nothing on this path reaches the hub.
   - Close: send `createMcpNotification(event)` (`agent-event-publisher.js:305`) from the subscriber, and add a cross-repo contract test that feeds the subscriber's real bytes into `process_frame`.
2. **The forwarder presents no credential (ES-02.2, Drift).**
   - Trigger: `new WebSocket(this.url, [SUBPROTOCOL])` is opened with no headers (`agent-event-ws-subscriber.js:94` @c57d9c0), and the derived URL carries no token (`server.js:383`).
   - Consequence: a release VisionClaw ingest rejects the socket (`src/agent_events/ingest.rs:261-293` @86cdd76). Only dev builds with insecure defaults accept it.
   - Close: give the subscriber a header-borne token or a NIP-98 post-connect authentication.
3. **The ingest socket accepts `?token=` in release builds (ES-02.2, Tension).**
   - Trigger: `src/agent_events/ingest.rs:267-271` has no cfg gate. ADR-2090 compiles the query carrier out of release on `mcp_relay_handler.rs:482,496` @86cdd76.
   - Consequence: a bearer can land in access and proxy logs on this one socket.
   - Close: apply the same cfg gate, or record why this server-to-server socket is exempt.
4. **The binary stream mode cannot carry a current event (ES-02.1, Debt).**
   - Trigger: `timestamp: Date.now()` is in milliseconds (`agent-event-publisher.js:54` @c57d9c0) and is written with `writeUInt32LE` (`:281`), which range-checks.
   - Consequence: `?binary=true` subscribers get no frame. The send error is caught and logged (`routes/agent-events.js:37-47`). This is inferred from Node's documented range check, not executed.
   - Close: truncate or rebase the timestamp, as the VisionClaw encoder does (`src/utils/binary_protocol.rs:1587` @86cdd76), and add a unit test with a present-day value.
5. **MAST `failure_mode` and `authority_class` are dropped at ingest, and the Rust `intent` is never emitted (ES-02.3, ES-03.1, Open/Drift).**
   - Trigger: agentbox puts both fields on the wire (`agent-event-publisher.js:326,335` @c57d9c0). `AgentActionEnvelope` declares neither field and does not deny unknown fields (`src/agent_events/schema.rs:61-147` @86cdd76). `intent` (`schema.rs:143`) has no producer.
   - Consequence: the previous "mirrors byte-for-field" claim was false at the old stamp too, and both files are unchanged since. The audit tags are lost silently.
   - Close: add the fields with serde defaults or record the drop as deliberate, and declare `intent` producer-optional.
6. **The solid-pod-rs version skew persists and the ledger docs describing it are stale (ES-01.1, ES-03.12).**
   - Trigger: VisionClaw pins `0.5.0-alpha.17` (`Cargo.toml:246` @86cdd76). agentbox Nix pins `0.5.0-alpha.18` rev `76ab7aab` (`lib/solid-pod-rs.nix:54,56-58` @c57d9c0), and the forum requires `0.5.0-alpha.18` (`nostr-rust-forum/Cargo.toml:185` @c39f41f).
   - Consequence: forum ADR-2012 (`docs/adr/ADR-2012-d1-ledger-becomes-a-chain-view.md:28-30`) and agentbox `docs/proposals/sovereign-settlement.md:61` still describe an alpha.7 forum, and still name a `D1PaymentStore` that is now `D1Ledger` (`crates/nostr-bbs-pod-worker/src/payments.rs:61,82` @c39f41f).
   - Close: bump VisionClaw to alpha.18 or record why it stays, re-verify forum ADR-2012 and PRD-024, and add a gate that compares solid-pod-rs pins across the estate.
7. **The VisionClaw agentbox gitlink is 51 commits behind the agentbox pin (ES-01.1, Drift).**
   - Trigger: the gitlink is `c3746299e` at 86cdd76, an ancestor of c57d9c0. The diff covers 154 files, including config, management-api, mcp, scripts, services and tests.
   - Consequence: the previous "only docs/ differs" edge was wrong at this pin. A VisionClaw checkout builds agentbox code 51 commits old.
   - Close: bump the submodule, or record the lag as intended.
8. **`loom/` in VisionClaw is not deployment notes only (ES-01.6, Drift).**
   - Trigger: `loom/README.md:3-4` @86cdd76 says the directory "no longer contains an implementation". `loom/app/ontology-mcp/` is a tracked stdio MCP server (`index.js`, 577 lines; `README.md:3`), and 179 `.npm-cache` blobs are committed under it.
   - Consequence: the README misstates the tree, and the repository carries a committed package cache.
   - Close: move or delete `ontology-mcp` and the cache, or correct the README.
9. **Literal estate addresses remain in cited agentbox sources (ES-01.2, Drift).**
   - Trigger: `agentbox.toml:1190-1191` and `docs/adr/ADR-2023-loom-facade.md:363` @c57d9c0 state LAN and rail addresses. The previous panel said every literal had been generalised out. That was already false at the old stamp.
   - Close: either generalise these lines or drop the claim. The topic now states the drift.
10. **Orchestrator is a fail-closed adapter slot (ES-03.9).**
    - Trigger: `FAIL_CLOSED_SLOTS = new Set(['orchestrator'])` with a fatal abort (`management-api/adapters/lifecycle.js:75,298-302` @c57d9c0).
    - Consequence: the previous note ("no slot is privileged") was wrong at the old stamp too. `docs/BASELINE-container.md:300` still cites stale lifecycle anchors.
    - Close: the topic is corrected. The BASELINE line is an agentbox doc fix.
11. **The settlement-pack status was overstated (ES-03.11, ES-01.8).**
    - Trigger: ADR-2097 is `accepted / complete / staged` (`docs/adr/ADR-2097-sidestr-rail-supersedes-lightning-first.md:5-7` @c57d9c0). ADR-2106 withdrew the clean-room claim (`ADR-2096…:45-48`).
    - Consequence: "every record proposed" was false.
    - Close: done in the topics.
12. **The Rust federation-kind parity test is not CI-gated (ES-03.5, Tension).**
    - Trigger: ADR-2061 records the gap (`docs/adr/ADR-2061-federation-kind-map-parity.md:232-237` @c57d9c0). VisionClaw's CPU job excludes `visionclaw-server` (`.github/workflows/ci.yml:80-81,258` @86cdd76).
    - Consequence: a one-sided `federation-kinds.json` edit that breaks only Rust passes CI.
    - Close: run `cargo test --lib uri` in a CPU job.
13. **The did:nostr resolver ignores the pubkey (ES-03.8, Open).**
    - Trigger: every `did:nostr:<hex>` redirects to the single pod `/.well-known/did.json` (`management-api/routes/uri-resolver.js:65-75` @c57d9c0).
    - Close: redirect to an identity-specific path, or document a single-identity pod.
14. **The `group_add` note overstated docker access (ES-01.5).**
    - Trigger: `docker-compose.override.yml:156-162` @c57d9c0 says group_add reaches PID 1 only. devuser programs rely on the entrypoint's socket chmod, which `role_isolation` removes.
    - Consequence: the previous "drives docker without sudo" claim was already wrong at the old stamp.
    - Close: done in the topic.
15. **Smaller doc drift.**
    - The host kind table puts estimates and settlements in 38000-38099 (`docs/explanation/visionflow-coordination-platform.md:166` @86cdd76), against agentbox's 38200-38299 band (`docs/PROTOCOL-registry.md:85,87` @c57d9c0).
    - `AgentBeamActor` now owns a 1 s roster tick that its comment calls 5 s (`src/actors/agent_beam_actor.rs:244,302`). Roster frames use a drop-on-full `try_send` outside the held-backlog invariant (`:222-232`).
    - `hub.rs:4-7` still calls the render actor future.
    - `agentbox/CLAUDE.md` no longer names the CDP port. The topic now cites `skills/browser/SKILL.md:33`.
    - Close: correct each doc.
