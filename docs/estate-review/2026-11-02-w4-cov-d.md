# Audit wave 4, coverage D: VisionClaw, agentbox, solid-pod-rs and dream-engine

**Outcome.** I gave all 19 uncited components a disposition. Nine are **assessed**, seven are **out-of-scope** and three are **covered-elsewhere**. None is left as a **gap**. The material results are in VisionClaw's `src/events`. `AppState` builds an `EventBus` and registers four handlers on it, but nothing publishes to that bus. The only production publisher, `PhysicsService`, is handed a second, empty `EventBus` in `main.rs`, so every domain event it emits reaches no subscriber (CD-F1). The file-backed `EventStore` that `AppState` builds is never written (CD-F2). In agentbox, the laya engine downloads its weights with no revision pin, while its sibling openjev refuses to load unpinned weights (CD-F4). The Isaac Sim runner accepts unauthenticated job submissions that run Python with the sidecar's full environment (CD-F3). ES-08.10 says the vendored JavaScriptSolidServer is gone, but its CLI and test suite are still tracked at the VisionClaw root (CD-F6). Evidence class: **source tracing at the pinned revision** only. I ran no build, test or runtime check.

Pins: VisionClaw `project` `86cdd7635582`, agentbox `c57d9c0508f4`, solid-pod-rs `9b6143ce55b2`, dream-engine `bfe8c8885a58`. Paths in the tables are relative to each repository.
