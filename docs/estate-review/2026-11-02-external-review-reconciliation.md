# External review reconciliation

The operator supplied an external architectural summary, strengths/weaknesses list and fourteen remediation groups. This pass checked their mechanisms against current source and the completed audit, then added scoped qualifications to 47 existing ADRs across twelve repositories. Documentation changes are merged to local mains. No implementation, deployment, key cutover or package publication was performed. ## Main corrections

- The table labelled ten areas contains eleven rows and is not the whole estate roster. The diagram catalogue has 212 topics and 1,750 panels across additional areas; the explicit scope remains the roster authority. A revision stamp and valid line citation do not independently prove semantic correctness, security or deployment. The closed-loop description is an architectural intent: the completed audit found eighteen disagreeing cross-repository contracts.
- Numeric crate, actor, line and layer counts are revision snapshots. Current Agentbox has five observed image layers, not four. VisionClaw's external actor roster is not an exhaustive current boot inventory. The named protocols and broad repository responsibilities are supported; pinned package versions do not establish current release adoption.
- GPU comparison deltas are results on named fixtures, not mathematical proofs for every input. Certificate parity is conditional on requesting a certificate and covers the specified named fragment, not every OWL statement or factual truth. A recall harness is a gate with receipts, not evidence that current recall passes.
- Capability confinement applies to operations through the capability-backed filesystem, not automatically to Git subprocesses and every backend. Typestate guarantees apply to APIs that use the checked type; explicit unchecked escape hatches and caller adoption remain relevant.
- Hermes checks captured process identity. The ruflo daemon reaper checks current allowed argv without the same recorded start-time comparison. Neither a separate verify/kill pair nor argv matching alone eliminates every process replacement race.
- NIP-98 proxy bearer expiry/scope controls are optional. Source classifies 36 DEVUSER_CLASS names, rather than the quoted historical 37; classification is not a count of secrets actually set at runtime. File-only RuVector custody already supersedes the blanket ambient-password claim.
- Solid's Git double-prefix routing defect still exists. The merged hidden-object and mirror-publication repairs address different boundaries. Mirror A/B1/B2 are merged in the producer; Agentbox's pinned dependency still predates them. My initial commentary that the path duplication was repaired was incorrect.
- Device re-enrolment findings require a valid owner-bound device proof and the existing principal guard; they are not arbitrary unauthenticated takeovers. The device gate uses a shared pure predicate with separate worker enforcement. Website configuration mirrors are an explicit accepted trade-off with checks.
- Ontology application already prefers the actual created path returned by the producer. Grouped application remains refused and explicit promote lacks approve's proposal-digest equality. Keep those distinct from the implemented path handling.
- The XR 512 limit caps link records; deduplicated endpoint markers are additional. This is an allowance-accounting gap, not evidence of a fixed-size buffer overflow. GPU hold messages carry holder identity; the remaining node-only state is in orchestrator bookkeeping. Link provenance belongs to VisionClaw's XR producer.
- Feature flags do not authorise promotion or withdrawal of decisions. VoiceLink's baked executable and recorder registrations justify implementation=partial rather than none; its end-to-end activation remains unverified. Isaac is outside the manifest gate described by the external text. Video routing and production acceptance receipts remain required.
