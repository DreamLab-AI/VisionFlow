# Audit wave 4, component coverage C

Each of the eight uncited components in my four repositories now has one disposition. Five are **assessed**: codescape `client`, `crates/codescape-model`, `crates/codescape-collab` and `(root)`, plus visiontouch-rs `apps/workspace-viewer`. Three are **out-of-scope**: WasmVOWL `legacy` (archived), WasmVOWL `tests` (an orphaned suite that nothing can run) and vowl-wasm `examples` (a benchmark with no product role). None is covered-elsewhere at its pin. VC-39 does describe codescape-model, codescape-collab and one client file, but it does so through VisionClaw's embedded copy at codescape `13e056d9` (VC-39:64). The coverage script only matches `../codescape/` paths, so it does not see those citations either way. The work produced eight findings. Two of them are about codescape's runtime surface: the client's `?server=` override can send the microphone stream to any host, and the language-model `answer` text has no length limit. The rest are debt, drift and corpus gaps. The evidence class is source tracing at the pinned revisions. Nothing here was run, built or tested.
