# agentbox governance, spend and custody diagrams (AB-14, AB-15, AB-16)

I assessed all 44 panels of AB-14 (governance journal, actions, approvals), AB-15 (capability gating, spend, consultants) and AB-16 (secrets custody, seccomp, profiles) against agentbox `c57d9c0508f4`. All three topics were stamped at `6500582dfae2`, 120 commits behind the pin, and 29 of their cited files had changed, so I restamped all three and re-resolved every citation. Outcome: 16 panels accurate, 20 corrected, 8 accurate with limits, none inaccurate-unfixed. The most important finding: AB-15.6 and AB-15.7 drew `POST /v1/pay/deposit` as forwarding a TXO deposit to the pod and returning `200 credited`. At the pin the route returns `501 deposit-not-served` and calls nothing. That route file did not change after the old stamp, so the drawing was already wrong when it was stamped. Two documented gaps have since closed upstream: `/v1/system` now reads the live action-plane snapshot, and the `vault edit` drift in AB-14.13 is resolved.

## Findings

**W3E-01. The `/v1/pay/deposit` route was drawn wrongly (AB-15.6, AB-15.7).**
- *Trigger:* both panels showed `POST /v1/pay/deposit {txo_uri, amount_sats}` → `POST /pay/.deposit` → `200 credited, new_balance`.
- *Consequence:* the drawing taught a deposit path that does not exist. A reader would expect agentbox to credit a balance.
- *Evidence:* the route answers `501` with `deposit-not-served` and a `deposit_url`, and calls nothing, because the pod accepts only a verified MRC20 body that is NIP-98 signed for the pod's own URL (`management-api/routes/payments.js:278-285`, `:286`, `:303-308`, at `c57d9c050`). `payments.js` is identical at `6500582` and at the pin, so the old stamp had already credited a wrong panel.
- *Closed:* both panels are corrected. AB-15.6 now shows the 501 and the out-of-band MRC20 deposit to the pod. AB-15.7 shows the 501 branch only.

**W3E-02. `/v1/system` execution coverage is now wired (AB-14.8, also AB-14.7 and AB-14.1).**
- *Trigger:* the AB-14.8 DOC-DRIFT note said `server.js` never supplied `options.execution.snapshot`, so `GET /v1/system` always reported `declared`.
- *Evidence:* at the pin, `server.js:1029-1037` registers `routes/system` with a lazy, fail-open `execution.snapshot` that calls `getCoverageSnapshot()` (`action-plane.js:296`). `routes/system.js:48-49` and `:61` consume it. ADR-2041 is now `implementation_status: complete`. Its close-out records the server wiring as staged until management-api restarts.
- *Closed:* the note is rewritten as RESOLVED, with that runtime limit stated. AB-14.7's "partial" now reads "implementation complete".

## Verification

**Evidence class.** Source tracing at agentbox `c57d9c0508f4044915f9aecea4b9aa5629cc6a35`, and at VisionClaw `86cdd76355823a51bb64d503c005fe277726e724` for AB-16's one VisionClaw source, `scripts/backup-secrets.sh`, which it names without a line. I read everything with `git show <pin>:<path>` and `git grep <pin>`. I ran no product tests and inspected no running container.

**Restamp.**
- AB-14 and AB-15: `verified_commit` set to the agentbox pin.
- AB-16: `{agentbox: <pin>, visionclaw: <pin>}`. The old VisionClaw stamp `8692b12` is an ancestor of the VisionClaw pin.

**How I re-resolved citations.**
1. A scratch script enumerated every `path:line` in each topic: Mermaid and prose, comma tails, and bare refs, using the generator's binding rules. That came to 648, 254 and 262 occurrences.
2. For each, it proposed the pin line from a difflib equal-block alignment of the file at the old stamp and at the pin. A proposal exists only where the line's text is byte-identical at both revisions.
3. I hand-confirmed every moved anchor in `entrypoint-unified.sh`, which was reordered, by reading the surrounding block at the pin.
4. One anchor could not be mapped (`consultant-base.js:43`). I re-derived it from the symbol, along with each line named in the Findings.
5. Every panel claim in a changed file was re-read against the pin.

**Disposition rule.** A panel whose only edits are renumbered citations from the restamp, with every claim still true, is **accurate** (examples: AB-16.13, AB-15.14). A panel with a citation that was wrong before the restamp, or with a stale claim, is **corrected**.

**Frontmatter paths.** Every path in the `sources:` and `governing:` lists of all three topics exists at its pin, including those cited without a line number (`git cat-file -e` over each list). No Drift is needed for missing paths.

**Non-unique anchors.** A remapped line whose text occurs more than once in its file was checked by hand to be the intended one: `system_one.rs:593`, `server.js:1225`, `agentbox.toml:1687,2223`, `flake.nix:2250`, `system_one.rs:458`, `env-classes.json:94` and the five repeated `entrypoint-unified.sh` anchors.
