## Lessons for the next session

- **Briefs go in files.** Inline agent messages and long shell commands are cut off at about 4 KB with no warning. Write the brief or script to a file and send the path.
- **Each worktree gets its own `CARGO_TARGET_DIR`.** With a shared target, a test in one worktree ran a binary built in another.
- **After a mutation run, `touch` the restored file.** Restoring with `mv` keeps the old mtime, so cargo does not rebuild and runs the mutated binary.
- **Codex `exec` here needs** `--skip-git-repo-check --sandbox read-only -`, with the evidence bundle on stdin. Its bwrap sandbox cannot start in this container.
- **Review every fix round's diff independently.** Each round whose code only its author read turned up real defects.
